You publish a new post, wait a week, and it still doesn’t show up on Google. So you open Search Console, paste the URL into URL Inspection, wait, read the result, and move on to the next one. That’s fine for 5 pages. For 500 product pages, or a whole website after a migration, it takes an entire afternoon.

I built a free bulk URL inspection tool for Google Sheets to fix that. Select your URLs, click Inspect, and it checks every one of them with Google’s own URL Inspection API: index status, last crawl date, canonicals, sitemaps, robots.txt and rich results. You can check up to 2,000 URLs a day per website, with no copy-paste.

In this guide you’ll see who it helps, what it shows for each URL, what every index status means, and how to set it up step by step.

What Is the Check Indexing Tool?

The Check Indexing tool is one of four free SEO tools I built with Google Apps Script for Supriyo’s Growth Lab. It runs in a sidebar inside Google Sheets and connects to your Google Search Console account.

For every URL you give it, it asks Google’s URL Inspection API the same question Search Console’s URL Inspection tool answers: is this page in Google’s index, and if not, why? The answers land in a new sheet tab, one row per URL, colour-coded so you can see the problems at a glance.

Because the data comes straight from Google, it’s the most reliable way to check indexing. Tricks like searching site: on Google are rough estimates, while bulk URL inspection gives you Google’s own answer for each page.

Who Can It Help?

  • Bloggers: check which of your new posts Google has indexed, and which it has crawled but left out.
  • E-commerce teams: find product and category pages that aren’t in Google, so they can’t bring in sales.
  • SEO agencies: check indexing for a client’s key pages every month, without hours of manual work.
  • Developers: confirm the important pages are still indexed after a migration, redesign or URL change.
  • Large and programmatic websites: check a sample of thousands of similar pages to see how many Google keeps.
  • News and content sites: see how quickly new articles are crawled and indexed.

You need to be a user on the website’s Search Console property. You don’t need to know how to code.

What You Get for Every URL

The results tab has 14 columns for each URL:

Column What it tells you
Index Status Yes, or No with Google’s reason, for example “URL is unknown to Google”
Last Crawled When Googlebot last visited the page
Google Selected Canonical The URL Google chose as the main version of this page
User Selected Canonical The canonical URL your page declares
Sitemaps The sitemaps where Google found this URL
Referring Page Pages that link to this URL, as Google sees them
Robots.txt Whether robots.txt allows Google to crawl the page
Indexing Whether the page allows indexing (no noindex)
Rich Results Whether Google found rich result markup, and if it’s valid
Rich Results Valid, Warning and Error Which rich results are valid, and the exact warnings and errors
Search Console Link A direct link to this URL’s report in Search Console

When Google’s selected canonical is different from yours, Google has decided another URL is the main version. That’s one of the most common hidden indexing problems, and it’s easy to spot here.

Key Features

1. Pick URLs from your sheet, or paste them

Select the cells with your URLs anywhere in the spreadsheet, or paste a list of up to 5,000 URLs. The selection can come from any tab, such as a sitemap export, an SEO audit or a list of new blog posts.

2. Manual or automatic property matching

Choose Manual to check every URL against one Search Console property. Choose Automatic if your URLs belong to several properties, for example a domain property and a few URL-prefix properties: the tool matches each URL to the property in your account that covers it.

3. Your daily quota, tracked for you

Google allows 2,000 inspections per property per day. The sidebar shows how many you’ve used, how many are left, and when the quota resets, in your own time zone. URLs outside the chosen property are marked as errors without using any quota.

4. Live progress and a clear summary

Click Inspect and watch the progress bar. When it’s done, the sidebar shows how many URLs are indexed, how many aren’t, any errors, any URLs skipped because of the quota, and a Why not indexed breakdown, for example “Page with redirect: 4” or “URL is unknown to Google: 2”.

5. Long lists keep going by themselves

The tool checks 10 URLs at a time, well under Google’s limit of 600 per minute. Long lists rest for about a minute every 4.5 minutes, then continue automatically, so you can close the sheet while a big list runs.

What Each Index Status Means (and What to Do)

These are the statuses you’ll see most often, with the fix for each.

Index status What it means What to do
Submitted and indexed The page is in Google Nothing. Keep it updated
URL is unknown to Google Google has never found the page Add it to your XML sitemap and link to it from other pages
Discovered – currently not indexed Google knows the URL but hasn’t crawled it yet Add internal links from strong pages, and make sure the site isn’t slow
Crawled – currently not indexed Google visited the page but chose not to index it Improve the content so it’s useful and unique, and add internal links
Duplicate without user-selected canonical Google sees the page as a copy of another one Add a canonical tag pointing to the main version, or make the page unique
Duplicate, Google chose different canonical than user Google ignored your canonical Make the content of the canonical page match, and fix conflicting signals
Page with redirect The URL redirects to another page Fine if it’s intended. Update internal links and sitemaps to the final URL
Excluded by “noindex” tag The page tells Google not to index it Remove the noindex tag if the page should rank
Blocked by robots.txt Google isn’t allowed to crawl the page Remove the robots.txt rule if the page should rank
Not found (404) The page doesn’t exist Restore it, or 301-redirect it to the closest page

After fixing your most important pages, use the Request Indexing button in Search Console to ask Google to crawl them again.

Where and When to Use It

  • After publishing new content: check last week’s posts or products to see which Google has picked up.
  • After a website migration: check the old site’s most important URLs on the new site to confirm they’re still indexed.
  • Checking your sitemap: run a bulk URL inspection on every URL in your XML sitemap to see how many Google actually keeps.
  • Fixing Search Console errors: export the URLs from a “Crawled – currently not indexed” report, fix them, then re-check them in bulk a few weeks later.
  • Monthly client reports: check a client’s 100 most important pages each month and report any that dropped out.
  • E-commerce clean-ups: find product pages that Google treats as duplicates of each other.

How to Set Up the Tool in Google Sheets (Step by Step)

The Check Indexing tool runs as a free Google Apps Script attached to a Google Sheet. The setup takes about 15 minutes, once.

If you’ve already set up my Search Console + GA4 performance report, you can reuse the same Google Cloud project and skip Steps 3 and 4.

Before you start

  • One Google account (Gmail) for every step. If your browser is signed in to several accounts, open an Incognito window and sign in with only this one.
  • Access to the data: your Gmail must be a user on the website’s Search Console property.
  • The tool code: nothing to download. You’ll copy it from the code boxes in Steps 1 and 2 below.

Step 1: Create a Google Sheet and add the code

  1. Go to sheets.new to create a new Google Sheet, and name it, for example “Index Check – website name”.
  2. Click Extensions → Apps Script. A code editor opens in a new tab.
  3. On the left, click the ⋮ next to Code.gs → Rename, and type index-checker.
  4. Click inside the code area, press Ctrl + A, then Delete, so it’s completely empty.
  5. Click Copy on the tool code box below these steps. Back in Apps Script, click inside the empty code area and paste with Ctrl + V.
  6. Press Ctrl + S to save. No red error should appear.

/** How many URLs are in the cells you have selected right now. */
function idxSelectionInfo() {
  try {
    const r = SpreadsheetApp.getActiveRange();
    if (!r) return { count: 0, a1: "" };
    return { count: idxSelectionUrls(r).length, a1: r.getSheet().getName() + "!" + r.getA1Notation() };
  } catch (e) {
    return { count: 0, a1: "" };
  }

function idxSelectionUrls(range) {
  return idxParseUrls(range.getValues().map(row => row.join("\n")).join("\n"));
}

/** Properties from Search Console (sites.list) that this Google account can use, sorted by name. */
function idxListSites() {
  const r = UrlFetchApp.fetch("https://searchconsole.googleapis.com/webmasters/v3/sites", {
    headers: { Authorization: "Bearer " + ScriptApp.getOAuthToken() }, muteHttpExceptions: true
  });
  if (r.getResponseCode() !== 200) {
    const err = new Error(idxApiError(r));
    if (idxApiDisabled(r)) {
      err.help = true;
      // Google's error usually contains the exact "enable" page for this script's Cloud project.
      err.enableUrl = (r.getContentText().match(/https:\/\/console\.(?:developers|cloud)\.google\.com\/apis\/(?:api|library)\/searchconsole\.googleapis\.com[^"\s\\]*/) || [""])[0];
    }
    throw err;
  }
  return (JSON.parse(r.getContentText()).siteEntry || [])
    .filter(s => s.permissionLevel && s.permissionLevel !== "siteUnverifiedUser")
    .map(s => ({ siteUrl: s.siteUrl, permission: s.permissionLevel.replace(/^site/, "") }))
    .sort((a, b) => idxSiteLabel(a.siteUrl).localeCompare(idxSiteLabel(b.siteUrl)));
}

function idxSiteLabel(siteUrl) {
  return String(siteUrl).replace(/^sc-domain:/, "").replace(/^https?:\/\//, "").replace(/\/$/, "");
}

/** True when the URL belongs to the property (domain property: same host or a subdomain; URL prefix: starts with it). */
function idxInProperty(url, siteUrl) {
  const u = String(url).toLowerCase(), s = String(siteUrl).toLowerCase();
  if (s.indexOf("sc-domain:") === 0) {
    const d = s.slice(10), m = u.match(/^https?:\/\/([^\/:?#]+)/);
    return !!m && (m[1] === d || m[1].slice(-(d.length + 1)) === "." + d);
  }
  return u.indexOf(s) === 0;
}

/** The most specific property in the list that covers the URL (longest URL prefix wins over a domain property). */
function idxBestSite(url, siteUrls) {
  let best = "", score = -1;
  siteUrls.forEach(s => {
    if (!idxInProperty(url, s)) return;
    const sc = (s.indexOf("sc-domain:") === 0 ? 0 : 1000) + s.length;
    if (sc > score) { score = sc; best = s; }
  });
  return best;
}

function idxApiDisabled(r) {
  return /has not been used|is disabled|SERVICE_DISABLED|accessNotConfigured/i.test(r.getContentText());
}

/** Turns an API error into a message a person can act on. */
function idxApiError(r) {
  let msg = "";
  try { msg = (JSON.parse(r.getContentText()).error || {}).message || ""; } catch (e) {}
  const code = r.getResponseCode();
  if (idxApiDisabled(r))
    return "The Google Search Console API isn't enabled for this sheet's Google Cloud project yet (one-time setup).";
  if (/insufficient.*scope|ACCESS_TOKEN_SCOPE_INSUFFICIENT/i.test(msg))
    return "Missing permission: add https://www.googleapis.com/auth/webmasters.readonly to appsscript.json, save, and authorise again.";
  if (code === 401) return "Google sign-in expired. Reload the sheet and try again.";
  return msg ? msg + " (HTTP " + code + ")" : "Search Console answered HTTP " + code;
}

/** choice = { source: "selection" | "paste", urls, mode: "manual" | "auto", siteUrl, output: "__new__" | tab name, replace } */
function idxStartCheck(choice) {
  const st = idxStatus();
  if ((st.phase === "running" || st.phase === "waiting") && !choice.replace)
    throw new Error("A check is already running. Press Stop first, or tick 'Replace it'.");

  // 1. URLs
  let urls;
  if (choice.source === "selection") {
    const r = SpreadsheetApp.getActiveRange();
    if (!r) throw new Error("Select the cells that contain your URLs first.");
    urls = idxSelectionUrls(r);
    if (!urls.length) throw new Error("No URLs found in the selected cells (" + r.getA1Notation() + "). Select the cells with your URLs and try again.");
  } else {
    urls = idxParseUrls(choice.urls);
    if (!urls.length) throw new Error("Paste at least one URL (one per line).");
  }
  urls = urls.slice(0, IDX.MAX_URLS);

  // 2. Property for each URL
  let sites;
  if (choice.mode === "auto") {
    sites = idxListSites().map(s => s.siteUrl);
    if (!sites.length) throw new Error("No Search Console properties found for this Google account.");
  } else {
    if (!choice.siteUrl) throw new Error("Choose a property for the selected URLs.");
    sites = [String(choice.siteUrl)];
  }
  const used = idxQuotaCounts();
  const left = {};
  const pre = urls.map(u => {
    const site = choice.mode === "auto" ? idxBestSite(u, sites) : (idxInProperty(u, sites[0]) ? sites[0] : "");
    if (!site) return choice.mode === "auto" ? IDX_MSG.noProperty : IDX_MSG.notInProperty;
    if (!(site in left)) left[site] = Math.max(0, IDX.DAILY_QUOTA - (used[site] || 0));
    if (left[site] <= 0) return IDX_MSG.quota;
    left[site]--;
    return "";
  });
  const toInspect = pre.filter(x => !x).length;
  if (!toInspect && pre.every(x => x === IDX_MSG.quota)) throw new Error("Today's URL Inspection quota (" + IDX.DAILY_QUOTA + " per property) is used up. It resets at midnight Pacific Time.");

  // 3. Results sheet
  idxDeleteTriggers();
  const ss = SpreadsheetApp.getActive();
  let sh;
  if (choice.output && choice.output !== IDX.NEW_SHEET) {
    sh = ss.getSheetByName(String(choice.output));
    if (!sh) throw new Error("Tab '" + choice.output + "' was not found.");
    sh.clear();
    sh.clearConditionalFormatRules();
  } else {
    const what = choice.mode === "auto" ? "Auto" : idxSiteLabel(sites[0]);
    const stamp = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd HH-mm");
    sh = ss.insertSheet(idxUniqueTabName(idxSafeTabName("URL Inspection · " + what + " · " + stamp)));
  }
  sh.getRange(1, 1, 1, IDX_HEADERS.length).setValues([IDX_HEADERS])
    .setFontWeight("bold").setBackground("#1f3864").setFontColor("#ffffff");
  sh.setFrozenRows(1);
  sh.setFrozenColumns(1);
  sh.getRange(2, 1, urls.length, 2).setValues(urls.map((u, i) => [u, pre[i]]));
  ss.setActiveSheet(sh);

  const preErrors = pre.filter(x => x === IDX_MSG.noProperty || x === IDX_MSG.notInProperty).length;
  const skipped = pre.filter(x => x === IDX_MSG.quota).length;
  PropertiesService.getScriptProperties().setProperty(IDX.STATUS_KEY, JSON.stringify({
    phase: "running", mode: choice.mode === "auto" ? "auto" : "manual", sites: sites.slice(0, 300),
    sheetName: sh.getName(), sheetId: sh.getSheetId(), total: urls.length, toInspect, next: 0, inspected: 0,
    counts: { indexed: 0, notIndexed: 0, errors: preErrors, skipped }, reasons: {}, startedAt: Date.now(), nextRunAt: null,
    log: [{ t: Date.now(), msg: "Started: " + toInspect + " of " + urls.length + " URL/s to inspect (" +
      (choice.mode === "auto" ? "automatic property matching" : idxSiteLabel(sites[0])) + ")" +
      (preErrors ? " · " + preErrors + " outside your properties" : "") + (skipped ? " · " + skipped + " skipped: daily quota" : "") +
      " → tab '" + sh.getName() + "'" }]
  }));
  idxRunChunk();
  return idxStatusForUi();
}

function idxStop() {
  idxDeleteTriggers();
  const s = idxStatus();
  if (s.phase === "running" || s.phase === "waiting") idxSaveStatus({ phase: "stopped", nextRunAt: null, log: "Stopped by you at " + (s.inspected || 0) + "/" + (s.toInspect || 0) });
  return idxStatusForUi();
}

function idxResume() {
  const s = idxStatus();
  if (!s.sheetName || s.phase === "done") return idxStatusForUi();
  idxSaveStatus({ phase: "running", nextRunAt: null, log: "Resumed" });
  idxRunChunk();
  return idxStatusForUi();
}

/** Brings the results tab to the front. */
function idxOpenResults() {
  const sh = idxResultSheet(idxStatus());
  if (sh) SpreadsheetApp.getActive().setActiveSheet(sh);
}

// Time-based trigger after a rest.
function continueIndexCheck() { idxRunChunk(); }

// ============================================================
//  THE RUN: batches of parallel URL Inspection calls, resume after rests
// ============================================================

function idxRunChunk() {
  // Document lock (not the script lock), so it never blocks a running On-Page & Tech Audit.
  const lock = LockService.getDocumentLock();
  if (!lock.tryLock(5000)) return;
  try {
    idxDeleteTriggers();
    let s = idxStatus();
    if (s.phase === "waiting") s = idxSaveStatus({ phase: "running", nextRunAt: null, log: "Resumed after resting" });
    if (s.phase !== "running") return;
    const sh = idxResultSheet(s);
    if (!sh) { idxSaveStatus({ phase: "error", message: "The results tab was deleted.", log: "Error: results tab not found" }); return; }

    const rows = sh.getRange(2, 1, s.total, 2).getValues();
    const token = ScriptApp.getOAuthToken();
    const start = Date.now();
    const counts = s.counts || { indexed: 0, notIndexed: 0, errors: 0, skipped: 0 };
    const reasons = s.reasons || {};
    let i = s.next || 0, inspected = s.inspected || 0;

    while (i < s.total && Date.now() - start < IDX.MAX_RUN_MS) {
      if (idxStatus().phase !== "running") return; // Stop was pressed
      // Next rows that still need inspecting (rows already marked as error/skipped are left as they are).
      const batch = [];
      while (i < s.total && batch.length < IDX.BATCH_SIZE) {
        const url = String(rows[i][0]).trim();
        if (url && !String(rows[i][1])) {
          batch.push({ row: i, url, site: s.mode === "auto" ? idxBestSite(url, s.sites) : s.sites[0] });
        }
        i++;
      }
      if (!batch.length) break;

      const resps = UrlFetchApp.fetchAll(batch.map(b => idxRequest(b.url, b.site, token)));
      // Rate limit (429): wait and retry those URLs once.
      const retry = [];
      resps.forEach((r, k) => { if (r.getResponseCode() === 429) retry.push(k); });
      if (retry.length) {
        idxSaveStatus({ log: "Google asked to slow down (429): waiting 15 s and retrying " + retry.length + " URL/s" });
        Utilities.sleep(15000);
        UrlFetchApp.fetchAll(retry.map(k => idxRequest(batch[k].url, batch[k].site, token))).forEach((r, j) => { resps[retry[j]] = r; });
      }
      // One inspection per URL: a 429 answer is a refusal, so the retry is the only call that counts.
      const spent = {};
      batch.forEach(b => { spent[b.site] = (spent[b.site] || 0) + 1; });
      idxAddQuota(spent);

      batch.forEach((b, k) => {
        const out = idxParseResult(resps[k], b.url);
        sh.getRange(2 + b.row, 2, 1, IDX_HEADERS.length - 1).setValues([out]);
        const v = String(out[0]);
        if (v === "Yes") counts.indexed++;
        else if (/^No, /.test(v)) { counts.notIndexed++; const why = v.slice(4); reasons[why] = (reasons[why] || 0) + 1; }
        else counts.errors++;
      });
      inspected += batch.length;
      idxSaveStatus({ next: i, inspected, counts, reasons });
      SpreadsheetApp.flush();
      Utilities.sleep(IDX.BATCH_PAUSE_MS);
    }

    if (i >= s.total) {
      idxFormatResults(sh, s.total);
      idxSaveStatus({ phase: "done", next: i, inspected, finishedAt: Date.now(),
        log: "Done: " + counts.indexed + " indexed, " + counts.notIndexed + " not indexed, " + counts.errors + " error/s" +
          (counts.skipped ? ", " + counts.skipped + " skipped" : "") });
      try { SpreadsheetApp.getActive().toast("Index check done: " + counts.indexed + " of " + inspected + " indexed.", "Check Indexing (GSC)", 8); } catch (e) {}
    } else {
      ScriptApp.newTrigger(IDX.TRIGGER).timeBased().after(IDX.REST_MS).create();
      const at = Date.now() + IDX.REST_MS;
      idxSaveStatus({ phase: "waiting", nextRunAt: at, restStartedAt: Date.now(),
        log: "Resting (Google's 6-minute limit) after " + inspected + "/" + s.toInspect + ". Expected to resume at " +
          Utilities.formatDate(new Date(at), Session.getScriptTimeZone(), "HH:mm:ss") });
    }
  } catch (e) {
    idxSaveStatus({ phase: "error", message: e.message, log: "Error: " + e.message + " (press Resume to retry)" });
    throw e;
  } finally {
    lock.releaseLock();
  }
}

function idxRequest(page, siteUrl, token) {
  return {
    url: "https://searchconsole.googleapis.com/v1/urlInspection/index:inspect",
    method: "post",
    contentType: "application/json",
    headers: { Authorization: "Bearer " + token },
    payload: JSON.stringify({ inspectionUrl: page, siteUrl, languageCode: "en-US" }),
    muteHttpExceptions: true
  };
}

/** One row (13 values, Index Status … Search Console Link) from one URL Inspection response. */
function idxParseResult(resp, page) {
  const E = IDX.EMPTY;
  const errorRow = msg => [msg, E, E, E, E, E, E, E, E, E, E, E, E];
  const code = resp.getResponseCode();
  if (code !== 200) {
    let msg = "";
    try { msg = (JSON.parse(resp.getContentText()).error || {}).message || ""; } catch (e) {}
    if (code === 403 || /not part of this property|do not own/i.test(msg)) return errorRow("Error: URL not in this property, or no access");
    if (code === 429) return errorRow("Error: rate limit / quota reached (run again later)");
    if (code === 400) return errorRow("Error: invalid URL for this property");
    return errorRow("Error: " + (msg || "HTTP " + code));
  }
  const result = JSON.parse(resp.getContentText()).inspectionResult;
  const s = result && result.indexStatusResult;
  if (!s) return errorRow("Unknown");

  const status = s.verdict === "PASS" ? "Yes" : "No, " + (s.coverageState || s.verdict);
  const rich = idxRichResults(result.richResultsResult);
  return [
    status,
    idxFormatTime(s.lastCrawlTime) || E,
    s.googleCanonical || E,
    s.userCanonical || E,
    (s.sitemap && s.sitemap.length) ? s.sitemap.join(",\n") : E,
    (s.referringUrls && s.referringUrls.length) ? s.referringUrls.join(",\n") : E,
    s.robotsTxtState === "ALLOWED" ? "Allowed" : s.robotsTxtState === "DISALLOWED" ? "Blocked" : E,
    ({ INDEXING_ALLOWED: "Allowed", BLOCKED_BY_META_TAG: "Blocked by meta tag", BLOCKED_BY_HTTP_HEADER: "Blocked by HTTP header",
      BLOCKED_BY_ROBOTS_TXT: "Blocked by robots.txt" })[s.indexingState] || E,
    rich.summary, rich.valid, rich.warning, rich.error,
    result.inspectionResultLink || E
  ];
}

function idxFormatTime(iso) {
  if (!iso) return "";
  const d = new Date(iso);
  return isNaN(d.getTime()) ? iso : Utilities.formatDate(d, Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
}

/** Rich results summary: worst issue wins; the three detail columns list types / messages. */
function idxRichResults(rr) {
  const E = IDX.EMPTY;
  if (!rr || !rr.detectedItems || !rr.detectedItems.length) return { summary: "No rich results detected", valid: E, warning: E, error: E };
  const valid = [], warn = [], err = [];
  rr.detectedItems.forEach(d => {
    let issue = false;
    (d.items || []).forEach(item => (item.issues || []).forEach(x => {
      issue = true;
      const m = x.issueMessage || "Unspecified issue";
      const list = x.severity === "ERROR" ? err : x.severity === "WARNING" ? warn : null;
      if (list && list.indexOf(m) === -1) list.push(m);
    }));
    const type = d.richResultType || "Unknown type";
    if (!issue && valid.indexOf(type) === -1) valid.push(type);
  });
  return {
    summary: err.length ? "Some items have errors" : warn.length ? "Some items have warnings" : "All items valid",
    valid: valid.length ? valid.join(",\n") : E,
    warning: warn.length ? warn.join(",\n") : E,
    error: err.length ? err.join(",\n") : E
  };
}

/** Colours and widths once the run is complete. */
function idxFormatResults(sh, rows) {
  const n = Math.max(1, rows);
  const col = sh.getRange(2, 2, n, 1);
  const rich = sh.getRange(2, 10, n, 1);
  const rule = () => SpreadsheetApp.newConditionalFormatRule();
  sh.setConditionalFormatRules([
    rule().whenTextEqualTo("Yes").setBackground("#d9ead3").setRanges([col]).build(),
    rule().whenTextStartsWith("No").setBackground("#f4cccc").setRanges([col]).build(),
    rule().whenTextStartsWith("Error").setBackground("#fff2cc").setRanges([col]).build(),
    rule().whenTextStartsWith("Skipped").setBackground("#eeeeee").setRanges([col]).build(),
    rule().whenTextEqualTo("Some items have errors").setBackground("#f4cccc").setRanges([rich]).build(),
    rule().whenTextEqualTo("Some items have warnings").setBackground("#fff2cc").setRanges([rich]).build()
  ]);
  sh.getRange(2, 1, n, IDX_HEADERS.length).setWrapStrategy(SpreadsheetApp.WrapStrategy.CLIP).setVerticalAlignment("top");
  sh.setColumnWidth(1, 360);
  sh.setColumnWidth(2, 260);
  for (let c = 3; c <= IDX_HEADERS.length; c++) sh.setColumnWidth(c, 180);
}

/**
 * Google's quota day: it runs midnight to midnight Pacific Time (12:30 PM / 1:30 PM in India).
 * Returns that day's date and the time (ms) it resets.
 */
function idxQuotaDay() {
  const tz = "America/Los_Angeles", now = new Date();
  const day = Utilities.formatDate(now, tz, "yyyy-MM-dd");
  const off = Utilities.formatDate(now, tz, "Z").replace(/(\d\d)$/, ":$1"); // e.g. -07:00
  return { day, resetAt: new Date(day + "T00:00:00" + off).getTime() + 24 * 3600 * 1000 };
}

/**
 * Saved quota use, kept in the script's properties (so it survives closing the sheet):
 * { days: { "yyyy-MM-dd" (Pacific): { siteUrl: count } }, last: { siteUrl: { at, day, n } } }
 */
function idxQuotaStore() {
  let q = {};
  try { q = JSON.parse(PropertiesService.getScriptProperties().getProperty(IDX.QUOTA_KEY) || "{}"); } catch (e) {}
  if (q.date && q.counts) q = { days: { [q.date]: q.counts }, last: {} }; // older format
  q.days = q.days || {};
  q.last = q.last || {};
  return q;
}

/** Inspections used today (Google's day) per property. */
function idxQuotaCounts() {
  return idxQuotaStore().days[idxQuotaDay().day] || {};
}

/** spent = { siteUrl: inspections } from one batch. Also remembers when each property was last used. */
function idxAddQuota(spent) {
  const q = idxQuotaStore(), today = idxQuotaDay().day, counts = q.days[today] || {};
  Object.keys(spent).forEach(site => {
    counts[site] = (counts[site] || 0) + spent[site];
    q.last[site] = { at: Date.now(), day: today, n: counts[site] };
  });
  q.days[today] = counts;
  Object.keys(q.days).sort().slice(0, -7).forEach(d => delete q.days[d]); // keep a week
  const sites = Object.keys(q.last).sort((a, b) => q.last[b].at - q.last[a].at);
  sites.slice(50).forEach(s => delete q.last[s]);
  PropertiesService.getScriptProperties().setProperty(IDX.QUOTA_KEY, JSON.stringify(q));
}

/** What the sidebar shows about the daily quota. */
function idxQuotaInfo() {
  const q = idxQuotaStore(), d = idxQuotaDay();
  return { day: d.day, resetAt: d.resetAt, dailyQuota: IDX.DAILY_QUOTA, used: q.days[d.day] || {}, last: q.last };
}

/** Unique http(s) URLs from text (one per line, or separated by spaces/commas). Bare domains get https://. */
function idxParseUrls(text) {
  const out = [], seen = {};
  String(text || "").split(/[\s,;]+/).forEach(t => {
    t = t.trim().replace(/^["'<(]+|[>)"',;]+$/g, "");
    if (!t) return;
    if (!/^https?:\/\//i.test(t)) {
      if (!/^[a-z0-9-]+(\.[a-z0-9-]+)+(\/|$)/i.test(t)) return;
      t = "https://" + t;
    }
    if (!/^https?:\/\/[^\s\/]+\.[^\s\/]+/i.test(t) || seen[t.toLowerCase()]) return;
    seen[t.toLowerCase()] = 1;
    out.push(t);
  });
  return out;
}

How to Run a Bulk URL Inspection

  1. Put your URLs in a column of the sheet and select them, or choose Paste URLs in the sidebar.
  2. Under Property, choose Manual and pick the website’s property, or choose Automatic.
  3. Under Results, keep Create New Sheet.
  4. Click Inspect. The progress bar shows each URL as it’s checked.
  5. When it says Done, read the summary, then click Open results to see every URL.

Tips for Getting the Most From Your Quota

  • Start each bulk URL inspection with your most important pages: money pages, top blog posts and new content.
  • Don’t re-check too soon. After fixing a page, give Google a week or two to crawl it again.
  • Start from your sitemap. It lists the pages you want indexed, so it’s the best list to check.
  • Use separate sheets for separate websites. Each sheet remembers its own settings.

What This Tool Doesn’t Do

Google’s URL Inspection API can read a page’s index status, but it can’t request indexing. For that, you still need the Request Indexing button in Search Console, one page at a time. The tool also only works for Search Console properties your account can access, and Google limits it to 2,000 inspections per property per day. Frequently asked questions

Is this bulk URL inspection tool free?

Yes. It uses Google's own URL Inspection API through a Google Apps Script in your Google Sheet. Google Sheets, Apps Script and the API are free for this kind of use, and no credit card is needed.

How many URLs can I check per day?

Google allows 2,000 URL inspections per Search Console property per day. The tool tracks your remaining quota, shows when it resets, and marks any extra URLs as skipped so you can run them the next day.

Can I check the indexing of a website I don't own?

No. Google's URL Inspection API only works for Search Console properties your Google account has access to. Ask the site owner to add you as a user in Search Console first.

Can the tool request indexing for my pages?

No. Google's URL Inspection API can read the index status but can't request indexing. Use the Request Indexing button in Search Console for your most important pages.

Do URLs outside my property use up the quota?

No. URLs that don't belong to the chosen property are marked as errors without calling Google, so they don't use any of your 2,000 daily inspections.
