Website migrations are where good rankings go to die. A new CMS, a redesign or a change of domain, and suddenly hundreds of old URLs return 404 errors. The traffic they brought in disappears with them, and often nobody notices until weeks later, because nobody saved a list of the old pages before the move.

The fix is simple: before you change anything, save every URL the website has. The quickest way to get that list is the XML sitemap. The problem is that real sitemaps are messy: a sitemap index pointing to dozens of child sitemaps, compressed .xml.gz files, thousands of URLs buried in XML.

So I built a free tool to extract URLs from sitemap files straight into Google Sheets. Paste a sitemap, or just a domain, click Extract URLs, and seconds later every page URL is in your spreadsheet, ready to sort, filter and compare.

What Is the Sitemap URL Extractor?

The Sitemap URL Extractor is one of four free SEO tools I built with Google Apps Script for Supriyo’s Growth Lab. It runs in a sidebar inside Google Sheets. You give it a sitemap address, and it:

  1. Reads the sitemap, or finds it for you from robots.txt if you only type the domain.
  2. Follows every child sitemap in a sitemap index, including nested indexes up to 3 levels deep.
  3. Writes every page URL into a new tab in your sheet, with a summary of what it found.

It works on any public sitemap. You don’t need Search Console access or a login to the website, so you can use it on your own sites, client sites and competitor sites alike.

Who Can It Help?

  • Developers and agencies handling migrations: save the full list of old URLs before the move, then use it to build the redirect map.
  • SEO consultants: extract URLs from sitemap files to get a complete page inventory of a new client’s website in seconds.
  • Content marketers: see every page a competitor has published, grouped by section.
  • Bloggers: build a list of every post for a content audit or an internal-linking plan.
  • E-commerce managers: count products and categories, and spot sitemaps that are out of date.

Key Features

1. Paste a sitemap, or just the domain

Paste any sitemap address: sitemap_index.xml, sitemap.xml, a compressed .xml.gz file or a plain-text .txt sitemap. Don’t know the address? Type only the domain. The tool checks robots.txt, then the usual addresses /sitemap_index.xml, /sitemap.xml and /wp-sitemap.xml, and uses the first real sitemap it finds. Shortcut buttons fill in the common addresses for you.

2. Sitemap indexes and nested sitemaps, handled for you

Big websites split their URLs across many sitemaps, listed in a sitemap index. Some indexes even point to more indexes. The tool follows all of them, up to 3 levels deep and 1,000 sitemap files per run, reading 10 at a time so even huge websites finish quickly.

3. Two layouts: one column per sitemap, or a single list

  • One column per sitemap: column A lists every sitemap file with its URL count, then each sitemap’s URLs get their own column. It’s perfect for seeing how a website is organised.
  • Single list: every URL in one column, with its Last Modified date and the sitemap it came from. You can also tick Remove duplicate URLs. It’s the best layout for sorting, filtering and comparing.

Results always go to a new tab, or one you choose, so your current tab is never cleared.

4. A clear summary, even for huge websites

When it’s done, the sidebar shows the total page URLs, unique URLs, sitemaps read and any errors, plus a list of every sitemap file with its own URL count. If a sitemap returns an error or an HTML page instead of XML, it’s reported for that sitemap instead of failing silently.

To test the limits, I ran it on the public sitemap of Meesho, one of India’s largest e-commerce websites. It read 80 sitemaps from an index of 507 and extracted 1,067,973 page URLs (1,054,099 unique) before stopping at its safety limit of about 1,000,000 URLs.

5. A tolerant reader for messy sitemaps

Real sitemaps often have small problems: a hidden byte-order mark, unusual namespaces or minor XML errors. The tool reads the page URLs anyway, and it leaves out image and video URLs, so your list contains only pages.

How to Use It for a Website Migration

This is the job the tool was made for. Use it in four steps around your migration:

  1. Before the move, save the old URLs. Extract URLs from the sitemap of the old website using the Single list layout, and keep that tab safe. It’s your record of every page that existed.
  2. Build the redirect map. Add a column next to each old URL with its new address. Every old URL needs a 301 redirect to the closest matching new page.
  3. After the launch, test the old URLs. Paste the old list into my free SEO audit tool using List of URLs. It shows which old URLs redirect correctly, which return 404 errors, and which redirect through a chain of hops.
  4. Check that Google keeps the new pages. A few weeks later, run the new URLs through a bulk Google indexing check to see which pages Google has indexed.

Do the same extraction on the new website’s sitemap too. Comparing the two lists in Google Sheets shows pages that were dropped in the move.

More Ways to Use It

  • Competitor research: extract URLs from a competitor’s sitemap to see every page they’ve published. Sort by section, such as /blog/ or /products/, to see where they invest their content.
  • Content audits: start your content inventory from the sitemap in seconds, then add columns for traffic, quality and next steps.
  • Finding missing pages: compare your sitemap with a crawl of your website. Pages in the crawl but not in the sitemap may be hard for Google to find.
  • Checking freshness: in the Single list layout, sort by Last Modified to find sections that haven’t been updated in years.
  • Feeding your other tools: paste the URLs into an indexing checker, a rank tracker or a redirect tester.

How to Set Up the Tool in Google Sheets (Step by Step)

The extractor runs as a free Google Apps Script attached to a Google Sheet. It’s the easiest of my four tools to set up: about 3 minutes, with no Google Cloud project.

Before you start

  • A Google account (Gmail). If your browser is signed in to several accounts, open an Incognito window and sign in with only this one.
  • The tool code: nothing to download. You’ll copy it from the code boxes in Steps 1 and 2 below.

Step 1: Create a Google Sheet and add the code

  1. Go to sheets.new to create a new Google Sheet, and name it, for example “Sitemap URLs – website name”.
  2. Click Extensions → Apps Script. A code editor opens in a new tab.
  3. On the left, click the ⋮ next to Code.gs → Rename, and type sitemap-extractor.
  4. Click inside the code area, press Ctrl + A, then Delete, so it’s completely empty.
  5. Click Copy on the tool code box below these steps. Back in Apps Script, click inside the empty code area and paste with Ctrl + V.
  6. Press Ctrl + S to save. No red error should appear.

The tool code (sitemap-extractor.gs, 449 lines). The box scrolls, and Copy copies all of it:

/**
 * ============================================================
 *  SITEMAP URL EXTRACTOR
 * ============================================================
 *  Menu: SEO Tools > Sitemap URL Extractor (menu created by onOpen() at the end of this file).
 *
 *  Sidebar: paste a sitemap URL (sitemap_index.xml, sitemap.xml, .xml.gz, .txt) or just a domain
 *  (the sitemap is then found from robots.txt or the usual addresses), choose the layout and the
 *  results tab, press Extract.
 *  - Index sitemap: every child sitemap is read (nested indexes too, up to 3 levels).
 *  - Single sitemap: its URLs are listed directly.
 *  Layouts: "One column per sitemap" (column A = sitemap files, then one column per sitemap)
 *           or "Single list" (URL | Last Modified | Sitemap), optionally without duplicates.
 *  Your current tab is never cleared: results go to a new tab or a tab you pick.
 *
 * ============================================================
 */

const SMX = {
  PARALLEL: 10,                 // child sitemaps fetched at the same time
  MAX_DEPTH: 3,                 // index → index → index → sitemap
  MAX_SITEMAPS: 1000,           // sitemap files read in one run
  MAX_URLS: 1000000,            // stops reading more sitemaps after this many URLs
  STATUS_KEY: "SMX_STATUS",
  LAST_KEY: "SMX_LAST_INPUT",
  NEW_SHEET: "__new__",
  UA: "Mozilla/5.0 (compatible; SitemapURLExtractor/1.0)"
};

function openSitemapExtractor() {
  SpreadsheetApp.getUi().showSidebar(HtmlService.createHtmlOutput(SMX_SIDEBAR_HTML).setTitle("Sitemap URL Extractor"));
}

/** Tabs for the Results list and the last sitemap you typed. */
function smxGetInfo() {
  return {
    tabs: SpreadsheetApp.getActive().getSheets().map(s => s.getName()),
    lastInput: PropertiesService.getUserProperties().getProperty(SMX.LAST_KEY) || ""
  };
}

/** Live progress for the sidebar while smxExtract runs. */
function smxStatus() {
  try { return JSON.parse(PropertiesService.getUserProperties().getProperty(SMX.STATUS_KEY) || "{}"); } catch (e) { return {}; }
}

function smxSet(patch, fresh) {
  const s = fresh ? {} : smxStatus();
  Object.keys(patch).forEach(k => { s[k] = patch[k]; });
  PropertiesService.getUserProperties().setProperty(SMX.STATUS_KEY, JSON.stringify(s));
}

/** choice = { input, layout: "columns" | "list", dedupe, output: "__new__" | tab name } */
function smxExtract(choice) {
  try {
    const input = String(choice.input || "").trim();
    if (!input) throw new Error("Enter a sitemap URL or a domain.");
    const start = /^https?:\/\//i.test(input) ? input : "https://" + input;
    const m = start.match(/^(https?:\/\/[^\/?#]+)(.*)$/i);
    if (!m || m[1].indexOf(".") === -1) throw new Error("That doesn't look like a website address.");
    PropertiesService.getUserProperties().setProperty(SMX.LAST_KEY, input);
    smxSet({ phase: "running", step: "Starting…", read: 0, known: 1, urls: 0 }, true);

    // 1. Which sitemap(s) to start from
    let roots;
    if (/\.xml(\.gz)?$|\.txt$|sitemap/i.test(m[2] || "")) roots = [start];
    else {
      smxSet({ step: "Looking for the sitemap (robots.txt, /sitemap_index.xml, /sitemap.xml)…" });
      roots = smxDiscover(m[1]);
      if (!roots.length) throw new Error("No sitemap found for " + m[1] + " (checked robots.txt, /sitemap_index.xml, /sitemap.xml and /wp-sitemap.xml). Paste the sitemap URL instead.");
    }

    // 2. Read the sitemaps: an index adds its children to the queue
    const queue = roots.map(u => ({ url: u, depth: 0, from: "" }));
    const seen = new Set(roots);
    const files = [];
    let read = 0, urlCount = 0, stopped = "";
    while (queue.length) {
      if (files.length >= SMX.MAX_SITEMAPS) { stopped = "Stopped after " + SMX.MAX_SITEMAPS + " sitemap files"; break; }
      if (urlCount >= SMX.MAX_URLS) { stopped = "Stopped after " + SMX.MAX_URLS.toLocaleString() + " URLs"; break; }
      const batch = queue.splice(0, SMX.PARALLEL);
      const resps = smxFetchAll(batch.map(b => b.url));
      batch.forEach((b, k) => {
        const res = smxRead(resps[k]);
        read++;
        if (res.error) { files.push({ url: b.url, from: b.from, type: "error", error: res.error }); return; }
        if (res.type === "index") {
          let added = 0;
          res.items.forEach(c => {
            if (seen.has(c.loc) || b.depth >= SMX.MAX_DEPTH) return;
            seen.add(c.loc); added++;
            queue.push({ url: c.loc, depth: b.depth + 1, from: b.url });
          });
          files.push({ url: b.url, from: b.from, type: "index", children: added });
        } else {
          files.push({ url: b.url, from: b.from, type: "urlset", urls: res.items });
          urlCount += res.items.length;
        }
      });
      smxSet({ read, known: read + queue.length, urls: urlCount, step: "Read " + read + " of " + (read + queue.length) + " sitemap file/s" });
    }

    // 3. Write the results
    smxSet({ step: "Writing " + urlCount.toLocaleString() + " URLs to the sheet…" });
    const host = m[1].replace(/^https?:\/\//i, "");
    const sh = smxResultSheet(choice.output, host);
    const unique = smxWrite(sh, files, choice.layout === "list" ? "list" : "columns", !!choice.dedupe);
    SpreadsheetApp.getActive().setActiveSheet(sh);

    const summary = {
      sheetName: sh.getName(),
      indexes: files.filter(f => f.type === "index").length,
      sitemaps: files.filter(f => f.type === "urlset").length,
      errors: files.filter(f => f.type === "error").length,
      urls: urlCount, unique, stopped,
      files: files.slice(0, 300).map(f => ({ url: f.url, type: f.type, count: f.urls ? f.urls.length : 0, children: f.children || 0, error: f.error || "" }))
    };
    smxSet({ phase: "done", step: "Done" });
    return summary;
  } catch (e) {
    smxSet({ phase: "error", step: e.message });
    throw e;
  }
}

/** Sitemaps for a domain: "Sitemap:" lines in robots.txt, else the first usual address that is a real sitemap. */
function smxDiscover(origin) {
  const robots = smxFetchAll([origin + "/robots.txt"])[0];
  const fromRobots = [];
  if (!robots.error && robots.getResponseCode() === 200) {
    robots.getContentText().split(/\r?\n/).forEach(line => {
      const mm = line.match(/^\s*sitemap\s*:\s*(\S+)/i);
      if (mm && fromRobots.indexOf(mm[1]) === -1) fromRobots.push(mm[1]);
    });
  }
  if (fromRobots.length) return fromRobots;
  const guesses = [origin + "/sitemap_index.xml", origin + "/sitemap.xml", origin + "/wp-sitemap.xml"];
  const resps = smxFetchAll(guesses);
  for (let i = 0; i < guesses.length; i++) if (!smxRead(resps[i]).error) return [guesses[i]];
  return [];
}

function smxFetchAll(urls) {
  const req = u => ({ url: u, muteHttpExceptions: true, followRedirects: true, headers: { "User-Agent": SMX.UA } });
  try {
    return UrlFetchApp.fetchAll(urls.map(req));
  } catch (e) {
    // One bad address (DNS error, invalid URL) fails the whole batch: retry one by one.
    return urls.map(u => { try { return UrlFetchApp.fetch(u, req(u)); } catch (e2) { return { error: e2.message }; } });
  }
}

/** One fetched sitemap → { type: "index" | "urlset", items: [{ loc, lastmod }] } or { error }. */
function smxRead(resp) {
  if (resp.error) return { error: "Couldn't fetch: " + resp.error };
  const code = resp.getResponseCode();
  if (code !== 200) return { error: "HTTP " + code + (code === 404 ? " (not found)" : code === 403 ? " (blocked)" : "") };
  let text;
  try {
    const b = resp.getContent();
    text = b.length > 1 && (b[0] & 255) === 0x1f && (b[1] & 255) === 0x8b
      ? Utilities.ungzip(resp.getBlob().setContentType("application/x-gzip")).getDataAsString("UTF-8") // .xml.gz
      : resp.getContentText("UTF-8");
  } catch (e) {
    return { error: "Couldn't read the file: " + e.message };
  }
  return smxParse(text);
}

function smxParse(text) {
  text = String(text || "").replace(/^﻿/, "");
  if (/<sitemapindex[\s>]/i.test(text)) return { type: "index", items: smxBlocks(text, "sitemap") };
  if (/<urlset[\s>]/i.test(text)) return { type: "urlset", items: smxBlocks(text, "url") };
  if (/<html[\s>]/i.test(text.slice(0, 3000))) return { error: "Not a sitemap (the address returned a web page)" };
  const lines = text.split(/\r?\n/).map(s => s.trim()).filter(s => /^https?:\/\/\S+$/i.test(s)); // .txt sitemap
  if (lines.length) return { type: "urlset", items: lines.map(l => ({ loc: l, lastmod: "" })) };
  return { error: "Not a sitemap (no <urlset> or <sitemapindex> found)" };
}

/** <url> or <sitemap> blocks → unique { loc, lastmod }. Only the block's own <loc>, never <image:loc> / <video:loc>. */
function smxBlocks(text, tag) {
  const re = new RegExp("<" + tag + "\\b[^>]*>([\\s\\S]*?)</" + tag + ">", "gi");
  const out = [], seen = new Set();
  let m;
  while ((m = re.exec(text))) {
    const loc = smxTag(m[1], "loc");
    if (!loc || seen.has(loc)) continue;
    seen.add(loc);
    out.push({ loc, lastmod: smxTag(m[1], "lastmod") });
  }
  return out;
}

function smxTag(block, name) {
  const m = block.match(new RegExp("<" + name + ">\\s*(?:<!\\[CDATA\\[)?\\s*([\\s\\S]*?)\\s*(?:\\]\\]>)?\\s*</" + name + ">", "i"));
  if (!m) return "";
  return m[1].replace(/&amp;/g, "&").replace(/&lt;/g, "<").replace(/&gt;/g, ">").replace(/&quot;/g, "\"").replace(/&apos;/g, "'").trim();
}

//  OUTPUT

function smxResultSheet(output, host) {
  const ss = SpreadsheetApp.getActive();
  if (output && output !== SMX.NEW_SHEET) {
    const sh = ss.getSheetByName(String(output));
    if (!sh) throw new Error("Tab '" + output + "' was not found.");
    sh.clear();
    return sh;
  }
  const stamp = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd HH-mm");
  let name = ("Sitemap URLs · " + host + " · " + stamp).replace(/[\[\]\*\?\/\\:]/g, " ").slice(0, 90);
  if (ss.getSheetByName(name)) { let i = 2; while (ss.getSheetByName(name + " (" + i + ")")) i++; name += " (" + i + ")"; }
  return ss.insertSheet(name);
}

/** Makes sure the tab has at least rows × cols cells. */
function smxEnsureSize(sh, rows, cols) {
  if (sh.getMaxRows() < rows) sh.insertRowsAfter(sh.getMaxRows(), rows - sh.getMaxRows());
  if (sh.getMaxColumns() < cols) sh.insertColumnsAfter(sh.getMaxColumns(), cols - sh.getMaxColumns());
}

/** Writes the results; returns the number of unique page URLs. */
function smxWrite(sh, files, layout, dedupe) {
  const all = new Set();
  files.forEach(f => (f.urls || []).forEach(u => all.add(u.loc)));
  const head = r => r.setFontWeight("bold").setBackground("#1f3864").setFontColor("#ffffff").setWrap(true).setVerticalAlignment("middle");

  if (layout === "list") {
    const rows = [], seen = new Set();
    files.forEach(f => (f.urls || []).forEach(u => {
      if (dedupe) { if (seen.has(u.loc)) return; seen.add(u.loc); }
      rows.push([u.loc, u.lastmod || "", f.url]);
    }));
    files.filter(f => f.type === "error").forEach(f => rows.push(["Error: " + f.error, "", f.url]));
    smxEnsureSize(sh, rows.length + 1, 3);
    head(sh.getRange(1, 1, 1, 3).setValues([["URL", "Last Modified", "Sitemap"]]));
    if (rows.length) sh.getRange(2, 1, rows.length, 3).setValues(rows);
    sh.setColumnWidth(1, 420); sh.setColumnWidth(2, 170); sh.setColumnWidth(3, 320);
  } else {
    // Column A lists the sitemap files (when there's more than one); then one column per sitemap.
    const cols = [];
    const single = files.length === 1 && files[0].type !== "index";
    if (!single) cols.push(["Sitemap files (" + files.length + ")"].concat(files.map(f =>
      f.url + (f.type === "index" ? "  [index: " + f.children + (f.children === 1 ? " sitemap]" : " sitemaps]") : f.type === "error" ? "  [error]" : "  [" + f.urls.length + (f.urls.length === 1 ? " URL]" : " URLs]")))));
    let n = 0;
    files.forEach(f => {
      if (f.type === "index") return;
      n++;
      const title = "Sitemap " + n + " (" + f.url + ")" + (f.urls ? " · " + f.urls.length + (f.urls.length === 1 ? " URL" : " URLs") : "");
      cols.push([title].concat(f.type === "error" ? ["Error fetching sitemap: " + f.error] : f.urls.map(u => u.loc)));
    });
    const maxLen = cols.reduce((a, c) => Math.max(a, c.length), 1);
    // Google Sheets holds 10 million cells: a very wide + very long result goes in the single list instead.
    if (maxLen * cols.length > 9000000) return smxWrite(sh, files, "list", dedupe);
    smxEnsureSize(sh, maxLen, cols.length);
    cols.forEach((c, i) => sh.getRange(1, i + 1, c.length, 1).setValues(c.map(v => [v])));
    head(sh.getRange(1, 1, 1, cols.length));
    sh.setRowHeight(1, 48);
    for (let i = 1; i <= cols.length; i++) sh.setColumnWidth(i, 360);
  }
  sh.setFrozenRows(1);
  return all.size;
}

  2. Tick Show “appsscript.json” manifest file in editor.
  3. Click ‹› Editor, open appsscript.json, select everything and delete it.

The tool asks for only 3 permissions: to edit the sheet, to download sitemaps from the web, and to show its sidebar.

Step 3: Give permission once

  1. Go back to your Google Sheet and reload the page. A new SEO Tools menu appears.
  2. Click SEO Tools → Sitemap URL Extractor, then Continue, and choose your Gmail.
  3. You’ll see “Google hasn’t verified this app”. That’s normal for your own private script: click Advanced → Go to (your project name) (unsafe), then Allow.
  4. Click SEO Tools → Sitemap URL Extractor again. The sidebar opens.

How to Extract URLs From Sitemap Files in Google Sheets

  1. Open SEO Tools → Sitemap URL Extractor.
  2. Paste the sitemap address, for example https://example.com/sitemap_index.xml, or just example.com.
  3. Choose One column per sitemap or Single list. For a migration or an audit, choose Single list and tick Remove duplicate URLs.
  4. Keep Results sheet on Create New Sheet.
  5. Click Extract URLs. Most sitemaps finish in a few seconds, and very large ones in a minute or two.
  6. Click Open results to see every URL.

Limits to Know

  • Up to 1,000 sitemap files and about 1,000,000 URLs per run. For bigger websites, extract one child sitemap at a time.
  • Google Sheets holds 10 million cells. If the one-column-per-sitemap layout would be too big, the tool switches to a single list automatically.
  • Sitemaps only. The tool lists the URLs in the sitemap, not every page on the website. To find pages that are missing from the sitemap, crawl the website with an audit tool and compare.
  • Some firewalls block scripts. If a website blocks the request, download the sitemap in your browser instead.

Frequently asked questions

Is the Sitemap URL Extractor free?

Yes. It runs as a Google Apps Script inside your own Google Sheet, so there's no subscription and no URL limit to pay for. You only need a free Google account.

Can I extract URLs from any website's sitemap?

Yes, from any public sitemap. You don't need Search Console or admin access, so it works for your own websites, clients' websites and competitors' websites.

How many URLs can it extract?

It reads up to 1,000 sitemap files and stops after about 1,000,000 URLs in one run. In a test on a large e-commerce website it extracted 1,067,973 URLs from 80 sitemaps.

What if I don't know the sitemap's address?

Type just the domain. The tool looks for the sitemap in robots.txt and at the usual addresses, such as /sitemap_index.xml, /sitemap.xml and /wp-sitemap.xml.

Does it work with compressed .xml.gz sitemaps?

Yes. It reads normal XML sitemaps, sitemap index files, compressed .xml.gz sitemaps and plain-text sitemaps, and follows nested sitemap indexes up to 3 levels deep.
