Paid SEO audit tools are great, until you see the price. Semrush costs well over $100 a month, and the free version of Screaming Frog stops at 500 URLs. If you’re a freelancer, a student, a small business owner or an agency just starting out, that’s a lot of money before you’ve earned anything.

So I built a free SEO audit tool that runs inside Google Sheets. Enter a website, click Start audit, and in about 10 minutes you get an in-depth on-page and technical SEO audit: every page checked against 60+ data points, every broken link, a site-wide health check, and a summary with a health score and your top 5 quick wins.

It doesn’t replace everything Semrush does, and I’ll be honest about that below. But it covers the checks you need for a solid basic-to-moderate audit, for free.

What Is the On-Page & Tech Audit Tool?

The On-Page & Tech Audit is one of four free SEO tools I built with Google Apps Script for Supriyo’s Growth Lab. This free SEO audit tool works like a small website crawler that lives in your spreadsheet:

  1. It finds the site’s pages from robots.txt, XML sitemaps and internal links.
  2. It visits each page, the way a search engine crawler does.
  3. It writes everything it finds into 5 tabs in your Google Sheet: Page Audit, Broken Links, Site Health, Summary and Discovered URLs.

Because the results land in Google Sheets, you can filter, sort, share and comment on them like any other spreadsheet. No exports, no software to install, no account to create.

Who Can It Help?

  • Freelancers: run a professional audit for every new client without paying for a tool subscription.
  • Agencies: audit a prospect’s website in 10 minutes and use the findings in your sales pitch.
  • Small business owners: find out what’s holding your website back before you pay anyone to fix it.
  • Bloggers: catch missing meta descriptions, thin posts, broken links and missing alt text across the whole blog.
  • E-commerce teams: check category and product pages, product counts and structured data in one pass.
  • Developers: check a new website before launch, or compare before and after a migration.
  • SEO students: learn technical SEO by seeing real data, check by check.

You don’t need to code, and you don’t need access to the website’s Search Console. The audit works on any public website.

What the Free SEO Audit Tool Checks

1. Audit a whole domain, one folder, or your own list of URLs

Choose Domain / Directory to crawl a whole website, or enter a folder URL like example.com/blog/ to audit only that section. Site Health still checks the whole domain. Or choose List of URLs and paste up to 5,550 URLs, one per line.

2. Settings you control

Every audit setting lives in the same sidebar and is saved automatically:

  • Crawl mode: Polite (recommended) sends 5 requests at a time with a 1-second pause and slows down if the server is busy. Fast mode is there for your own websites.
  • Max pages: from 1 to 5,550. URLs beyond the limit are listed in the Discovered URLs tab but not audited.
  • Follow links found on pages: finds pages missing from the sitemap.
  • URLs with a “?”: skipped by default, because they’re usually filter, sort or tracking copies of normal pages.
  • Respect robots.txt: skips blocked URLs and honours Crawl-delay.
  • Identify as: an honest bot name by default, or a normal browser if a firewall blocks bots.
  • Check external links: finds broken links to other websites, up to 500.

You can also add Core Web Vitals from real Chrome users (LCP, INP and CLS, the same data behind Search Console’s Core Web Vitals report) by pasting a free Google API key. It’s optional, and the setup steps are below.

3. A page-by-page audit with 60+ columns

The Page Audit tab has one row per page and a column for every check. Here’s what it covers, group by group.

Status, indexability and meta tags: initial and final status code, redirect hops and the full redirect chain, final URL, whether the page is indexable, HTML size, meta title and its length, meta description and its length, canonical URL, meta robots and hreflang tags.

Content and links: viewport, Open Graph and Twitter cards, H1 count and text, H2 and H3 headings, word count, images missing alt text or width and height, and every internal and external link in the main content, with its anchor text.

Performance and technology: broken links on the page, orphan pages, script count, render-blocking scripts, third-party domains, a performance risk rating, Core Web Vitals, the CMS or platform, products listed, tracking tags and the JavaScript-rendering risk.

Structured data, trust and duplicates: schema types, schema parse errors and missing properties, breadcrumbs, author, published and modified dates, contact signals, placeholder text, and duplicate titles, descriptions and content. Each row ends with its issues by priority (Critical, High, Medium, Low) and a page score.

4. Every broken link, with how to fix it

The Broken Links tab lists every broken link and every link that points to a redirect, with the page it’s on, the anchor text, where it sits (main content, or menu, header and footer), its status code and a plain-English fix. Menu links are checked too, so one broken footer link that appears on 868 pages shows up as one row, not 868.

5. Site Health checks for the whole domain

The Site Health tab checks the things that affect every page: homepage and SSL, HTTP to HTTPS and www redirects, robots.txt, XML sitemaps (count, freshness and coverage), indexable pages missing from the sitemap, non-indexable URLs inside the sitemap, 404 handling, browser and CDN caching, response time, HSTS and security headers, mixed content, orphan pages and the favicon.

6. A summary with a health score and quick wins

The Summary tab is where you start. It lists every check the audit ran, gives the website an overall health score out of 100, shows the key numbers, ranks every issue by priority with how to fix it, and picks your top 5 quick wins.

Where and When to Use It

  • Pitching a new client: use the free SEO audit tool on the prospect’s website before the call and walk them through their top 5 quick wins.
  • Monthly health checks: re-run the audit on your own websites and compare the health score month by month.
  • Before and after a migration: audit the old site, save the sheet, then audit the new one to catch lost pages, redirect chains and missing canonicals.
  • Before a website launch: catch noindex tags left over from staging, missing titles and broken links before Google sees them.
  • Content clean-ups: filter the Page Audit tab for thin content, duplicate titles and missing meta descriptions.
  • E-commerce reviews: find categories with fewer than 3 products, structured data errors and product listing problems.

How to Set Up the Tool in Google Sheets (Step by Step)

The audit runs as a free Google Apps Script attached to a Google Sheet. It takes about 5 minutes, and unlike most SEO tools there’s no Google Cloud project to create.

Before you start

  • A Google account (Gmail). If your browser is signed in to several accounts, open an Incognito window and sign in with only this one.
  • The tool code: nothing to download. You’ll copy it from the code boxes in Steps 1 and 2 below.

Step 1: Create a Google Sheet and add the code

  1. Go to sheets.new to create a new Google Sheet, and name it, for example “SEO Audit – website name”.
  2. Click Extensions → Apps Script. A code editor opens in a new tab.
  3. On the left, click the ⋮ next to Code.gs → Rename, and type seo-audit.
  4. Click inside the code area, press Ctrl + A, then Delete, so it’s completely empty.
  5. Click Copy on the tool code box below these steps. Back in Apps Script, click inside the empty code area and paste with Ctrl + V.
  6. Press Ctrl + S to save. No red error should appear.

/** Core of the URL-list mode (used by the Start sidebar). */
function runListAudit(urls) {
  const settings = getSettings();
  const seen = new Set(), queue = [];
  urls.forEach(u => {
    const k = queueKey(u);
    if (!seen.has(k)) { seen.add(k); queue.push([u, "Your list", ""]); }

  const p = parseUrl(queue[0][0]) || { host: "", protocol: "https" };
  initStatus();
  beginAudit({ mode: "manual", queue, settings, host: p.host, protocol: p.protocol, robots: null,
    discovery: { listed: queue.length, sitemap: 0, crawl: 0, blocked: 0, sitemapFiles: 0, sitemapFound: "" } });
}

/**
 * Core of the automatic mode (used by the Start sidebar). p = parsed domain or directory URL.
 * A directory URL (e.g. https://site.com/blog/) limits the crawl to pages inside that folder;
 * Site Health still checks the whole domain.
 */
function runAutoAudit(p) {
  const settings = getSettings();
  CURRENT_UA = settings.userAgent;
  const scope = directoryScope(p.path);
  clearTriggers();
  initStatus();
  setStatus({ phase: "discovering", auto: true, step: "Checking the homepage",
    log: "Auto-discovery started for " + p.host + (scope ? " (only the " + scope + "/ folder)" : "") });
  showProgress();

  // The homepage's final URL decides the exact host and protocol we crawl (www / non-www, http / https).
  const homeChain = followRedirectChain(p.protocol + "://" + p.host + "/");
  const home = parseUrl(homeChain.finalUrl) || p;
  const origin = home.protocol + "://" + home.host;

  setStatus({ step: "Reading robots.txt" });
  const rr = fetchOne(origin + "/robots.txt", true);
  const robotsTxt = rr.response && rr.response.getResponseCode() === 200 && !looksHtml(rr.response.getContentText())
    ? rr.response.getContentText() : "";
  const robots = parseRobots(robotsTxt);
  const group = findRobotsGroup(robots.groups, CONFIG.BOT_TOKEN);

  const candidates = unique(robots.sitemaps.concat([origin + "/sitemap.xml", origin + "/sitemap_index.xml", origin + "/wp-sitemap.xml"])).slice(0, 6);
  const sm = discoverSitemapUrls(candidates, step => setStatus({ step }));

  const ctx = { root: bareHost(home.host), host: home.host, protocol: home.protocol, settings, scope };
  const seen = new Set(), queue = [];
  let blocked = 0, fromSitemap = 0;
  const add = (u, source) => {
    const q = toQueueUrl(u, ctx);
    if (!q) return;
    const k = queueKey(q);
    if (seen.has(k)) return;
    seen.add(k);
    if (settings.respectRobots && group && !robotsAllows(group, pathOf(q))) { blocked++; return; }
    if (queue.length >= CONFIG.MAX_QUEUE) return;
    queue.push([q, source, ""]);
    if (source === "Sitemap") fromSitemap++;
  };
  if (scope) add(origin + p.path, "Start URL");
  else add(origin + "/", "Homepage");
  sm.urls.forEach(u => add(u, "Sitemap"));
  setStatus({ step: "Found " + queue.length + " URLs", log: "Discovery: " + queue.length + " URLs (" + fromSitemap + " from " +
    sm.files + " sitemap file/s" + (scope ? ", inside " + scope + "/" : "") + (blocked ? ", " + blocked + " blocked by robots.txt" : "") + ")" });

  beginAudit({ mode: "auto", queue, settings, host: home.host, protocol: home.protocol, scope,
    robots: group ? { agents: group.agents, rules: group.rules.slice(0, 300), crawlDelay: group.crawlDelay || 0 } : null,
    discovery: { listed: 0, sitemap: fromSitemap, crawl: 0, blocked, sitemapFiles: sm.files, sitemapFound: sm.found, scope } });
}

/** Called by the Settings card: tests the key with one CrUX request, then saves it. An empty key removes it. */
function saveCruxKey(key) {
  const props = PropertiesService.getScriptProperties();
  key = String(key || "").trim();
  if (!key) { props.deleteProperty("CRUX_API_KEY"); return cruxKeyInfo(); }
  if (!/^[A-Za-z0-9_\-]{30,60}$/.test(key)) throw new Error("That doesn't look like an API key (it usually starts with AIza).");
  const r = UrlFetchApp.fetch(CRUX_ENDPOINT + "?key=" + encodeURIComponent(key), { method: "post", contentType: "application/json",
    muteHttpExceptions: true, payload: JSON.stringify({ origin: "https://www.google.com", formFactor: "PHONE" }) });
  const code = r.getResponseCode();
  if (code !== 200 && code !== 404) {
    let msg = "";
    try { msg = JSON.parse(r.getContentText()).error.message || ""; } catch (e) {}
    throw new Error(cruxErrorText(code, msg));
  }
  props.setProperty("CRUX_API_KEY", key);
  return cruxKeyInfo();
}

/**
 * Called by the Start sidebar. choice = { mode: "domain" | "list", site, urls, settings, replace }.
 * Validation errors are shown in the sidebar; once the audit starts, the sidebar switches to the progress view.
 */
function startFromSidebar(choice) {
  saveSettings(choice.settings || {});
  const state = PropertiesService.getScriptProperties().getProperty("STATE");
  if ((state === "running" || state === "checking" || state === "finalizing") && !choice.replace) {
    throw new Error("An audit is already running. Tick 'Replace it' to start a new one.");
  }
  if (choice.mode === "domain") {
    let site = String(choice.site || "").trim();
    if (!site) throw new Error("Please enter a domain or directory URL.");
    if (!/^https?:\/\//i.test(site)) site = "https://" + site;
    const p = parseUrl(site);
    if (!p || p.host.indexOf(".") === -1) throw new Error("That doesn't look like a website address.");
    runAutoAudit(p);
    return "started";
  }
  const urls = parseUrlList(choice.urls);
  if (!urls.length) throw new Error("Paste at least one URL (one per line).");
  writeInputList(urls);
  runListAudit(urls);
  return "started";
}

/** Splits pasted text into unique URLs (one per line, or separated by spaces/commas). Bare domains get https://. */
function parseUrlList(text) {
  const out = [], seen = new Set();
  String(text || "").split(/[\s,;]+/).forEach(t => {
    t = t.trim().replace(/^["'<(]+|[>)"',.;]+$/g, "");
    if (!t) return;
    if (!/^https?:\/\//i.test(t)) {
      if (!/^[a-z0-9-]+(\.[a-z0-9-]+)+(\/|$)/i.test(t)) return;
      t = "https://" + t;
    }
    if (!parseUrl(t)) return;
    const k = queueKey(t);
    if (seen.has(k)) return;
    seen.add(k);
    out.push(t);
  });
  return out;
}

/** Saves the pasted list in the On Page tab so it's kept with the report. */

  const sheet = getOrCreateSheet(CONFIG.INPUT_TAB);
  const last = sheet.getLastRow();
  if (last > 1) sheet.getRange(2, 1, last - 1, 1).clearContent();
  sheet.getRange("A1").setValue("URL").setFontWeight("bold");
  sheet.getRange(2, 1, urls.length, 1).setValues(urls.map(u => [u]));
}

/** Polite = 5 parallel + 1 s pause; Fast = 25 parallel. A robots.txt Crawl-delay forces one request at a time. */
function initialCrawlState(settings, robots) {
  const s = settings.mode === "Fast" ? { conc: 25, delay: 0 } : { conc: 5, delay: 1000 };
  if (settings.respectRobots && robots && robots.crawlDelay > 0) { s.conc = 1; s.delay = Math.min(10, robots.crawlDelay) * 1000; }
  s.slowdowns = 0;
  return s;
}

function processChunk() {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(5000)) return;
  let checksNow = false, start = Date.now();
  try {
    const props = PropertiesService.getScriptProperties();
    if (props.getProperty("STATE") !== "running") return;
    clearTriggers();

    start = Date.now();
    const settings = JSON.parse(props.getProperty("SETTINGS") || "null") || getSettings();
    CURRENT_UA = settings.userAgent;
    const mode = props.getProperty("MODE") || "manual";
    const robots = JSON.parse(props.getProperty("ROBOTS") || "null");
    const crawl = JSON.parse(props.getProperty("CRAWL") || "null") || initialCrawlState(settings, robots);
    const disc = JSON.parse(props.getProperty("DISCOVERY") || "{}");
    const agg = JSON.parse(props.getProperty("AGG") || "null") || emptyAgg();
    const host = props.getProperty("SITE_HOST") || "";
    const ctx = { root: bareHost(host), host, protocol: props.getProperty("SITE_PROTOCOL") || "https", settings,
      scope: props.getProperty("SITE_SCOPE") || "" };
    const follow = mode === "auto" && settings.followLinks;

    const qs = getOrCreateSheet(CONFIG.QUEUE_TAB);
    const queue = qs.getLastRow() > 1 ? qs.getRange(2, 1, qs.getLastRow() - 1, 1).getValues().map(r => String(r[0])) : [];
    const seen = new Set(queue.map(queueKey));
    const sheet = getOrCreateSheet(CONFIG.AUDIT_TAB);
    const cap = settings.maxPages;
    const limit = () => Math.min(queue.length, cap);

    let next = Number(props.getProperty("NEXT_INDEX") || 0), written = next;
    let buffer = [], newQueue = [], linkBuffer = [];
    const linkSheet = hiddenSheet(CONFIG.LINKS_TAB);
    const prev = getAuditStatus();
    setStatus({ phase: "crawling", nextRunAt: null, done: written, total: limit(), discovered: queue.length,
      log: prev.phase === "waiting" ? "Resumed after resting " + Math.round((Date.now() - (prev.restStartedAt || Date.now())) / 1000) + " s" : null });

    // Writes buffered rows + newly found URLs, then refreshes the live summary. No requests: sheet writes only.
    const flush = () => {
      if (buffer.length) {
        sheet.getRange(written + 2, 1, buffer.length, HEADERS.length).setValues(buffer);
        updateAgg(agg, buffer);
        written += buffer.length;
        buffer = [];
      }
      if (newQueue.length) {
        qs.getRange(qs.getLastRow() + 1, 1, newQueue.length, 3).setValues(newQueue.map(r => r.map(sanitize)));
        newQueue = [];
      }
      if (linkBuffer.length) {
        linkSheet.getRange(linkSheet.getLastRow() + 1, 1, linkBuffer.length, 2).setValues(linkBuffer);
        linkBuffer = [];
      }
      props.setProperties({ NEXT_INDEX: String(written), AGG: JSON.stringify(agg), CRAWL: JSON.stringify(crawl), DISCOVERY: JSON.stringify(disc) });
      setStatus({ done: written, total: limit(), discovered: queue.length, conc: crawl.conc });
      writeLiveSummary(agg, queue.length, disc, cap, settings);
      SpreadsheetApp.flush();
    };

    while (next < limit() && Date.now() - start < CONFIG.MAX_RUNTIME_MS) {
      const batch = queue.slice(next, Math.min(next + Math.max(1, crawl.conc), limit()));
      const t0 = Date.now();
      const chains = resolveChainsParallel(batch, fetchMany(batch, false));
      const took = Date.now() - t0;

      // Politeness: on 429/503 slow down (honouring Retry-After), then retry those URLs once so a busy
      // server isn't reported as broken pages. In Polite mode also slow down when the server gets slow.
      const busy = [];
      let retryAfter = 0;
      chains.forEach((c, i) => {
        const code = c.chain.length ? c.chain[c.chain.length - 1].code : 0;
        if (code === 429 || code === 503) {
          busy.push(i);
          const ra = c.response ? Number(getHeader(c.response.getAllHeaders(), "Retry-After")) : 0;
          if (ra > retryAfter) retryAfter = ra;
        }
      });
      const throttled = busy.length;
      if (throttled) {
        crawl.conc = Math.max(1, Math.floor(crawl.conc / 2));
        crawl.delay = Math.min(15000, Math.max(2000, crawl.delay * 2));
        crawl.slowdowns++;
        setStatus({ log: "Server answered " + throttled + "× 429/503: slowing down to " + crawl.conc + " parallel + " +
          (crawl.delay / 1000) + " s pause, retrying those URLs" });
        Utilities.sleep(Math.min(30000, Math.max(crawl.delay, retryAfter * 1000)));
        const again = busy.map(i => batch[i]);
        resolveChainsParallel(again, fetchMany(again, false)).forEach((c, j) => { chains[busy[j]] = c; });
      }

      const rows = batch.map((u, i) => {
        try { return analyzeUrl({ url: u }, null, chains[i]); }
        catch (e) { return errorRow({ url: u }, "Script error: " + e.message); }
      });
      if (follow) rows.forEach(r => (r.discovered || []).forEach(link => {
        const q = toQueueUrl(link, ctx);
        if (!q) return;
        const k = queueKey(q);
        if (seen.has(k)) return;
        seen.add(k);
        if (settings.respectRobots && robots && !robotsAllows(robots, pathOf(q))) { disc.blocked = (disc.blocked || 0) + 1; return; }
        if (queue.length >= CONFIG.MAX_QUEUE) return;
        queue.push(q);
        newQueue.push([q, "Crawl", ""]);
        disc.crawl = (disc.crawl || 0) + 1;
      }));
      rows.forEach(r => { if (r.links) linkBuffer.push([r.source, r.links]); });
      buffer = buffer.concat(rows.map(r => r.slice()));
      next += batch.length;
      if (buffer.length >= CONFIG.WRITE_EVERY) flush();

      if (!throttled) {
        if (settings.mode === "Polite" && took > 3000 && crawl.delay < 5000) {
          crawl.delay += 1000;
          crawl.slowdowns++;
          setStatus({ log: "Server is slow (" + (took / 1000).toFixed(1) + " s per batch): pause increased to " + (crawl.delay / 1000) + " s" });
        }
        if (crawl.delay) Utilities.sleep(crawl.delay);
      }
    }
    flush();

    if (written >= limit()) {
      // Next stage: broken links, orphan pages and Core Web Vitals (checkChunk), then Site Health + Summary.
      props.setProperties({ STATE: "checking", STAGE: "checks", CHECK_READY: "", CHECK_INDEX: "0" });
      setStatus({ stage: "checks", log: "Crawl finished: " + written + " pages. Next: links and Core Web Vitals" });
      if (Date.now() - start < CONFIG.INLINE_FINALIZE_MS) {
        checksNow = true;
      } else {
        rest("checkChunk", "link & speed checks", written, limit());
      }
    } else {
      rest("processChunk", "crawling", written, limit());
    }
  } catch (e) {
    setStatus({ phase: "error", message: e.message, log: "Error: " + e.message + " (use Resume audit to retry)" });
    throw e;
  } finally {
    lock.releaseLock();
  }
  if (checksNow) checkChunk(start); // same execution: the checks share this run's 6-minute budget
}

/** Pause before Google's 6-minute limit and schedule the next run; the sidebar shows a countdown to resumeAt. */
function rest(fnName, what, done, total, unit) {
  scheduleNext(fnName);
  const resumeAt = Date.now() + 60 * 1000;
  const at = Utilities.formatDate(new Date(resumeAt), Session.getScriptTimeZone(), "HH:mm:ss");
  setStatus({ phase: "waiting", waitingFor: what, nextRunAt: resumeAt, restStartedAt: Date.now(),
    log: "Resting (Google's 6-minute limit) after " + done + "/" + total + " " + (unit || "pages") + ". Expected to resume " + what + " at " + at });
}

function finalizeAudit() {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(10000)) return;
  try {
    clearTriggers();
    const props = PropertiesService.getScriptProperties();
    const stored = JSON.parse(props.getProperty("SETTINGS") || "null");
    if (stored) CURRENT_UA = stored.userAgent;
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.AUDIT_TAB);
    if (!sheet || sheet.getLastRow() < 2) { safeToast("No audit data found. Run an audit first."); return; }

    const n = sheet.getLastRow() - 1;
    const data = sheet.getRange(2, 1, n, HEADERS.length).getValues();
    const prev = getAuditStatus();
    if (prev.phase === "waiting") setStatus({ log: "Resumed after resting " + Math.round((Date.now() - (prev.restStartedAt || Date.now())) / 1000) + " s" });

    // Site Health first: its sitemap <lastmod> dates feed the page date checks and scores.
    setStatus({ done: n, nextRunAt: null });
    const site = runSiteHealth(data);
    // Broken links, orphan pages and Core Web Vitals come from the post-crawl checks (no requests here).
    const extra = analyzeLinksAndSpeed(data, site);
    const checks = site.checks.concat(extra.checks);
    writeSiteHealth(checks);
    writeBrokenLinks(extra.broken, extra.hasLinks);

    setStatus({ phase: "scoring", log: "Scoring pages and finding duplicates" });
    applySitemapDates(data, site.lastmods);
    applyDuplicatesAndScores(data, extra.pageIssues);
    sheet.getRange(2, 1, n, HEADERS.length).setValues(data.map(r => r.map(sanitize)));
    formatAuditSheet(sheet, n);
    markQueueStatus(n, stored ? stored.maxPages : CONFIG.MAX_PAGES);

    setStatus({ phase: "summary", log: "Building the Summary tab" });
    buildSummary(data, checks, site.host);

    props.setProperty("STATE", "done");
    setStatus({ phase: "done", log: "Audit complete: " + n + " pages" });
    safeToast("Audit complete: " + n + " pages. See the Summary tab.");
  } catch (e) {
    setStatus({ phase: "error", message: e.message, log: "Error: " + e.message + " (use Rebuild Site Health + Summary to retry)" });
    throw e;
  } finally {
    lock.releaseLock();
  }
}

const CRUX_ENDPOINT = "https://chromeuxreport.googleapis.com/v1/records:queryRecord";
const CRUX_METRICS = ["largest_contentful_paint", "interaction_to_next_paint", "cumulative_layout_shift"];

/**
 * Works through the _Checks tab (kind | URL | result) in ~4-minute chunks, like the crawl:
 * "int" = internal link target that wasn't crawled, "ext" = external URL, "crux-origin" / "crux-url" = CrUX lookups.
 * Then hands over to finalizeAudit.
 * runStartedAt: when called straight after the crawl in the same execution, the time that execution began
 * (a trigger passes an event object instead), so both share Google's 6-minute limit.
 */
function checkChunk(runStartedAt) {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(5000)) return;
  let finalizeNow = false;
  try {
    const props = PropertiesService.getScriptProperties();
    if (props.getProperty("STATE") !== "checking") return;
    clearTriggers();
    const start = typeof runStartedAt === "number" ? runStartedAt : Date.now();
    const settings = JSON.parse(props.getProperty("SETTINGS") || "null") || getSettings();
    CURRENT_UA = settings.userAgent;
    const crawl = JSON.parse(props.getProperty("CRAWL") || "null") || initialCrawlState(settings, null);
    const sheet = hiddenSheet(CONFIG.CHECKS_TAB);
    const prev = getAuditStatus();
    setStatus({ phase: "checking", stage: "checks", nextRunAt: null,
      log: prev.phase === "waiting" ? "Resumed after resting " + Math.round((Date.now() - (prev.restStartedAt || Date.now())) / 1000) + " s" : null });

    if (props.getProperty("CHECK_READY") !== "1") {
      setStatus({ checkStep: "Collecting the links found on the audited pages" });
      const n = prepareChecks(sheet, settings);
      props.setProperties({ CHECK_READY: "1", CHECK_INDEX: "0", CHECK_SKIPPED: JSON.stringify(n.skipped) });
      setStatus({ log: "To check: " + n.internal + " internal link target/s that weren't crawled, " + n.external + " external URL/s" +
        (n.crux ? ", " + n.crux + " Core Web Vitals lookup/s" : n.cruxNote ? " · Core Web Vitals: " + n.cruxNote : "") });
    }

    const total = Math.max(0, sheet.getLastRow() - 1);
    const rows = total ? sheet.getRange(2, 1, total, 3).getValues() : [];
    const key = props.getProperty("CRUX_API_KEY") || "";
    const isCrux = k => String(k).indexOf("crux") === 0;
    const label = k => isCrux(k) ? "Core Web Vitals (CrUX)" : k === "ext" ? "External links" : "Internal links";
    let next = Number(props.getProperty("CHECK_INDEX") || 0), lastCrux = 0, cruxDead = "";
    while (next < total && Date.now() - start < CONFIG.MAX_RUNTIME_MS) {
      const kind = String(rows[next][0]);
      const size = isCrux(kind) ? CONFIG.CRUX_BATCH : kind === "ext" ? 10 : Math.max(1, crawl.conc);
      let end = next;
      while (end < total && end - next < size && (isCrux(kind) ? isCrux(rows[end][0]) : rows[end][0] === kind)) end++;
      const batch = rows.slice(next, end);
      setStatus({ checkDone: next, checkTotal: total, checkStep: label(kind) });
      let results;
      if (isCrux(kind)) {
        if (cruxDead) results = batch.map(() => JSON.stringify({ err: cruxDead }));
        else {
          const wait = CONFIG.CRUX_GAP_MS - (Date.now() - lastCrux);
          if (lastCrux && wait > 0) Utilities.sleep(wait);
          results = cruxBatch(batch, key);
          lastCrux = Date.now();
          const fatal = results.map(r => JSON.parse(r)).find(r => r.fatal);
          if (fatal) { cruxDead = fatal.err; setStatus({ log: "Core Web Vitals skipped: " + fatal.err }); }
        }
      } else {
        results = linkBatch(batch.map(r => String(r[1])), kind === "ext");
        if (kind !== "ext" && crawl.delay) Utilities.sleep(Math.min(crawl.delay, 5000)); // same server as the crawl: stay polite
      }
      sheet.getRange(next + 2, 3, results.length, 1).setValues(results.map(r => [r]));
      next = end;
      props.setProperty("CHECK_INDEX", String(next));
    }
    setStatus({ checkDone: next, checkTotal: total });

    if (next >= total) {
      props.setProperty("STATE", "finalizing");
      setStatus({ log: "Links and Core Web Vitals checked (" + total + " request/s)" });
      // Site Health + Summary now also read every stored link: run them inline only with plenty of time left.
      if (Date.now() - start < CONFIG.INLINE_FINALIZE_MS - 90 * 1000) finalizeNow = true;
      else rest("finalizeAudit", "Site Health + Summary", next, total, "checks");
    } else {
      rest("checkChunk", "link & speed checks", next, total, "checks");
    }
  } catch (e) {
    setStatus({ phase: "error", message: e.message, log: "Error: " + e.message + " (use Resume audit to retry)" });
    throw e;
  } finally {
    lock.releaseLock();
  }
  if (finalizeNow) finalizeAudit();
}

/**
 * Builds the to-do list in the _Checks tab. Internal targets that were crawled are skipped (their status is in
 * the Page Audit tab). The most-linked targets come first, so the limits cut the least important ones.
 */
function prepareChecks(sheet, settings) {
  sheet.clear();
  const audit = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.AUDIT_TAB);
  const data = audit && audit.getLastRow() > 1 ? audit.getRange(2, 1, audit.getLastRow() - 1, HEADERS.length).getValues() : [];
  const known = new Set();
  data.forEach(r => {
    known.add(normalizeForCompare(String(r[COL["URL"]])));
    if (r[COL["Final URL"]]) known.add(normalizeForCompare(String(r[COL["Final URL"]])));
  });
  const internal = {}, external = {};
  forEachStoredLink((source, url) => {
    const p = parseUrl(url), sp = parseUrl(source);
    if (!p || !sp) return;
    const k = normalizeForCompare(url);
    const bucket = isInternal(bareHost(p.host), bareHost(sp.host)) ? (known.has(k) ? null : internal) : external;
    if (!bucket) return;
    if (bucket[k]) bucket[k].n++;
    else bucket[k] = { u: url, n: 1 };
  });
  const top = (map, max) => Object.keys(map).map(k => map[k]).sort((a, b) => b.n - a.n).slice(0, max).map(x => x.u);
  const intList = top(internal, CONFIG.MAX_INTERNAL_CHECKS);
  const extList = settings.checkExternal ? top(external, CONFIG.MAX_EXTERNAL_CHECKS) : [];
  const skipped = {
    int: Object.keys(internal).length - intList.length,
    ext: settings.checkExternal ? Object.keys(external).length - extList.length : 0,
    extOff: !settings.checkExternal
  };

  // Core Web Vitals: every indexable page plus the whole-site value of its origin (the fallback for low-traffic pages).
  const key = PropertiesService.getScriptProperties().getProperty("CRUX_API_KEY") || "";
  let crux = [], cruxNote = "";
  if (!key) cruxNote = "no API key in Settings";
  else if (!settings.checkCwv) cruxNote = "turned off in Settings";
  else {
    const seen = new Set();
    const pages = [];
    data.forEach(r => {
      if (String(r[COL["Indexable"]]) !== "Yes") return;
      const u = String(r[COL["Final URL"]] || r[COL["URL"]]);
      const k = normalizeForCompare(u);
      if (!seen.has(k)) { seen.add(k); pages.push(u); }
    });
    const origins = unique(pages.map(u => { const p = parseUrl(u); return p ? p.protocol + "://" + p.host : ""; }).filter(Boolean)).slice(0, 5);
    crux = origins.map(o => ["crux-origin", o, ""]).concat(pages.map(u => ["crux-url", u, ""]));
  }
  const todo = intList.map(u => ["int", u, ""]).concat(extList.map(u => ["ext", u, ""]), crux);
  sheet.getRange(1, 1, 1, 3).setValues([["Kind", "URL", "Result"]]);
  if (todo.length) sheet.getRange(2, 1, todo.length, 3).setValues(todo);
  return { internal: intList.length, external: extList.length, crux: crux.length, cruxNote, skipped };
}

/** Status of each URL as JSON: { c: code, l: redirect target } or { e: error }. External URLs follow redirects. */
function linkBatch(urls, external) {
  return fetchMany(urls, external).map((r, i) => {
    if (r.error) return JSON.stringify({ e: String(r.error).slice(0, 150) });
    const c = r.response.getResponseCode();
    const out = { c };
    if (!external && c >= 300 && c < 400) out.l = resolveUrl(getHeader(r.response.getAllHeaders(), "Location"), urls[i]) || "";
    return JSON.stringify(out);
  });
}

/** CrUX lookups (mobile). Result JSON: { lcp, inp, cls } p75 values, { nd: 1 } = not enough traffic, { err, fatal } = key/API problem. */
function cruxBatch(batch, key) {
  const url = CRUX_ENDPOINT + "?key=" + encodeURIComponent(key);
  const req = r => ({ url, method: "post", contentType: "application/json", muteHttpExceptions: true,
    payload: JSON.stringify(Object.assign(r[0] === "crux-origin" ? { origin: String(r[1]) } : { url: String(r[1]) }, { formFactor: "PHONE", metrics: CRUX_METRICS })) });
  let resps;
  try { resps = UrlFetchApp.fetchAll(batch.map(req)); }
  catch (e) { return batch.map(() => JSON.stringify({ err: String(e.message).slice(0, 150) })); }
  const busy = [];
  resps.forEach((r, i) => { if (r.getResponseCode() === 429) busy.push(i); });
  if (busy.length) {
    Utilities.sleep(20000); // per-minute quota: wait and retry once
    try { UrlFetchApp.fetchAll(busy.map(i => req(batch[i]))).forEach((r, j) => { resps[busy[j]] = r; }); } catch (e) {}
  }
  return resps.map(r => {
    const code = r.getResponseCode();
    let body = {};
    try { body = JSON.parse(r.getContentText()); } catch (e) {}
    if (code === 200) {
      const m = (body.record || {}).metrics || {};
      const p75 = k => m[k] && m[k].percentiles && m[k].percentiles.p75 !== undefined ? Number(m[k].percentiles.p75) : null;
      return JSON.stringify({ lcp: p75("largest_contentful_paint"), inp: p75("interaction_to_next_paint"), cls: p75("cumulative_layout_shift") });
    }
    if (code === 404) return JSON.stringify({ nd: 1 });
    const msg = (body.error || {}).message || "";
    const fatal = (code === 400 || code === 403) && /api key|has not been used|disabled|permission|restrict|not authorized|blocked/i.test(msg);
    return JSON.stringify({ err: cruxErrorText(code, msg), fatal });
  });
}

function cruxErrorText(code, msg) {
  if (/not valid|API_KEY_INVALID/i.test(msg)) return "Google says this API key isn't valid. Copy it again from Google Cloud → APIs & Services → Credentials.";
  if (/has not been used|disabled|SERVICE_DISABLED/i.test(msg)) return "The Chrome UX Report API isn't enabled for this key's Google Cloud project. Enable it (APIs & Services → Library), wait a minute and try again.";
  if (/restrict|not authorized|blocked/i.test(msg)) return "This API key is restricted and can't call the Chrome UX Report API. Add that API to the key's restrictions.";
  if (code === 429) return "CrUX quota reached for now (150 requests per minute). Rebuild later.";
  return "CrUX API error " + code + (msg ? ": " + msg : "");
}

/** Google's Core Web Vitals thresholds (p75): Good / Needs improvement / Poor; the worst metric decides. */
function cwvRating(v) {
  const rate = (x, good, poor) => x === null || x === undefined || isNaN(x) ? null : x <= good ? 0 : x <= poor ? 1 : 2;
  const s = [rate(v.lcp, 2500, 4000), rate(v.inp, 200, 500), rate(v.cls, 0.1, 0.25)].filter(x => x !== null);
  return s.length ? ["Good", "Needs improvement", "Poor"][Math.max.apply(null, s)] : "";
}

function cwvText(v) {
  const parts = [];
  if (v.lcp !== null && v.lcp !== undefined) parts.push("LCP " + (v.lcp / 1000).toFixed(1) + " s");
  if (v.inp !== null && v.inp !== undefined) parts.push("INP " + Math.round(v.inp) + " ms");
  if (v.cls !== null && v.cls !== undefined) parts.push("CLS " + Number(v.cls).toFixed(2));
  return parts.join(" · ");
}

/**
 * Broken links, orphan pages and Core Web Vitals from the _Links and _Checks tabs (no requests).
 * Fills the new Page Audit columns, returns Site Health checks, extra page issues (by row) and the Broken Links rows.
 */
function analyzeLinksAndSpeed(data, site) {
  const out = { checks: [], pageIssues: {}, broken: [], hasLinks: false };
  const add = (category, check, status, result, priority, fix) => {
    const problem = status === "Fail" || status === "Warn";
    out.checks.push({ category, check, status, result: String(result), priority: problem ? priority : "", fix: problem ? fix : "" });
  };
  const issue = (i, name) => { (out.pageIssues[i] = out.pageIssues[i] || []).push(name); };
  const props = PropertiesService.getScriptProperties();
  const settings = JSON.parse(props.getProperty("SETTINGS") || "null") || getSettings();
  const skipped = JSON.parse(props.getProperty("CHECK_SKIPPED") || "{}");
  const key = props.getProperty("CRUX_API_KEY") || "";

  // Results of the post-crawl checks, by kind + normalized URL.
  const res = {};
  const cs = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.CHECKS_TAB);
  let extChecked = 0;
  if (cs && cs.getLastRow() > 1) cs.getRange(2, 1, cs.getLastRow() - 1, 3).getValues().forEach(r => {
    if (!r[2]) return;
    try { res[r[0] + "|" + normalizeForCompare(String(r[1]))] = JSON.parse(String(r[2])); } catch (e) {}
    if (r[0] === "ext") extChecked++;
  });

  // What the crawl already knows about each audited URL (and the page a redirect ends on).
  const byUrl = {}, srcRow = {};
  data.forEach((r, i) => {
    const k = normalizeForCompare(String(r[COL["URL"]]));
    const hops = Number(r[COL["Redirect Hops"]]) || 0;
    byUrl[k] = { init: r[COL["Initial Status"]], fin: r[COL["Final Status"]], hops, finalUrl: String(r[COL["Final URL"]] || r[COL["URL"]]) };
    const fk = normalizeForCompare(String(r[COL["Final URL"]] || r[COL["URL"]]));
    if (!byUrl[fk]) byUrl[fk] = { init: r[COL["Final Status"]], fin: r[COL["Final Status"]], hops: 0, finalUrl: String(r[COL["Final URL"]]) };
    if (srcRow[fk] === undefined || hops === 0) srcRow[fk] = i; // links were read from the final page
  });

  const NAMES = { 404: "404 Not Found", 410: "410 Gone", 401: "401 Login required", 403: "403 Forbidden", 429: "429 Too many requests", 999: "999 Blocks bots" };
  const codeText = c => NAMES[c] || (c >= 500 ? c + " Server error" : String(c));
  // -> [result, status text]; result = broken | redirect | unverified | ok | unchecked
  const classify = (url, internal) => {
    const k = normalizeForCompare(url);
    const a = internal ? byUrl[k] : null;
    if (a) {
      if (String(a.init) === "Error" || String(a.fin) === "Error") return ["broken", "Doesn't load (see the Page Audit tab)"];
      const fin = Number(a.fin);
      if (a.hops > 0) return fin >= 400 ? ["broken", a.init + " → " + codeText(fin)] : ["redirect", a.init + " → " + a.finalUrl];
      if (fin === 401 || fin === 403 || fin === 429) return ["unverified", codeText(fin)];
      if (fin >= 400) return ["broken", codeText(fin)];
      return ["ok"];
    }
    const r = res[(internal ? "int" : "ext") + "|" + k];
    if (!r) return ["unchecked"];
    if (r.e) return /dns|unknown host|address unavailable|unable to resolve|nodename/i.test(r.e)
      ? ["broken", "Doesn't load (domain not found)"] : ["unverified", "No answer: " + r.e.replace(/:\s*https?:\/\/\S+/, "").slice(0, 60)];
    const c = Number(r.c);
    if (c >= 300 && c < 400) return internal ? ["redirect", c + " → " + (r.l || "?")] : ["ok"];
    if (c === 404 || c === 410 || c >= 500) return ["broken", codeText(c)];
    if (c >= 400) return ["unverified", codeText(c)];
    return ["ok"];
  };
  const FIX = {
    "broken|Internal": "Point the link to a working page, or 301-redirect the missing URL to the closest match.",
    "broken|External": "The other site's page is gone: update the link or remove it.",
    "redirect|Internal": "Link straight to the final URL (saves a redirect for users and crawlers).",
    "unverified|Internal": "Open it in a browser to confirm: the server refused the automated check.",
    "unverified|External": "Open it in a browser to confirm: many sites block automated checks."
  };
  const LABEL = { broken: "Broken", redirect: "Redirect", unverified: "Couldn't verify" };
  const ORDER = { "broken|Internal": 0, "broken|External": 1, "redirect|Internal": 2, "unverified|Internal": 3, "unverified|External": 4 };

  const brokenOn = {}, inbound = {}, menuRows = {};
  const uniq = { "broken|Internal": {}, "broken|External": {}, "redirect|Internal": {}, "unverified|Internal": {}, "unverified|External": {} };
  let internalLinks = 0;
  const linkPages = new Set();
  out.hasLinks = forEachStoredLink((source, url, anchor, where) => {
    const p = parseUrl(url), sp = parseUrl(source);
    if (!p || !sp) return;
    linkPages.add(source);
    const internal = isInternal(bareHost(p.host), bareHost(sp.host));
    const type = internal ? "Internal" : "External";
    const sk = normalizeForCompare(source);
    if (internal) {
      internalLinks++;
      const a = byUrl[normalizeForCompare(url)];
      const tk = normalizeForCompare(a && a.hops > 0 ? a.finalUrl : url);
      if (tk !== sk) inbound[tk] = (inbound[tk] || 0) + 1;
    }
    const c = classify(url, internal);
    if (c[0] === "ok" || c[0] === "unchecked") return;
    const bucket = c[0] + "|" + type;
    const u = uniq[bucket];
    if (u) { const k = normalizeForCompare(url); if (!u[k]) u[k] = { url, status: c[1], pages: 0 }; u[k].pages++; }
    if (c[0] === "broken" && srcRow[sk] !== undefined) brokenOn[srcRow[sk]] = (brokenOn[srcRow[sk]] || 0) + 1;
    // A menu/footer link repeats on every page: one row with a page count instead of one row per page.
    const gk = where === "c" ? "" : bucket + "|" + normalizeForCompare(url);
    if (gk && menuRows[gk]) { menuRows[gk].row[1]++; return; }
    const entry = { o: ORDER[bucket], row: [source, 1, url, anchor, where === "c" ? "Content" : "Menu / header / footer / sidebar", type, c[1], LABEL[c[0]], FIX[bucket] || ""] };
    if (gk) menuRows[gk] = entry;
    out.broken.push(entry);
  });
  out.broken.sort((a, b) => a.o - b.o || b.row[1] - a.row[1]);
  out.broken = out.broken.slice(0, CONFIG.MAX_BROKEN_ROWS).map(x => x.row);

  // ---- Page columns ----
  const discovered = (() => { const qs = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.QUEUE_TAB); return qs ? qs.getLastRow() - 1 : data.length; })();
  const capped = discovered > data.length;
  const orphanOk = out.hasLinks && props.getProperty("MODE") === "auto" && settings.followLinks;
  const sitemap = site.sitemapUrls || null;
  const originOf = u => { const p = parseUrl(u); return p ? normalizeForCompare(p.protocol + "://" + p.host) : ""; };
  const cwvRan = Object.keys(res).some(k => k.indexOf("crux-") === 0);
  const cwvOff = !key ? "Not checked (add a free API key in Settings)" : !settings.checkCwv ? "Not checked (turned off in Settings)" : "Not checked";
  const orphans = [], cwvPages = { Good: 0, "Needs improvement": 0, Poor: 0, fallback: 0, none: 0 }, cwvBad = [];
  data.forEach((r, i) => {
    const page = Number(r[COL["Final Status"]]) === 200 && !isNonHtml(r);
    const setCwv = (status, v, from) => {
      r[COL["Core Web Vitals (mobile)"]] = status;
      r[COL["LCP p75 (s)"]] = v && v.lcp !== null && v.lcp !== undefined ? Math.round(v.lcp / 100) / 10 : "";
      r[COL["INP p75 (ms)"]] = v && v.inp !== null && v.inp !== undefined ? Math.round(v.inp) : "";
      r[COL["CLS p75"]] = v && v.cls !== null && v.cls !== undefined ? Math.round(Number(v.cls) * 100) / 100 : "";
      r[COL["CWV Data From"]] = from;
    };
    r[COL["Broken Links (on page)"]] = page ? (out.hasLinks ? brokenOn[i] || 0 : "N/A (run a new audit)") : "";
    if (brokenOn[i]) issue(i, "Broken links on page");
    const indexable = String(r[COL["Indexable"]]) === "Yes";
    // Orphan pages: indexable pages that no other audited page links to (the homepage is the entry point).
    if (!indexable) r[COL["Orphan Page"]] = page ? "N/A (not indexable)" : "";
    else if (!orphanOk) r[COL["Orphan Page"]] = out.hasLinks ? "N/A (needs a Domain audit with 'Follow links')" : "N/A (run a new audit)";
    else {
      const u = String(r[COL["Final URL"]] || r[COL["URL"]]);
      const k = normalizeForCompare(u);
      const n = inbound[k] || 0;
      const home = (parseUrl(u) || {}).path === "/";
      if (n || home) r[COL["Orphan Page"]] = home && !n ? "No (homepage)" : "No (" + n + " link" + (n === 1 ? "" : "s") + " from other pages)";
      else {
        const inSm = sitemap && sitemap.has(k);
        r[COL["Orphan Page"]] = (capped ? "Possible" : "Yes") + " – no internal links" + (inSm ? ", found only in the sitemap" : "") +
          (capped ? " (the crawl stopped at the page limit, so some links weren't seen)" : "");
        orphans.push(u + (inSm ? " (in sitemap)" : ""));
        if (!capped) issue(i, "Orphan page");
      }
    }
    // Core Web Vitals: the page's own real-user data, else the whole-site value of its origin.
    if (!indexable) { setCwv("", null, ""); return; }
    if (!cwvRan) { setCwv(cwvOff, null, ""); return; }
    const own = res["crux-url|" + normalizeForCompare(String(r[COL["Final URL"]] || r[COL["URL"]]))];
    const site0 = res["crux-origin|" + originOf(String(r[COL["Final URL"]] || r[COL["URL"]]))];
    if (own && !own.err && !own.nd && cwvRating(own)) {
      const st = cwvRating(own);
      setCwv(st, own, "This page (last 28 days)");
      cwvPages[st]++;
      if (st === "Poor") issue(i, "Poor Core Web Vitals");
      else if (st === "Needs improvement") issue(i, "Core Web Vitals need improvement");
      if (st !== "Good") cwvBad.push({ u: String(r[COL["Final URL"]] || r[COL["URL"]]), st, t: cwvText(own) });
    } else if (own && own.err) { setCwv("Not checked: " + own.err, null, ""); cwvPages.none++; }
    else if (site0 && !site0.err && !site0.nd && cwvRating(site0)) {
      setCwv("No page data · site: " + cwvRating(site0), site0, "Whole site (this page has too little Chrome traffic)");
      cwvPages.fallback++;
    } else { setCwv("No data (too little Chrome traffic)", null, ""); cwvPages.none++; }
  });

  // ---- Site Health checks ----
  const list = (map, max) => {
    const arr = Object.keys(map).map(k => map[k]).sort((a, b) => b.pages - a.pages);
    return arr.slice(0, max).map(x => x.url + " (" + x.status + (x.pages > 1 ? ", on " + x.pages + " pages" : "") + ")").join(", ") +
      (arr.length > max ? " … and " + (arr.length - max) + " more (see the " + CONFIG.BROKEN_TAB + " tab)" : "");
  };
  const count = b => Object.keys(uniq[b]).length;
  const pagesWith = b => Object.keys(uniq[b]).reduce((s, k) => s + uniq[b][k].pages, 0);
  if (!out.hasLinks) {
    add("Links", "Broken internal links", "Info", "No link data: run a new audit (links are collected while crawling)", "", "");
  } else {
    const bi = count("broken|Internal");
    const more = skipped.int ? " · " + skipped.int + " more internal link target/s not checked (limit " + CONFIG.MAX_INTERNAL_CHECKS + ")" : "";
    add("Links", "Broken internal links", bi === 0 ? "Pass" : bi < 10 ? "Warn" : "Fail",
      bi === 0 ? "None (" + internalLinks + " internal links on " + linkPages.size + " pages checked" + more + ")"
        : bi + " broken URL/s, linked " + pagesWith("broken|Internal") + " time/s" + more + ": " + list(uniq["broken|Internal"], 30),
      "High", "Fix or remove these links, or 301-redirect the missing pages to the closest working page. Every link is listed in the " + CONFIG.BROKEN_TAB + " tab with the page it's on.");
    if (skipped.extOff) add("Links", "Broken external links", "Info", "Not checked (turned off in Settings)", "", "");
    else {
      const be = count("broken|External");
      const moreExt = skipped.ext ? " · " + skipped.ext + " more not checked (limit " + CONFIG.MAX_EXTERNAL_CHECKS + ")" : "";
      add("Links", "Broken external links", be ? "Warn" : "Pass",
        be ? be + " of " + extChecked + " external URL/s checked are broken" + moreExt + ": " + list(uniq["broken|External"], 30)
          : "None (" + extChecked + " external URL/s checked" + moreExt + ")",
        "Medium", "Update or remove links to pages that no longer exist on other websites.");
    }
    const rd = count("redirect|Internal");
    add("Links", "Internal links to redirects", rd ? "Warn" : "Pass",
      rd ? rd + " linked URL/s redirect: " + list(uniq["redirect|Internal"], 30) : "None", "Low",
      "Change these links to point straight to the final URL.");
    const uv = count("unverified|Internal") + count("unverified|External");
    if (uv) {
      const both = Object.assign({}, uniq["unverified|Internal"], uniq["unverified|External"]);
      add("Links", "Links not verified", "Info", uv + " URL/s refused or didn't answer the check (often sites that block bots): " + list(both, 20), "", "");
    }
  }
  if (!orphanOk) {
    add("Links", "Orphan pages", "Info", out.hasLinks ? "Not checked: needs a Domain / Directory audit with 'Follow links found on pages' on"
      : "No link data: run a new audit", "", "");
  } else {
    add("Links", "Orphan pages", orphans.length ? (capped ? "Info" : "Warn") : "Pass",
      orphans.length ? (capped ? "Possible orphans (the crawl stopped at the page limit, so some links weren't seen). " : "") +
        orphans.length + " indexable page/s that no other page links to: " + orphans.slice(0, 50).join(", ") +
        (orphans.length > 50 ? " … and " + (orphans.length - 50) + " more (filter the Orphan Page column)" : "")
        : "None: every indexable page is linked from at least one other page",
      "Medium", "Link to these pages from related pages, categories or the menu. If a page isn't needed any more, redirect or noindex it and remove it from the sitemap.");
  }
  if (!cwvRan) {
    add("Performance", "Core Web Vitals (whole site)", "Info", !key ? "Not checked: real-user data needs a free Google API key (Settings → Core Web Vitals)"
      : !settings.checkCwv ? "Not checked (turned off in Settings)" : "Not checked", "", "");
  } else {
    const o = res["crux-origin|" + normalizeForCompare((site.host ? "https://" + site.host : ""))] ||
      res[Object.keys(res).find(k => k.indexOf("crux-origin|") === 0)];
    const st = o && !o.err && !o.nd ? cwvRating(o) : "";
    add("Performance", "Core Web Vitals (whole site)", st === "Good" ? "Pass" : st === "Poor" ? "Fail" : st ? "Warn" : "Info",
      st ? st + ": " + cwvText(o) + " (mobile, real Chrome users, last 28 days)" : o && o.err ? "Couldn't read Core Web Vitals: " + o.err
        : "Not enough Chrome traffic for whole-site data",
      "Medium", "Improve the worst metric: LCP (optimise the hero image and server response), INP (less JavaScript), CLS (reserve space for images, ads and fonts).");
    const ownN = cwvPages.Good + cwvPages["Needs improvement"] + cwvPages.Poor;
    const bad = cwvPages.Poor + cwvPages["Needs improvement"];
    // Information only: the pages themselves carry the issue and the score, so the site penalty doesn't count them twice.
    add("Performance", "Core Web Vitals (pages)", "Info",
      ownN + " page/s with their own data: " + cwvPages.Good + " good, " + cwvPages["Needs improvement"] + " need improvement, " + cwvPages.Poor + " poor · " +
        cwvPages.fallback + " use the whole-site value (too little traffic) · " + cwvPages.none + " without data" +
        (bad ? ": " + cwvBad.sort((a, b) => (b.st === "Poor") - (a.st === "Poor")).slice(0, 30).map(x => x.u + " (" + x.st + ": " + x.t + ")").join(", ") : ""),
      "Medium", "Start with the Poor pages: the Page Audit columns show which metric fails.");
  }
  return out;
}

/** The Broken Links tab: one row per link that is broken, redirects or couldn't be verified, with the page it's on. */
function writeBrokenLinks(rows, hasLinks) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(CONFIG.BROKEN_TAB);
  if (!hasLinks && !sheet) return;
  sheet = sheet || ss.insertSheet(CONFIG.BROKEN_TAB);
  const oldFilter = sheet.getFilter();
  if (oldFilter) oldFilter.remove();
  sheet.clear();
  sheet.clearConditionalFormatRules();
  // "Pages" > 1 = the same menu/footer link on that many pages (the first one is shown).
  const header = ["Found On Page", "Pages", "Link URL", "Anchor Text", "Where", "Type", "Status", "Result", "How to Fix"];
  sheet.getRange(1, 1, 1, header.length).setValues([header]).setFontWeight("bold").setBackground("#1f3864").setFontColor("#ffffff");
  sheet.setFrozenRows(1);
  if (!rows.length) {
    sheet.getRange(2, 1).setValue(hasLinks ? "No broken links, links to redirects or unverified links found. 🎉" : "No link data: run a new audit.");
  } else {
    sheet.getRange(2, 1, rows.length, header.length).setValues(rows.map(r => r.map(sanitize)))
      .setWrapStrategy(SpreadsheetApp.WrapStrategy.CLIP).setVerticalAlignment("top");
    const res = sheet.getRange(2, 8, rows.length, 1);
    const rule = () => SpreadsheetApp.newConditionalFormatRule();
    sheet.setConditionalFormatRules([
      rule().whenTextEqualTo("Broken").setBackground("#f4cccc").setRanges([res]).build(),
      rule().whenTextEqualTo("Redirect").setBackground("#fff2cc").setRanges([res]).build(),
      rule().whenTextEqualTo("Couldn't verify").setBackground("#eeeeee").setRanges([res]).build()
    ]);
    try { sheet.getRange(1, 1, rows.length + 1, header.length).createFilter(); } catch (e) {}
  }
  [320, 60, 360, 200, 170, 80, 230, 110, 420].forEach((w, i) => sheet.setColumnWidth(i + 1, w));
}

const DEFAULT_SETTINGS = { mode: "Polite", maxPages: CONFIG.MAX_PAGES, followLinks: true, includeQuery: false, respectRobots: true, identifyAs: "Bot",
  checkExternal: true, checkCwv: true };

/** Cleans a settings object: valid mode, page limit 1–MAX_PAGES, booleans, and the user agent it implies. */
function normalizeSettings(s) {
  const v = Object.assign({}, DEFAULT_SETTINGS, s || {});
  const n = Math.floor(Number(v.maxPages));
  const maxPages = isNaN(n) || v.maxPages === "" || v.maxPages == null ? CONFIG.MAX_PAGES : Math.max(1, Math.min(CONFIG.MAX_PAGES, n));
  const identifyAs = v.identifyAs === "Browser" ? "Browser" : "Bot";
  return {
    mode: v.mode === "Fast" ? "Fast" : "Polite",
    maxPages,
    followLinks: v.followLinks !== false && v.followLinks !== "false",
    includeQuery: v.includeQuery === true || v.includeQuery === "true",
    respectRobots: v.respectRobots !== false && v.respectRobots !== "false",
    checkExternal: v.checkExternal !== false && v.checkExternal !== "false",
    checkCwv: v.checkCwv !== false && v.checkCwv !== "false",
    identifyAs,
    userAgent: identifyAs === "Browser" ? CONFIG.USER_AGENT : CONFIG.BOT_UA
  };
}

function getSettings() {
  let saved = {};
  try { saved = JSON.parse(PropertiesService.getScriptProperties().getProperty("USER_SETTINGS") || "{}"); } catch (e) {}
  return normalizeSettings(saved);
}

/** Called by the Start sidebar whenever a setting changes. */
function saveSettings(s) {
  const n = normalizeSettings(s);
  const stored = Object.assign({}, n);
  delete stored.userAgent;
  PropertiesService.getScriptProperties().setProperty("USER_SETTINGS", JSON.stringify(stored));
  return n;
}

const FILE_EXT_RE = /\.(jpe?g|png|gif|webp|avif|svg|ico|bmp|css|js|json|xml|txt|csv|pdf|zip|rar|7z|gz|docx?|xlsx?|pptx?|mp4|m4v|mov|webm|mp3|wav|woff2?|ttf|eot|apk|exe|dmg)$/i;
const NON_PAGE_PATH_RE = /\/(wp-json|wp-admin|wp-login\.php|xmlrpc\.php|feed|cdn-cgi|trackback|comments\/feed)(\/|$)/i;

/**
 * Folder to stay inside, from a directory URL: "/blog/" or "/blog" -> "/blog"; "/blog/post.html" -> "/blog".
 * Returns "" for the domain root (no limit).
 */
function directoryScope(path) {
  let s = String(path || "/").toLowerCase();
  if (/\/[^\/]+\.[a-z0-9]{2,5}$/i.test(s)) s = s.replace(/\/[^\/]*$/, "/"); // a file: use its folder
  s = s.replace(/\/+$/, "");
  return s;
}

/** Normalizes a found URL into a queue URL on the audited host (and folder), or "" when it shouldn't be crawled. */
function toQueueUrl(u, ctx) {
  const p = parseUrl(String(u).replace(/#.*$/, ""));
  if (!p || bareHost(p.host) !== ctx.root) return "";
  if (ctx.scope) {
    const path = p.path.toLowerCase();
    if (path !== ctx.scope && path !== ctx.scope + "/" && path.indexOf(ctx.scope + "/") !== 0) return "";
  }
  if (p.query && !ctx.settings.includeQuery) return "";
  if (FILE_EXT_RE.test(p.path) || NON_PAGE_PATH_RE.test(p.path) || isUtilityLink(u)) return "";
  return ctx.protocol + "://" + ctx.host + p.path + (ctx.settings.includeQuery ? p.query : "");
}

/** Dedupe key: host without www, path without trailing slash, query; lower-case. */
function queueKey(u) {
  const p = parseUrl(u);
  return p ? (bareHost(p.host) + p.path.replace(/\/+$/, "") + p.query).toLowerCase() : String(u).toLowerCase();
}

function pathOf(u) {
  const p = parseUrl(u);
  return p ? p.path + p.query : "/";
}

/** Reads the first valid sitemap and expands sitemap indexes (child files fetched 10 at a time). */
function discoverSitemapUrls(candidates, onStep) {
  const out = { urls: [], files: 0, found: "" };
  for (let c = 0; c < candidates.length; c++) {
    const r = fetchOne(candidates[c], true);
    out.files++;
    if (r.error || r.response.getResponseCode() !== 200) continue;
    const xml = r.response.getContentText();
    if (!/<(urlset|sitemapindex)\b/i.test(xml)) continue;
    out.found = candidates[c];
    const todo = [xml], seenFiles = new Set([candidates[c]]);
    while (todo.length && out.urls.length < CONFIG.MAX_QUEUE) {
      const doc = todo.shift();
      if (/<sitemapindex\b/i.test(doc)) {
        const kids = extractLocs(doc).filter(u => !/\.gz(\?|$)/i.test(u) && !seenFiles.has(u));
        kids.forEach(u => seenFiles.add(u));
        for (let i = 0; i < kids.length && out.files < CONFIG.MAX_DISCOVERY_SITEMAPS; i += 10) {
          const group = kids.slice(i, i + Math.min(10, CONFIG.MAX_DISCOVERY_SITEMAPS - out.files));
          if (onStep) onStep("Reading sitemaps: " + out.files + " files, " + out.urls.length + " URLs so far");
          fetchMany(group, true).forEach(cr => {
            out.files++;
            if (cr.response && cr.response.getResponseCode() === 200) todo.push(cr.response.getContentText());
          });
        }
      } else {
        extractUrlEntries(doc).forEach(e => { if (out.urls.length < CONFIG.MAX_QUEUE) out.urls.push(e.loc); });
      }
    }
    break;
  }
  return out;
}

function emptyAgg() {
  return { audited: 0, ok: 0, redirected: 0, c4: 0, c5: 0, err: 0, indexable: 0, scoreSum: 0, listings: 0, low: 0, issues: {} };
}

/** Adds freshly audited rows to the running totals (provisional: duplicates and Site Health come at the end). */
function updateAgg(agg, rows) {
  rows.forEach(r => {
    agg.audited++;
    const st = r[COL["Final Status"]], code = Number(st);
    if (code === 200) agg.ok++;
    else if (String(st) === "Error") agg.err++;
    else if (code >= 500) agg.c5++;
    else if (code >= 400) agg.c4++;
    if (Number(r[COL["Redirect Hops"]]) > 0) agg.redirected++;
    if (String(r[COL["Indexable"]]) === "Yes") agg.indexable++;
    const list = unique(String(r[COL["_BaseIssues"]] || "").split("; ").filter(Boolean));
    const counts = { Critical: 0, High: 0, Medium: 0, Low: 0 };
    list.forEach(i => { agg.issues[i] = (agg.issues[i] || 0) + 1; counts[issuePriority(i)]++; });
    const broken = list.indexOf("Page fetch failed") !== -1 || list.indexOf("Page not returning 200") !== -1;
    if (isNonHtml(r)) { agg.nonHtml = (agg.nonHtml || 0) + 1; return; }
    agg.scoreSum += broken ? 0 : Math.max(0, 100 - Object.keys(counts).reduce((p, k) => p + counts[k] * PRIORITY_WEIGHT[k], 0));
    if (/in main grid/.test(String(r[COL["Products Listed"]]))) agg.listings++;
    if (list.indexOf("Low product count") !== -1) agg.low++;
  });
}

/**
 * Audits one URL. preChain (optional) is a redirect chain already resolved by resolveChainsParallel.
 * The returned row also carries .discovered: internal followable links found on the page (for auto-crawl).
 */
function analyzeUrl(item, firstResult, preChain) {
  const d = { "URL": item.url };
  const issues = [];
  const chain = preChain || followRedirectChain(item.url, firstResult);

  // Every chain entry is a redirect when the chain ended in an error; otherwise the last one is the final page.
  const redirects = chain.error ? chain.chain.length : chain.chain.length - 1;
  let chainText = chain.chain.map(c => c.code + " " + c.url).join(" → ");
  if (chain.error) chainText += (chainText ? " → " : "") + "Error: " + chain.error;
  d["Initial Status"] = chain.chain.length ? chain.chain[0].code : "Error";
  d["Redirect Hops"] = redirects;
  d["Redirect Chain"] = chainText && (redirects || chain.error) ? chainText : "None";
  d["Final URL"] = chain.finalUrl;
  if (redirects >= 2) issues.push("Redirect chain (2+ hops)");
  else if (redirects === 1) issues.push("URL redirects");

  // Indexability is judged for the URL that was entered: a redirecting URL is never indexed itself,
  // so it is "No" even when the page it ends on is fine (that page's verdict is added for context).
  const indexVerdict = reasons => {
    if (!redirects) return reasons.length ? "No – " + reasons.join(", ") : "Yes";
    return "No – redirects (" + chain.chain[0].code + ") to Final URL; Final URL " +
      (reasons.length ? "not indexable: " + reasons.join(", ") : "is indexable");
  };

  if (chain.error) {
    d["Final Status"] = "Error";
    d["Indexable"] = "No – fetch failed";
    issues.push("Page fetch failed");
    d["_BaseIssues"] = issues.join("; ");
    return buildRow(d);
  }

  const res = chain.response;
  const status = res.getResponseCode();
  const headers = res.getAllHeaders();
  const contentType = getHeader(headers, "Content-Type");
  const xRobots = getHeader(headers, "X-Robots-Tag");
  const compression = getHeader(headers, "Content-Encoding");
  const sizeKB = round1(res.getContent().length / 1024);
  d["Final Status"] = status;
  d["Content-Type"] = contentType || "Not set";
  d["Compression"] = compression || "None reported";
  d["Cache-Control"] = getHeader(headers, "Cache-Control") || "Not set";
  d["X-Robots-Tag"] = xRobots || "Not set";
  d["HTML Size (KB)"] = sizeKB;

  if (status !== 200) {
    d["Indexable"] = indexVerdict(["status " + status]);
    issues.push("Page not returning 200");
    d["_BaseIssues"] = issues.join("; ");
    return buildRow(d);
  }
  if (contentType && !/html|xml/i.test(contentType)) {
    // Images, PDFs, files: no page-level SEO to check, so no "Yes" and no page score.
    const type = contentType.split(";")[0].trim();
    d["Indexable"] = redirects ? indexVerdict(["not an HTML page (" + type + ")"]) : "N/A – not an HTML page (" + type + ")";
    d["Meta Title"] = "N/A (non-HTML)";
    d["_BaseIssues"] = issues.join("; ");
    return buildRow(d);
  }

  const pageUrl = chain.finalUrl;
  const pageInfo = parseUrl(pageUrl) || { protocol: "https", host: "", path: "/", query: "" };
  const pageRoot = bareHost(pageInfo.host);

  const html = res.getContentText().replace(/<!--[\s\S]*?-->/g, "");
  const markup = removeBlocks(html, ["script", "style", "noscript", "template", "svg"]);
  const headHtml = sectionOf(markup, "head") || markup;
  const bodyHtml = sectionOf(markup, "body") || markup;
  const rawHead = sectionOf(html, "head");
  const contentHtml = removeBlocks(bodyHtml, ["iframe", "select"]);

  const visibleText = cleanText(contentHtml);
  const words = visibleText ? visibleText.split(/\s+/).filter(w => /[\p{L}\p{N}]/u.test(w)) : [];
  const wordCount = words.length;

  // ---------- <head> ----------
  const metas = getTags(markup, "meta").map(parseAttributes);
  const meta = name => {
    const n = name.toLowerCase();
    const m = metas.find(a => a.content !== undefined &&
      [a.name, a.property, a.itemprop].some(x => (x || "").toLowerCase() === n));
    return m ? cleanSpaces(m.content) : "";
  };

  const titles = getElements(headHtml, "title").map(e => cleanText(e.inner));
  const title = titles[0] || "";
  d["Meta Title"] = title || "Missing";
  d["Title Length"] = title.length;
  d["Title Tag Count"] = titles.length;
  if (!title) issues.push("Missing meta title");
  else if (title.length < CONFIG.TITLE_MIN || title.length > CONFIG.TITLE_MAX) issues.push("Title length out of range");
  if (titles.length > 1) issues.push("Multiple title tags");

  const desc = meta("description");
  d["Meta Description"] = desc || "Missing";
  d["Description Length"] = desc.length;
  if (!desc) issues.push("Missing meta description");
  else if (desc.length < CONFIG.DESC_MIN || desc.length > CONFIG.DESC_MAX) issues.push("Description length out of range");

  const links = getTags(markup, "link").map(parseAttributes);
  const baseTag = getTags(headHtml, "base").map(parseAttributes).find(a => a.href);
  const baseUrl = baseTag ? (resolveUrl(baseTag.href, pageUrl) || pageUrl) : pageUrl;

  const canonHrefs = unique(links.filter(a => relHas(a, "canonical") && a.href).map(a => a.href.trim()));
  const headerCanon = (getHeader(headers, "Link").match(/<([^>]+)>\s*;[^,]*rel=["']?canonical/i) || [])[1];
  if (!canonHrefs.length && headerCanon) canonHrefs.push(headerCanon);
  let canonUrl = "";
  if (!canonHrefs.length) {
    d["Canonical Status"] = "Missing";
    issues.push("Missing canonical");
  } else {
    canonUrl = resolveUrl(canonHrefs[0], baseUrl) || canonHrefs[0];
    const isSelf = sameUrl(canonUrl, pageUrl);
    const isRelative = !/^https?:\/\//i.test(canonHrefs[0]);
    let st = canonHrefs.length > 1 ? "Multiple (" + canonHrefs.length + ")" : isSelf ? "Self" : "Points elsewhere";
    if (isRelative) st += " · relative";
    d["Canonical Status"] = st;
    if (canonHrefs.length > 1) issues.push("Multiple canonical tags");
    if (!isSelf) issues.push("Canonical points to another URL");
    if (isRelative) issues.push("Relative canonical URL");
  }
  d["Canonical URL"] = canonHrefs.length ? canonHrefs.join(", ") : "Missing";

  const robotsMetas = metas.filter(a => /^(robots|googlebot)$/i.test(a.name || "") && a.content);
  d["Meta Robots"] = robotsMetas.length ? robotsMetas.map(a => a.name.toLowerCase() + ": " + a.content).join(" | ") : "Not specified";
  const notIndexable = [];
  if (robotsMetas.some(a => /\b(noindex|none)\b/i.test(a.content))) notIndexable.push("noindex (meta)");
  if (/\b(noindex|none)\b/i.test(xRobots)) notIndexable.push("noindex (header)");
  if (notIndexable.length) issues.push("Page is noindex");
  if (canonUrl && !sameUrl(canonUrl, pageUrl)) notIndexable.push("canonicalised elsewhere");
  d["Indexable"] = indexVerdict(notIndexable);

  const htmlTag = (html.match(/<html\b[^>]*>/i) || [""])[0];
  const lang = htmlTag ? (parseAttributes(htmlTag).lang || "") : "";
  d["HTML Lang"] = lang || "Missing";
  if (!lang) issues.push("Missing html lang attribute");

  const hreflangs = links.filter(a => relHas(a, "alternate") && a.hreflang).map(a => a.hreflang);
  d["Hreflang Tags"] = hreflangs.length ? hreflangs.length + " (" + unique(hreflangs).slice(0, 10).join(", ") + ")" : "None";

  const viewport = meta("viewport");
  d["Viewport"] = viewport || "Missing";
  if (!viewport) issues.push("Missing viewport meta tag");

  const ogMissing = ["og:title", "og:description", "og:image", "og:url"].filter(p => !meta(p));
  d["Open Graph"] = ogMissing.length ? "Missing: " + ogMissing.join(", ") : "All present";
  if (ogMissing.length) issues.push("Incomplete Open Graph tags");
  d["Twitter Card"] = meta("twitter:card") || "Missing";

  // ---------- Headings ----------
  const headings = [];
  const hRe = /<h([1-6])\b[^>]*>([\s\S]*?)<\/h\1\s*>/gi;
  let hm;
  while ((hm = hRe.exec(contentHtml)) !== null) headings.push({ level: Number(hm[1]), text: cleanText(hm[2]) });
  const h1s = headings.filter(h => h.level === 1);
  d["H1 Count"] = h1s.length;
  d["H1 Text"] = h1s.length ? h1s.map(h => h.text || "(empty)").join(" | ") : "Missing";
  // Main content only: menus, header, footer, sidebars, hidden panels, forms, TOC and related-post blocks removed
  // (nesting-aware, so a hidden login panel or mega menu can't leak in). Product grids are removed for headings/links.
  const mainHtml = mainContentHtml(contentHtml);
  const mainNoGrid = removeElementsWhere(mainHtml, isProductGrid);
  const headingList = level => {
    const texts = getElements(mainNoGrid, "h" + level).map(e => cleanText(e.inner)).filter(Boolean);
    return texts.length ? texts.join(", ") : "None";
  };
  d["H2 Tags (body)"] = headingList(2);
  d["H3 Tags (body)"] = headingList(3);
  if (!h1s.some(h => h.text)) issues.push("Missing H1");
  if (h1s.length > 1) issues.push("Multiple H1 tags");
  const skips = [];
  let prev = 0;
  headings.forEach(h => { if (prev && h.level > prev + 1) skips.push("H" + prev + "→H" + h.level); prev = h.level; });
  d["Heading Hierarchy"] = skips.length ? "Skips: " + unique(skips).slice(0, 5).join(", ") : "OK";
  if (skips.length) issues.push("Heading levels skipped");

  // ---------- Content ----------
  d["Word Count"] = wordCount;
  d["Text/HTML Ratio %"] = html.length ? round1(visibleText.length / html.length * 100) : 0;
  if (wordCount < CONFIG.THIN_CONTENT_WORDS) issues.push("Thin content");

  // ---------- Images ----------
  const imgs = getTags(contentHtml, "img").map(parseAttributes);
  const modernRe = /\.(webp|avif)(\?|$|\s|,)/i;
  let modern = 0;
  getElements(contentHtml, "picture").forEach(p => {
    if (/type=["']image\/(webp|avif)/i.test(p.inner) || modernRe.test(p.inner)) modern += getTags(p.inner, "img").length;
  });
  getTags(removeBlocks(contentHtml, ["picture"]), "img").map(parseAttributes).forEach(a => {
    if (modernRe.test([a.src, a.srcset, a["data-src"], a["data-srcset"]].join(" "))) modern++;
  });
  // Alt-text check covers main content only (logos/icons in header, footer, menu and sidebar are skipped).
  const missingAltImgs = getTags(mainHtml, "img").map(parseAttributes).filter(a => a.alt === undefined);
  const missingAlt = missingAltImgs.length;
  // An image can't shift the layout when its size is known before it loads: width + height attributes, an inline
  // style with both sizes or an aspect-ratio, or CSS classes that fix both (w-full + h-full filling a sized box, aspect-*).
  // Width only with h-auto still counts as missing: the height is unknown until the file arrives.
  const sized = a => {
    if (a.width && a.height) return true;
    const st = a.style || "";
    if (/aspect-ratio/i.test(st) || (/(^|;)\s*width\s*:/i.test(st) && /(^|;)\s*height\s*:/i.test(st))) return true;
    if (a["data-nimg"] === "fill") return true; // Next.js <Image fill>: absolutely positioned in a sized box
    const c = " " + (a.class || "") + " ";
    if (/\s(aspect-(square|video|\[[^\]]+\]|\d+\/\d+)|ratio)\s/.test(c)) return true;
    const w = /\s(w|size)-(full|screen|\d+(\.\d+)?|\[[^\]]+\]|px)\s/.test(c), h = /\s(h|size)-(full|screen|\d+(\.\d+)?|\[[^\]]+\]|px)\s/.test(c);
    return w && h;
  };
  const unsizedImgs = imgs.filter(a => !sized(a));
  const missingDims = unsizedImgs.length;
  d["Images"] = imgs.length;
  // Lazy-loaded images often keep a placeholder in src and the real file in data-src.
  const missingAltUrls = unique(missingAltImgs.map(a => {
    const src = [a.src, a["data-src"], a["data-lazy-src"]].find(s => s && !/^data:/i.test(s.trim()));
    return src ? resolveUrl(src, baseUrl) || src : "(inline/embedded image)";
  }));
  d["Images Missing Alt (URLs)"] = missingAltUrls.length ? missingAltUrls.join(", ") : "None";
  d["Images Empty Alt"] = imgs.filter(a => a.alt !== undefined && !a.alt.trim()).length;
  d["Images Missing Dimensions"] = missingDims;
  d["Images Missing Width/Height (URLs)"] = missingDims ? unique(unsizedImgs.map(a => {
    const src = [a.src, a["data-src"], a["data-lazy-src"]].find(s => s && !/^data:/i.test(s.trim()));
    return src ? resolveUrl(src, baseUrl) || src : "(inline/embedded image)";
  })).join(", ") : "None";
  d["Images Lazy-Loaded"] = imgs.filter(a => (a.loading || "").toLowerCase() === "lazy" || a["data-src"] ||
    a["data-lazy-src"] || /\blazy/i.test(a.class || "")).length;
  d["Images WebP/AVIF"] = modern;
  if (missingAlt) issues.push("Images missing alt text");
  if (missingDims) issues.push("Images missing width/height");
  if (imgs.length >= 3 && !modern) issues.push("No WebP/AVIF images");

  // ---------- Links (whole page) ----------
  let total = 0, internal = 0, external = 0, nofollow = 0, generic = 0, blankNoOpener = 0, insecure = 0, tel = 0, mail = 0;
  // Links to follow for auto-discovery: every internal link on the page (menus included), unless nofollow.
  const pageNofollow = robotsMetas.some(a => /\b(nofollow|none)\b/i.test(a.content));
  const discovered = [];
  const pageLinks = []; // every link (menus and footers too) for the broken-link and orphan checks
  getElements(contentHtml, "a").forEach(a => {
    const href = (a.attrs.href || "").trim();
    if (/^tel:/i.test(href)) { tel++; return; }
    if (/^mailto:/i.test(href)) { mail++; return; }
    if (!href || href.charAt(0) === "#" || /^javascript:/i.test(href)) return;
    const full = resolveUrl(href, baseUrl);
    const p = full && parseUrl(full);
    if (!p) return;
    total++;
    if (!isUtilityLink(full)) {
      let anchor = cleanText(a.inner);
      if (!anchor) {
        const img = getTags(a.inner, "img").map(parseAttributes)[0];
        anchor = img ? "[image: " + (img.alt && img.alt.trim() ? cleanSpaces(img.alt) : "no alt") + "]" : "";
      }
      pageLinks.push({ u: full.replace(/#.*$/, ""), a: anchor });
    }
    if (isInternal(bareHost(p.host), pageRoot)) {
      internal++;
      if (pageInfo.protocol === "https" && p.protocol === "http") insecure++;
    } else {
      external++;
    }
    const rel = (a.attrs.rel || "").toLowerCase();
    if (/nofollow|sponsored|ugc/.test(rel)) nofollow++;
    else if (!pageNofollow && isInternal(bareHost(p.host), pageRoot)) discovered.push(full);
    if ((a.attrs.target || "").toLowerCase() === "_blank" && !/noopener|noreferrer/.test(rel)) blankNoOpener++;
    const text = cleanText(a.inner).toLowerCase().replace(/[^\p{L}\p{N}\s]/gu, "").trim();
    if (text && GENERIC_ANCHORS.indexOf(text) !== -1) generic++;
  });
  d["Total Links"] = total;
  d["Internal Links"] = internal;
  d["External Links"] = external;
  d["Nofollow/Sponsored/UGC"] = nofollow;
  d["Generic Anchors"] = generic;
  d["_blank w/o noopener"] = blankNoOpener;
  d["Internal http:// Links"] = insecure;
  if (generic) issues.push("Generic anchor text");
  if (blankNoOpener) issues.push("target=_blank without noopener");
  if (insecure) issues.push("Internal links using http://");

  const cLinks = extractContentLinks(mainNoGrid, baseUrl, pageUrl, pageRoot);
  d["Inlink URLs (content)"] = cLinks.inlinkUrls.join(", ");
  d["Inlink Anchor Texts (content)"] = cLinks.inlinkAnchors.join(", ");
  d["Outlink URLs (content)"] = cLinks.outlinkUrls.join(", ");
  d["Outlink Anchor Texts (content)"] = cLinks.outlinkAnchors.join(", ");
  if (cLinks.splitAnchors) issues.push("Split anchor links");
  const linkStore = packPageLinks(pageLinks, cLinks, pageUrl, pageInfo);

  // ---------- Performance proxies ----------
  const isExec = a => { const t = (a.type || "").toLowerCase(); return !t || /javascript|ecmascript|module/.test(t); };
  const scripts = getElements(html, "script").filter(s => isExec(s.attrs));
  const blockingScripts = getElements(rawHead, "script").filter(s => isExec(s.attrs) && s.attrs.src &&
    s.attrs.async === undefined && s.attrs.defer === undefined && (s.attrs.type || "").toLowerCase() !== "module");
  const renderBlocking = blockingScripts.length;
  const blockingNames = blockingScripts.map(s => {
    const full = resolveUrl(s.attrs.src, baseUrl);
    const p = full && parseUrl(full);
    if (!p) return s.attrs.src;
    const file = p.path.split("/").filter(Boolean).pop() || p.path;
    return file + " (" + bareHost(p.host) + ")";
  });
  const inlineBytes = scripts.filter(s => !s.attrs.src).reduce((sum, s) => sum + s.inner.length, 0) +
    getElements(html, "style").reduce((sum, s) => sum + s.inner.length, 0);

  // Third-party domains in order of appearance, with the resource hints (from <link> tags and the Link header) used for each.
  const HINTS = ["preconnect", "dns-prefetch", "prefetch", "preload", "modulepreload"];
  const domainHints = {};
  const domainOrder = [];
  const noteDomain = (u, hint) => {
    const full = resolveUrl(u, baseUrl);
    const p = full && parseUrl(full);
    const h = p ? bareHost(p.host) : "";
    if (!h || isInternal(h, pageRoot)) return;
    if (!domainHints[h]) { domainHints[h] = []; domainOrder.push(h); }
    if (hint && domainHints[h].indexOf(hint) === -1) domainHints[h].push(hint);
  };
  scripts.filter(s => s.attrs.src).forEach(s => noteDomain(s.attrs.src));
  links.forEach(a => {
    if (!a.href) return;
    const rels = (a.rel || "").toLowerCase().split(/\s+/);
    const hints = HINTS.filter(x => rels.indexOf(x) !== -1);
    if (hints.length) hints.forEach(x => noteDomain(a.href, x));
    else if (rels.indexOf("stylesheet") !== -1 || rels.some(r => /icon/.test(r))) noteDomain(a.href);
  });
  getHeader(headers, "Link").split(/,(?=\s*<)/).forEach(part => {
    const m = part.match(/<([^>]+)>[^]*?rel=["']?([^"';]+)/i);
    if (!m) return;
    m[2].toLowerCase().split(/\s+/).filter(x => HINTS.indexOf(x) !== -1).forEach(x => noteDomain(m[1], x));
  });
  imgs.forEach(a => { if (a.src) noteDomain(a.src); });
  getTags(html, "iframe").map(parseAttributes).forEach(a => { if (a.src) noteDomain(a.src); });
  const thirdParty = domainOrder;
  const domCount = (markup.match(/<[a-z][a-z0-9-]*[\s>\/]/gi) || []).length;

  // Performance Risk: points from 6 checks; the reasons are written into the cell.
  let risk = 0;
  const why = [];
  if (sizeKB > 1024) { risk += 2; why.push("HTML " + sizeKB + " KB > 1 MB (+2)"); }
  else if (sizeKB > 300) { risk += 1; why.push("HTML " + sizeKB + " KB > 300 KB (+1)"); }
  if (renderBlocking >= 3) { risk++; why.push(renderBlocking + " render-blocking scripts ≥ 3 (+1)"); }
  if (scripts.length > 25) { risk++; why.push(scripts.length + " scripts > 25 (+1)"); }
  if (thirdParty.length > 10) { risk++; why.push(thirdParty.length + " third-party domains > 10 (+1)"); }
  if (domCount > 1500) { risk++; why.push(domCount + " HTML elements > 1,500 (+1)"); }
  const perfRisk = risk >= 4 ? "High" : risk >= 2 ? "Medium" : "Low";
  d["Scripts"] = scripts.length;
  d["Render-Blocking Scripts"] = renderBlocking ? renderBlocking + ": " + blockingNames.slice(0, 15).join(", ") : "None";
  d["Stylesheets"] = links.filter(a => relHas(a, "stylesheet")).length;
  d["Inline JS+CSS (KB)"] = round1(inlineBytes / 1024);
  d["Third-Party Domains"] = thirdParty.length ? thirdParty.length + ": " + thirdParty.slice(0, 15)
    .map(h => h + (domainHints[h].length ? " (" + domainHints[h].join(", ") + ")" : "")).join(", ") : 0;
  d["DOM Elements (approx)"] = domCount;
  d["Performance Risk"] = perfRisk + " – " + risk + " pt" + (risk === 1 ? "" : "s") +
    (why.length ? ": " + why.join("; ") : " (all 6 checks within limits)") + ". Scale: 0–1 Low, 2–3 Medium, 4+ High";
  if (perfRisk === "High") issues.push("High performance risk");
  if (renderBlocking >= 3) issues.push("Render-blocking scripts in head");

  // ---------- Tech & tracking ----------
  d["CMS / Platform"] = detectPlatform(html, meta("generator"));
  const tracking = detectTracking(html);
  d["Tracking Detected"] = tracking.list.length ? tracking.list.join(", ") : "None found";
  if (!tracking.hasAnalytics) issues.push("No analytics detected");
  if (tracking.legacyUA) issues.push("Legacy Universal Analytics code");

  const appShell = /<div[^>]+id=["'](root|app|__next|__nuxt|svelte)["'][^>]*>\s*<\/div>/i.test(html);
  const jsRisk = wordCount < 50 && (appShell || scripts.length > 5) ? "High" :
    wordCount < 150 && (appShell || inlineBytes > 100 * 1024) ? "Medium" : "Low";
  d["JS-Rendering Risk"] = jsRisk + " – " + wordCount + " words in raw HTML, " + scripts.length + " scripts" +
    (appShell ? ", empty app container (#root/#app)" : "") + ". Rule: High = under 50 words + app shell or 5+ scripts; " +
    "Medium = under 150 words + app shell or 100 KB+ inline code";
  if (jsRisk === "High") issues.push("Content may depend on JavaScript");

  // ---------- Structured data ----------
  const ld = extractJsonLd(html);
  const microTypes = [];
  const itRe = /itemtype=["']https?:\/\/schema\.org\/([A-Za-z]+)["']/gi;
  let im;
  while ((im = itRe.exec(markup)) !== null) microTypes.push(im[1] + " (microdata)");
  const types = unique([].concat(...ld.nodes.map(typesOf), microTypes));
  const missingProps = [];
  ld.nodes.forEach(n => {
    if (Object.keys(n).filter(k => k !== "@type" && k !== "@id" && k !== "@context").length === 0) return; // reference only
    typesOf(n).forEach(t => {
      const rule = SCHEMA_RULES[t];
      if (!rule) return;
      const lacks = rule.filter(p => !p.split("|").some(k => hasValue(n[k]))).map(p => p.split("|")[0]);
      if (lacks.length) missingProps.push(t + ": " + lacks.join(", "));
    });
  });
  d["Schema Types"] = types.length ? types.join(", ") : "None";
  d["Schema Parse Errors"] = ld.errors;
  d["Schema Missing Properties"] = missingProps.length ? unique(missingProps).slice(0, 8).join("; ") : "None";
  d["Breadcrumbs"] = breadcrumbText(ld.nodes, markup);
  if (!types.length) issues.push("No structured data");
  if (ld.errors) issues.push("Structured data has errors");
  if (missingProps.length) issues.push("Structured data missing key properties");

  // ---------- E-commerce: products listed ----------
  const bodyTag = (html.match(/<body\b[^>]*>/i) || [""])[0];
  const products = detectProducts(bodyHtml, bodyTag ? (parseAttributes(bodyTag)["class"] || "") : "", ld.nodes, html, pageRoot);
  d["Products Listed"] = products.display;
  if (products.count !== null && products.count < CONFIG.MIN_PRODUCTS) issues.push("Low product count");

  // ---------- Trust / E-E-A-T ----------
  // Author only matters on editorial content (blog posts, guides, news); shops and service pages don't need one.
  const article = detectArticle(meta, ld.nodes, bodyTag ? (parseAttributes(bodyTag)["class"] || "") : "", pageInfo.path, contentHtml, products.count !== null || /^Product page/.test(products.display));
  d["Author"] = article ? findAuthor(meta, ld.nodes, links, contentHtml) : "N/A (not a blog/article)";
  const dates = analyzeDates(meta, ld.nodes, markup, contentHtml, getHeader(headers, "Last-Modified"), title);
  d["Published / Modified"] = dates.display;
  d["Date Check"] = dates.check;
  dates.issues.forEach(i => issues.push(i));
  const contact = [];
  if (tel) contact.push("tel links: " + tel);
  if (mail) contact.push("mailto links: " + mail);
  if (ld.nodes.some(n => n.address || typesOf(n).indexOf("PostalAddress") !== -1)) contact.push("address in schema");
  d["Contact Signals"] = contact.length ? contact.join(", ") : "None found";

  const placeholderHits = PLACEHOLDERS.filter(re => re.test(visibleText) || re.test(title)).map(re => re.source.replace(/\\b|\\/g, ""));
  d["Placeholder Text"] = placeholderHits.length ? placeholderHits.join(", ") : "None";
  if (placeholderHits.length) issues.push("Placeholder text found");
  d["Content Hash"] = wordCount >= 50 ? hashText(visibleText.toLowerCase()) : "";

  d["_BaseIssues"] = issues.join("; ");
  const row = buildRow(d);
  row.discovered = discovered; // not written to the sheet (rows are copied with slice() before writing)
  row.links = linkStore;       // goes to the hidden _Links tab
  row.source = pageUrl;
  return row;
}

/**
 * One page's links for the _Links tab: JSON [[url, anchor, where], ...], one entry per distinct URL.
 * where = "c" (main content) or "m" (menu, header, footer, sidebar). Same-site URLs are stored as a path
 * to save space; anchors are cut to 60 characters, and the list is shortened if it would not fit in a cell.
 */
function packPageLinks(pageLinks, cLinks, pageUrl, pageInfo) {
  const inContent = new Set(cLinks.inlinkUrls.concat(cLinks.outlinkUrls).map(normalizeForCompare));
  const self = normalizeForCompare(pageUrl);
  const origin = pageInfo.protocol + "://" + pageInfo.host;
  const at = {}, list = [];
  pageLinks.forEach(l => {
    const k = normalizeForCompare(l.u);
    if (k === self) return;
    const where = inContent.has(k) ? "c" : "m";
    if (at[k] !== undefined) { if (where === "c") list[at[k]][2] = "c"; return; }
    at[k] = list.length;
    const u = l.u.toLowerCase().indexOf(origin.toLowerCase() + "/") === 0 ? l.u.slice(origin.length) : l.u;
    list.push([u, String(l.a || "").slice(0, 60), where]);
  });
  let json = JSON.stringify(list);
  while (json.length > 45000 && list.length) { list.length = Math.floor(list.length * 0.8); json = JSON.stringify(list); }
  return list.length ? json : "";
}

/** Calls fn(sourcePage, absoluteUrl, anchor, where) for every stored link. Returns false when no link data exists. */
function forEachStoredLink(fn) {
  const sh = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(CONFIG.LINKS_TAB);
  if (!sh || sh.getLastRow() < 1) return false;
  sh.getRange(1, 1, sh.getLastRow(), 2).getValues().forEach(r => {
    const source = String(r[0]);
    const p = parseUrl(source);
    if (!p || !r[1]) return;
    let list;
    try { list = JSON.parse(String(r[1])); } catch (e) { return; }
    const origin = p.protocol + "://" + p.host;
    list.forEach(l => fn(source, l[0].charAt(0) === "/" ? origin + l[0] : l[0], l[1], l[2]));
  });
  return true;
}

/**
 * Contextual links in the main content (paragraphs, lists, tables, headings, quotes, image links).
 * - Pieces of one link split by the editor ("second-han" + "d laptop") are merged back into one anchor.
 * - Image links use the image's alt text as the anchor: [image: alt] or [image: no alt].
 * - Each distinct URL + anchor pair is listed once; jump links (#...), self links and file links are skipped.
 */
function extractContentLinks(html, baseUrl, pageUrl, pageRoot) {
  const out = { inlinkUrls: [], inlinkAnchors: [], outlinkUrls: [], outlinkAnchors: [], splitAnchors: 0 };
  const self = normalizeForCompare(pageUrl);
  const textOf = inner => decodeEntities(String(inner).replace(/<br\s*\/?>/gi, " ").replace(/<[^>]+>/g, ""));
  const re = /<a(?=[\s>])([^>]*)>([\s\S]*?)<\/a\s*>/gi;
  const links = [];
  let m;
  while ((m = re.exec(html)) !== null) {
    const attrs = parseAttributes("<a" + m[1] + ">");
    const href = (attrs.href || "").trim();
    const prev = links[links.length - 1];
    // A split link has nothing between its pieces except inline tags. Block tags between them (separate
    // list items, buttons in their own <div>) mean two real links that happen to share a URL.
    const between = html.slice(prev ? prev.end : 0, m.index);
    if (prev && href && prev.href === href && !cleanText(between) &&
        !/<\/?(li|div|p|br|h[1-6]|td|th|tr|ul|ol|section|article|figure|button)\b/i.test(between)) {
      prev.text += textOf(m[2]); prev.inner += m[2]; prev.end = re.lastIndex; prev.pieces++;
      continue;
    }
    links.push({ href, text: textOf(m[2]), inner: m[2], end: re.lastIndex, pieces: 1 });
  }
  const seen = {};
  links.forEach(l => {
    if (l.pieces > 1) out.splitAnchors++;
    const href = l.href;
    if (!href || href.charAt(0) === "#" || /^(javascript|mailto|tel|data):/i.test(href) || ASSET_RE.test(href)) return;
    let anchor = cleanSpaces(l.text);
    if (!anchor) {
      const img = getTags(l.inner, "img").map(parseAttributes)[0];
      if (!img) return;
      anchor = img.alt && img.alt.trim() ? "[image: " + cleanSpaces(img.alt) + "]" : "[image: no alt]";
    }
    const full = resolveUrl(href, baseUrl);
    const p = full && parseUrl(full);
    if (!p || isUtilityLink(full)) return; // wishlist, cart, account, login... are not contextual links
    const norm = normalizeForCompare(full);
    if (norm === self) return;
    const key = norm + "|" + anchor.toLowerCase();
    if (seen[key]) return;
    seen[key] = true;
    if (isInternal(bareHost(p.host), pageRoot)) { out.inlinkUrls.push(full); out.inlinkAnchors.push(anchor); }
    else { out.outlinkUrls.push(full); out.outlinkAnchors.push(anchor); }
  });
  return out;
}

/**
 * Detects the page type and how many products it lists, from the HTML already downloaded (no extra requests).
 * Only the main product grid is counted: sidebar/widget products and "related products" on product pages are ignored.
 */
function detectProducts(bodyHtml, bodyClass, nodes, html, pageRoot) {
  const cls = " " + bodyClass.toLowerCase() + " ";
  const has = re => re.test(cls);
  let type = "";
  if (has(/ single-product | template-product /)) type = "Product page";
  else if (has(/ tax-product_cat | template-collection /)) type = "Category";
  else if (has(/ tax-product_tag | tax-pa_/)) type = "Tag/attribute listing";
  else if (has(/ post-type-archive-product | woocommerce-shop /)) type = "Shop page";
  else if (has(/ search-results | template-search /) && has(/ woocommerce /)) type = "Product search";

  // Main grid: grids outside the header, menus, footer, sidebars and widgets; the one with the most products wins.
  const scope = removeElementsWhere(bodyHtml, (tag, open) => /^(aside|header|footer|nav)$/.test(tag) ||
    classTokens(open).some(t => SIDEBAR_TOKEN.test(t) || /^widget$|related|upsells|cross-sells|recently-viewed|mega-menu|offcanvas/.test(t)));
  let grid = 0;
  scanElements(scope, isProductGridContainer).forEach(f => {
    const inner = scope.slice(f.innerStart, f.innerEnd);
    const ids = new Set();
    let items = 0;
    (inner.match(/<(li|div|article)\b[^>]*class=["'][^"']*["'][^>]*>/gi) || []).forEach(tagStr => {
      const t = classTokens(tagStr);
      if (t.indexOf("type-product") !== -1 || t.indexOf("wd-product") !== -1 || t.indexOf("product-card") !== -1 ||
          (t.indexOf("product") !== -1 && t.some(x => /^post-\d+$/.test(x)))) {
        const id = t.find(x => /^post-\d+$/.test(x));
        if (id) ids.add(id); else items++;
      }
    });
    grid = Math.max(grid, ids.size || items);
  });
  // Custom/Bootstrap themes: count top-level product cards (a card nested in a card counts once).
  if (!grid) grid = scanElements(scope, isProductCard).length;
  // Last resort: unique product-detail links (/product/, /products/, /book/, /item/, /p/, /dp/) on this site only
  // (links to other sites, e.g. an Instagram feed's instagram.com/p/... posts, are not products).
  if (!grid) {
    grid = new Set((scope.match(/href=["'][^"']*\/(product|products|book|item|p|dp)\/[^"'#?\/]+/gi) || [])
      .map(h => h.replace(/^href=["']/i, ""))
      .filter(h => { const m = h.match(/^(?:https?:)?\/\/([^\/]+)/i); return !m || bareHost(m[1]) === pageRoot; })
      .map(h => h.replace(/^(?:https?:)?\/\/[^\/]+/i, ""))).size;
    if (grid < 2) grid = 0;
  }

  // Total products: WooCommerce result count, or any "Showing 1 to 20 of 197 results" / "Showing all 12 results" text.
  const rc = (html.match(/class=["'][^"']*woocommerce-result-count[^"']*["'][^>]*>([\s\S]*?)<\/p>/i) || [])[1];
  const rcText = rc ? cleanText(rc) : "";
  const anyText = cleanText(bodyHtml);
  const total = (rcText.match(/of\s+([\d,]+)\s+results?/i) || rcText.match(/all\s+([\d,]+)\s+results?/i) || rcText.match(/([\d,]+)\s+results?/i) ||
    anyText.match(/showing\s+[\d,]+\s*(?:[-–]|to)\s*[\d,]+\s+of\s+([\d,]+)\s+(?:results?|products?|items?|books?)/i) ||
    anyText.match(/showing\s+all\s+([\d,]+)\s+(?:results?|products?|items?|books?)/i) || [])[1];
  const totalNum = total ? Number(total.replace(/,/g, "")) : 0;
  const list = nodes.find(n => typesOf(n).indexOf("ItemList") !== -1);
  const schemaCount = list ? (Number(list.numberOfItems) || (Array.isArray(list.itemListElement) ? list.itemListElement.length : 0)) : 0;

  // Pagination: rel=next, WooCommerce page-numbers, or a Bootstrap .pagination block (page count = highest page number).
  let pages = 0;
  // Read from the full body (pagination is often inside a <nav>) and from every block: sites often have a
  // mobile "Previous / Next" block without numbers plus a desktop block with the page numbers.
  let nextLink = false;
  scanElements(bodyHtml, (tag, open) => classTokens(open).some(t => /^(pagination|woocommerce-pagination|page-numbers|pager|paginationblock)$/.test(t)))
    .forEach(b => {
      const inner = bodyHtml.slice(b.innerStart, b.innerEnd);
      // Page numbers only from the page links (their text or ?page=N / /page/N/), never from "Showing 1 to 20 of 197".
      getElements(inner, "a").forEach(a => {
        const href = a.attrs.href || "";
        const fromHref = Number((href.match(/[?&](?:page|p|pg)=(\d{1,4})\b|\/page\/(\d{1,4})\/?/i) || []).slice(1).find(Boolean) || 0);
        const fromText = /^\d{1,4}$/.test(cleanText(a.inner)) ? Number(cleanText(a.inner)) : 0;
        pages = Math.max(pages, fromHref, fromText);
        if (href && (/next|›|»/i.test(cleanText(a.inner)) || relHas(a.attrs, "next"))) nextLink = true;
      });
    });
  const paginated = pages > 1 || nextLink || /<link[^>]+rel=["']next["']/i.test(html) ||
    /class=["'][^"']*\bnext\b[^"']*\bpage-numbers\b|class=["'][^"']*\bpage-numbers\b[^"']*\bnext\b/i.test(html);

  // Empty listing: shop controls (sort/filter) or a "no products found" message, but no products.
  const visible = cleanText(scope);
  const emptyMsg = (visible.match(/\bno\s+(products?|books?|items?|results?)\s+(were\s+)?found\b/i) || [])[0] || "";
  const shopControls = /name=["'](orderby|short_by|sort_by|sort|order)["']|woocommerce-ordering|tf-shop-control|shop-control|toolbar-sorter|products-sort/i.test(scope);

  // Generic product page: one Product/Book schema with offers and no product grid.
  const productNodes = nodes.filter(n => typesOf(n).some(t => /^(Product|Book|ProductGroup)$/.test(t)) && n.offers);
  if (!type && !grid && productNodes.length === 1 && !list) type = "Product page";
  if (!type && (grid >= 2 || schemaCount >= 2 || (!grid && (emptyMsg || shopControls)))) type = "Listing (detected)";
  if (!type) return { display: "Not a product listing", count: null };
  if (type === "Product page") return { display: "Product page (related products not counted)", count: null };

  const count = totalNum || grid;
  const parts = [type, grid + " product" + (grid === 1 ? "" : "s") + " in main grid"];
  if (!grid && emptyMsg) parts.push("page says \"" + emptyMsg.trim() + "\" ⚠");
  if (totalNum) parts.push(totalNum + " in total (result count)");
  // Only a schema that claims MORE products than the page shows is a problem (plugins often cap ItemList at ~10).
  if (schemaCount > Math.max(grid, totalNum)) parts.push("schema ItemList says " + schemaCount + " ⚠");
  parts.push(pages > 1 ? pages + " pages" + (totalNum ? "" : " (about " + (grid * pages) + " products)") : paginated ? "more pages" : "no pagination");
  return { display: parts.join(" · "), count };
}

function extractJsonLd(html) {
  const nodes = [];
  let errors = 0;
  getElements(html, "script").forEach(s => {
    if (!/ld\+json/i.test(s.attrs.type || "")) return;
    const txt = s.inner.trim().replace(/^\s*<!\[CDATA\[/, "").replace(/\]\]>\s*$/, "").trim();
    if (!txt) return;
    try { collectNodes(JSON.parse(txt), nodes); } catch (e) { errors++; }
  });
  return { nodes, errors };
}

function collectNodes(obj, nodes) {
  if (!obj || typeof obj !== "object") return;
  if (Array.isArray(obj)) { obj.forEach(o => collectNodes(o, nodes)); return; }
  if (obj["@type"]) nodes.push(obj);
  Object.keys(obj).forEach(k => { if (obj[k] && typeof obj[k] === "object") collectNodes(obj[k], nodes); });
}

function typesOf(node) {
  const t = node["@type"];
  return (Array.isArray(t) ? t : [t]).filter(Boolean).map(x => String(x).replace(/^https?:\/\/schema\.org\//i, ""));
}

function hasValue(v) {
  return v !== undefined && v !== null && v !== "" && !(Array.isArray(v) && !v.length);
}

/**
 * True for blog posts, guides and news articles. Any one signal is enough:
 * og:type=article, Article/BlogPosting/NewsArticle/TechArticle/HowTo schema, a WordPress post (single-post / type-post),
 * or a blog-style URL (/blog/, /news/, /guide(s)/, /article(s)/, /insights/, /how-to/). Product and listing pages never count.
 */
function detectArticle(meta, nodes, bodyClass, path, contentHtml, isShopPage) {
  if (isShopPage) return false;
  if (/^article$/i.test(meta("og:type"))) return true;
  if (nodes.some(n => typesOf(n).some(t => /^(Article|BlogPosting|NewsArticle|TechArticle|HowTo|Report|ScholarlyArticle)$/.test(t)))) return true;
  const cls = " " + String(bodyClass).toLowerCase() + " ";
  if (/ single-post | post-template-default /.test(cls)) return true;
  if (/<article\b[^>]*class=["'][^"']*\btype-post\b/i.test(contentHtml)) return true;
  return /\/(blogs?|news|guides?|articles?|insights|how-to|knowledge-base|resources)\//i.test(path + "/");
}

/** Author name from the first source that has one; the source is shown in brackets. */
function findAuthor(meta, nodes, links, contentHtml) {
  const metaAuthor = meta("author");
  if (metaAuthor) return metaAuthor + " (meta)";

  const art = nodes.find(n => n.author && typesOf(n).some(t => /Article|Posting|WebPage/.test(t)));
  if (art) {
    const byId = id => nodes.find(x => x["@id"] === id && x.name);
    const names = (Array.isArray(art.author) ? art.author : [art.author]).map(a => {
      if (typeof a === "string") return a;
      if (!a) return "";
      if (a.name) return a.name;
      const ref = a["@id"] && byId(a["@id"]);
      return ref ? ref.name : "";
    }).filter(Boolean);
    if (names.length) return names.join(", ") + " (schema)";
  }

  const relLink = getElements(contentHtml, "a").find(a => relHas(a.attrs, "author") && cleanText(a.inner));
  if (relLink) return cleanText(relLink.inner) + " (author link)";

  const byline = contentHtml.match(/<([a-z0-9]+)[^>]*class=["'][^"']*\b(author|byline|post-author|entry-author|author-name)\b[^"']*["'][^>]*>([\s\S]*?)<\/\1>/i);
  if (byline) {
    const text = cleanText(byline[3]).replace(/^(posted|written|published)?\s*by[:\s]*/i, "").trim();
    if (text && text.length <= 60) return text + " (byline)";
  }

  const authorUrl = getElements(contentHtml, "a").map(a => a.attrs.href || "").find(h => /\/author\/[^\/?#]+/i.test(h));
  if (authorUrl) {
    const slug = authorUrl.match(/\/author\/([^\/?#]+)/i)[1];
    return slug.replace(/[-_]+/g, " ").replace(/\b\w/g, c => c.toUpperCase()) + " (author URL)";
  }
  if (links.some(a => relHas(a, "author"))) return "Unknown name (rel=author link in head)";
  return "Not found";
}

const DAY_MS = 24 * 60 * 60 * 1000;

/** Parses ISO/RFC dates, including "2024-01-05 10:00:00" and "+0530" offsets. Returns ms or NaN. */
function parseDate(s) {
  if (!s) return NaN;
  const t = String(s).trim().replace(/^(\d{4}-\d{2}-\d{2}) (\d)/, "$1T$2").replace(/([+-]\d{2})(\d{2})$/, "$1:$2");
  return Date.parse(t);
}

function dayOf(s) {
  const ms = parseDate(s);
  return isNaN(ms) ? String(s).slice(0, 10) : new Date(ms).toISOString().slice(0, 10);
}

/**
 * Collects published/modified dates from every source, picks the best one and checks them against each other.
 * Returns { display, check, issues }.
 */
function analyzeDates(meta, nodes, markup, contentHtml, lastModifiedHeader, title) {
  const now = Date.now();
  const artNodes = nodes.filter(n => typesOf(n).some(t => /Article|Posting|WebPage/.test(t)));
  const schemaDate = key => {
    const n = artNodes.find(x => hasValue(x[key]) && typeof x[key] !== "object") ||
      nodes.find(x => hasValue(x[key]) && typeof x[key] !== "object");
    return n ? String(n[key]) : "";
  };
  const itemprop = name => {
    const tag = (markup.match(new RegExp("<[^>]+itemprop=[\"']" + name + "[\"'][^>]*>", "i")) || [])[0];
    if (!tag) return "";
    const a = parseAttributes(tag);
    return a.content || a.datetime || "";
  };
  const times = getTags(contentHtml, "time").map(parseAttributes).filter(a => a.datetime);
  const timeByClass = re => (times.find(a => re.test(a.class || "")) || {}).datetime || "";

  const pubSrc = [
    ["meta", meta("article:published_time")],
    ["schema", schemaDate("datePublished")],
    ["time tag", timeByClass(/\b(published|entry-date|post-date|date-published)\b/i) || itemprop("datePublished")]
  ];
  const modSrc = [
    ["meta", meta("article:modified_time")],
    ["og:updated", meta("og:updated_time")],
    ["schema", schemaDate("dateModified")],
    ["time tag", timeByClass(/\b(updated|modified|date-modified)\b/i) || itemprop("dateModified")]
  ];
  // Last resort for the published date: the first <time> on the page that isn't the "updated" one.
  if (!pubSrc.some(s => s[1])) {
    const first = times.find(a => !/\b(updated|modified)\b/i.test(a.class || ""));
    if (first) pubSrc.push(["first time tag", first.datetime]);
  }

  const best = list => (list.find(s => s[1]) || [])[1] || "";
  const pub = best(pubSrc), mod = best(modSrc);
  const issues = [], flags = [];
  const spread = list => {
    const ms = list.map(s => parseDate(s[1])).filter(x => !isNaN(x));
    return ms.length > 1 ? Math.max.apply(null, ms) - Math.min.apply(null, ms) : 0;
  };

  let conflict = false;
  if (spread(pubSrc) > DAY_MS) { conflict = true; flags.push("published dates differ between sources"); }
  if (spread(modSrc) > DAY_MS) { conflict = true; flags.push("modified dates differ between sources"); }
  if (conflict) issues.push("Conflicting dates");

  const pubMs = parseDate(pub), modMs = parseDate(mod);
  if (!isNaN(pubMs) && !isNaN(modMs) && modMs < pubMs - DAY_MS) { issues.push("Modified before published"); flags.push("modified date is before the publish date"); }
  if (pubSrc.concat(modSrc).some(s => parseDate(s[1]) > now + DAY_MS)) { issues.push("Future date"); flags.push("date in the future"); }
  if (modSrc.some(s => { const ms = parseDate(s[1]); return !isNaN(ms) && Math.abs(now - ms) < 10 * 60 * 1000; })) {
    issues.push("Date changes on every load"); flags.push("modified date equals the time of the crawl");
  }
  const titleYears = (String(title).match(/\b20\d{2}\b/g) || []).map(Number);
  const titleYear = titleYears.length ? Math.max.apply(null, titleYears) : 0;
  if (titleYear && !isNaN(pubMs) && titleYear > new Date(pubMs).getUTCFullYear() &&
      (isNaN(modMs) || new Date(modMs).getUTCFullYear() < titleYear)) {
    issues.push("Title year newer than content"); flags.push("title says " + titleYear + " but the content date is older");
  }
  const structured = list => list.some(s => s[1] && s[0] !== "time tag" && s[0] !== "first time tag");
  const visibleOnly = (pub && !structured(pubSrc)) || (mod && !structured(modSrc));
  if (visibleOnly) { issues.push("Dates missing from meta & schema"); flags.push("Date only in visible HTML"); }

  const show = list => list.map(s => s[0] + ": " + (s[1] ? dayOf(s[1]) : "missing")).join(" · ");
  const header = lastModifiedHeader ? " · Last-Modified header: " + dayOf(lastModifiedHeader) : "";
  let check;
  if (!pub && !mod) check = "No published/modified dates found" + (header ? " |" + header.slice(2) : "");
  else check = "Pub → " + show(pubSrc) + " | Mod → " + show(modSrc) + header + flags.map(f => " | ⚠ " + f).join("");
  const display = pub || mod ?
    "Pub: " + (pub ? dayOf(pub) : "-") + " | Mod: " + (mod ? dayOf(mod) : "-") + (conflict ? " ⚠ conflict" : "") : "Not found";
  return { display, check, issues };
}

function breadcrumbText(nodes, markup) {
  const bc = nodes.find(n => typesOf(n).indexOf("BreadcrumbList") !== -1 && Array.isArray(n.itemListElement));
  if (bc) {
    const names = bc.itemListElement.slice()
      .sort((a, b) => (Number(a && a.position) || 0) - (Number(b && b.position) || 0))
      .map(i => i && (i.name || (i.item && typeof i.item === "object" && i.item.name)))
      .filter(Boolean);
    if (names.length) return names.join(" > ");
  }
  const block = markup.match(/<nav[^>]*aria-label=["']breadcrumbs?["'][^>]*>([\s\S]*?)<\/nav>/i) ||
    markup.match(/<(?:ol|ul)[^>]*class=["'][^"']*breadcrumb[^"']*["'][^>]*>([\s\S]*?)<\/(?:ol|ul)>/i) ||
    markup.match(/<(?:nav|div)[^>]*class=["'][^"']*breadcrumb[^"']*["'][^>]*>([\s\S]*?)<\/(?:nav|div)>/i);
  if (block) {
    let items = getElements(block[1], "li").map(e => cleanText(e.inner));
    if (!items.length) items = getElements(block[1], "a").map(e => cleanText(e.inner));
    items = items.filter(t => t && !/^[>\/»›|]+$/.test(t));
    if (items.length) return items.join(" > ") + " (HTML)";
  }
  return "Missing";
}

/** extra (optional): { rowIndex: [issue names] } from the link and Core Web Vitals checks; they are scored like page issues. */
function applyDuplicatesAndScores(data, extra) {
  // Redirected rows show the destination's title/content, so they are left out of duplicate checks.
  const redirected = r => Number(r[COL["Redirect Hops"]]) > 0;
  const isOk = r => Number(r[COL["Final Status"]]) === 200 && !redirected(r);
  const key = v => String(v || "").trim().toLowerCase();
  const counter = col => {
    const m = {};
    data.forEach(r => {
      const k = key(r[COL[col]]);
      if (!isOk(r) || !k || k === "missing" || k.indexOf("n/a") === 0) return;
      m[k] = (m[k] || 0) + 1;
    });
    return m;
  };
  const titleCount = counter("Meta Title");
  const descCount = counter("Meta Description");
  const hashCount = counter("Content Hash");

  data.forEach((r, i) => {
    const issues = String(r[COL["_BaseIssues"]] || "").split("; ").filter(Boolean).concat((extra && extra[i]) || []);
    const dup = (col, map, issueName) => {
      if (!isOk(r)) return redirected(r) ? "N/A (redirects)" : "";
      const k = key(r[COL[col]]);
      if (k && map[k] > 1) { issues.push(issueName); return "Yes (" + map[k] + " pages)"; }
      return "No";
    };
    r[COL["Duplicate Title"]] = dup("Meta Title", titleCount, "Duplicate meta title");
    r[COL["Duplicate Description"]] = dup("Meta Description", descCount, "Duplicate meta description");
    r[COL["Duplicate Content"]] = dup("Content Hash", hashCount, "Duplicate content");

    const list = unique(issues).sort((a, b) => PRIORITY_RANK[issuePriority(a)] - PRIORITY_RANK[issuePriority(b)]);
    const counts = { Critical: 0, High: 0, Medium: 0, Low: 0 };
    list.forEach(i => { counts[issuePriority(i)]++; });
    const broken = list.indexOf("Page fetch failed") !== -1 || list.indexOf("Page not returning 200") !== -1;
    const penalty = Object.keys(counts).reduce((p, k) => p + counts[k] * PRIORITY_WEIGHT[k], 0);
    r[COL["Critical"]] = counts.Critical;
    r[COL["High"]] = counts.High;
    r[COL["Medium"]] = counts.Medium;
    r[COL["Low"]] = counts.Low;
    r[COL["Page Score"]] = isNonHtml(r) ? "N/A" : broken ? 0 : Math.max(0, 100 - penalty);
    r[COL["Issues"]] = list.join("; ");
  });
}

/** Image, PDF or other file (not a web page): shown in the report but left out of page scores. */
function isNonHtml(r) {
  return String(r[COL["Meta Title"]]) === "N/A (non-HTML)";
}

function issuePriority(name) {
  return (ISSUES[name] || ["Medium"])[0];
}

// ============================================================
//  SITE HEALTH (one domain)
// ============================================================

function runSiteHealth(data) {
  const checks = [];
  const add = (category, check, status, result, priority, fix) => {
    const problem = status === "Fail" || status === "Warn";
    checks.push({ category, check, status, result: String(result), priority: problem ? priority : "", fix: problem ? fix : "" });
  };

  // Site Health covers one domain: the one most audited pages are on (a pasted list can mix domains).
  const rowHost = r => { const u = parseUrl(String(r[COL["Final URL"]] || r[COL["URL"]])); return u ? u.host : ""; };
  const okRows = data.filter(r => Number(r[COL["Final Status"]]) === 200);
  const hostCount = {};
  (okRows.length ? okRows : data).forEach(r => { const h = rowHost(r); if (h) hostCount[h] = (hostCount[h] || 0) + 1; });
  const hosts = Object.keys(hostCount).sort((a, b) => hostCount[b] - hostCount[a]); // ties: first in the list wins
  if (!hosts.length) {
    add("Site", "Domain", "Fail", "Could not determine the domain", "Critical", "Check the URLs in the input tab.");
    return { checks, host: "" };
  }
  const host = hosts[0];
  const onSite = r => bareHost(rowHost(r)) === bareHost(host);
  const siteRows = data.filter(onSite);
  const domains = unique(data.map(r => bareHost(rowHost(r))).filter(Boolean));
  if (domains.length > 1) {
    add("Site", "Domains in this audit", "Warn", domains.length + " domains (" + domains.slice(0, 5).join(", ") + (domains.length > 5 ? "…" : "") +
      "). Site Health and the sitemap checks cover only " + host + " (" + siteRows.length + " of " + data.length + " pages).", "Medium",
      "Audit one domain at a time so Site Health and the Summary describe a single site.");
  }
  let origin = "https://" + host;

  const steps = ["Homepage, HTTPS, www, robots.txt and 404 test", "XML sitemap", "Homepage response time", "Security headers and technology"];
  const step = i => setStatus({ phase: "site", stepNo: i + 1, steps: steps.length, step: steps[i], log: "Site Health: " + steps[i] });

  // The first request of each independent check goes out in parallel: on slow servers these used to run one by one.
  step(0);
  const altHost = host.indexOf("www.") === 0 ? host.slice(4) : "www." + host;
  const fake = origin + "/seo-audit-check-" + Utilities.getUuid().slice(0, 8);
  const first = fetchMany([origin + "/", "http://" + host + "/", "https://" + altHost + "/", origin + "/robots.txt", fake], false);

  // --- Availability & SSL ---
  const home = followRedirectChain(origin + "/", first[0]);
  let homeRes = null, homeHtml = "", homeHeaders = {}, homeFinal = origin + "/";
  if (home.error) {
    const ssl = /ssl|certificate|handshake/i.test(home.error);
    add("Availability", "Homepage", "Fail", "Unreachable: " + home.error, "Critical", "Check hosting, DNS and SSL.");
    if (ssl) add("Security", "SSL certificate", "Fail", home.error, "Critical", "Fix or renew the SSL certificate (it must cover " + host + ").");
  } else {
    homeRes = home.response;
    homeFinal = home.finalUrl;
    homeHeaders = homeRes.getAllHeaders();
    const code = homeRes.getResponseCode();
    if (code === 200) homeHtml = homeRes.getContentText().replace(/<!--[\s\S]*?-->/g, "");
    add("Availability", "Homepage", code === 200 ? "Pass" : "Fail",
      code + " " + homeFinal + (home.chain.length > 1 ? " (after " + (home.chain.length - 1) + " redirect/s)" : ""),
      "Critical", "The homepage must return 200.");
    add("Security", "SSL certificate", "Pass", "HTTPS loads with a valid certificate (expiry date not readable from Apps Script)", "", "");
  }
  // No HTTPS but the http:// site works: run the remaining checks on http:// so robots.txt, the sitemap and
  // the 404 test aren't reported as missing just because https:// is down.
  if (home.error) {
    const h = followRedirectChain("http://" + host + "/", first[1]);
    if (!h.error && /^http:/i.test(h.finalUrl) && h.response.getResponseCode() === 200) {
      origin = "http://" + host;
      homeRes = h.response;
      homeFinal = h.finalUrl;
      homeHeaders = homeRes.getAllHeaders();
      homeHtml = homeRes.getContentText().replace(/<!--[\s\S]*?-->/g, "");
      add("Availability", "Homepage over http://", "Warn", "200 " + homeFinal + " (the site works only without HTTPS; the checks below use http://)", "Critical",
        "Install an SSL certificate, then 301 redirect http:// to https://.");
      const again = fetchMany([origin + "/robots.txt", origin + "/seo-audit-check-" + Utilities.getUuid().slice(0, 8)], false);
      first[3] = again[0];
      first[4] = again[1];
    }
  }
  const homeHost = (parseUrl(homeFinal) || {}).host || host;

  // --- HTTP -> HTTPS ---
  // Stop once the chain reaches https: the page itself was already fetched above.
  const http = followRedirectChain("http://" + host + "/", first[1], u => /^https:/i.test(u));
  if (http.error) {
    add("Security", "HTTP → HTTPS redirect", "Info", "http:// version not reachable: " + http.error, "", "");
  } else {
    const firstCode = http.chain[0].code;
    const httpHops = http.stopped ? http.chain.length : http.chain.length - 1;
    if (!/^https:/i.test(http.finalUrl)) {
      add("Security", "HTTP → HTTPS redirect", "Fail", "http:// loads without redirecting to https://", "High", "Add a sitewide 301 redirect from http:// to https://.");
    } else if (firstCode !== 301 && firstCode !== 308) {
      add("Security", "HTTP → HTTPS redirect", "Warn", "Uses a " + firstCode + " (temporary) redirect", "Medium", "Use a permanent 301 redirect.");
    } else {
      add("Security", "HTTP → HTTPS redirect", "Pass", firstCode + " → " + http.finalUrl + " (" + httpHops + " hop/s)", "", "");
    }
  }

  // --- www vs non-www ---
  // Stop once the chain reaches the main host.
  const alt = followRedirectChain("https://" + altHost + "/", first[2], u => (parseUrl(u) || {}).host === homeHost);
  if (alt.error) {
    add("Duplicates", "www / non-www", "Warn", altHost + " does not load over HTTPS: " + alt.error, "Low",
      "Point " + altHost + " to the site (with a valid certificate) and 301 redirect it to " + homeHost + ".");
  } else {
    const altFinalHost = (parseUrl(alt.finalUrl) || {}).host;
    const altCode = alt.response ? alt.response.getResponseCode() : alt.chain[alt.chain.length - 1].code;
    if ((alt.stopped || alt.chain.length > 1) && altFinalHost === homeHost) {
      const c = alt.chain[0].code;
      if (c === 301 || c === 308) add("Duplicates", "www / non-www", "Pass", altHost + " → " + c + " → " + homeHost, "", "");
      else add("Duplicates", "www / non-www", "Warn", altHost + " uses a " + c + " (temporary) redirect", "Medium", "Use a permanent 301 redirect.");
    } else if (alt.chain.length === 1 && altCode === 200) {
      add("Duplicates", "www / non-www", "Fail", "Both " + host + " and " + altHost + " return 200 (duplicate site)", "High",
        "301 redirect one version to the other and keep canonicals consistent.");
    } else {
      add("Duplicates", "www / non-www", "Warn", altHost + " ends at " + alt.finalUrl + " (" + altCode + ")", "Medium",
        "Make " + altHost + " 301 redirect to " + homeHost + ".");
    }
  }

  // --- robots.txt ---
  const robotsChain = followRedirectChain(origin + "/robots.txt", first[3]);
  const robotsRes = robotsChain.error ? { error: robotsChain.error } : { response: robotsChain.response };
  let robots = { groups: [], sitemaps: [] };
  const robotsOk = robotsRes.response && robotsRes.response.getResponseCode() === 200 && !looksHtml(robotsRes.response.getContentText());
  if (robotsOk) {
    robots = parseRobots(robotsRes.response.getContentText());
    add("Crawling", "robots.txt", "Pass", "Found (" + robots.groups.length + " user-agent group/s)", "", "");
  } else {
    add("Crawling", "robots.txt", "Fail", "Missing or invalid (" + (robotsRes.error || robotsRes.response.getResponseCode()) + ")", "Medium",
      "Create a robots.txt that lists your sitemap.");
  }
  const group = findRobotsGroup(robots.groups, "googlebot");
  if (robotsOk) {
    if (!robotsAllows(group, "/") && !robotsAllows(group, "/seo-audit-random-page")) {
      add("Crawling", "robots.txt sitewide block", "Fail", "robots.txt blocks Googlebot from the whole site", "Critical",
        "Remove 'Disallow: /' unless the site is meant to be hidden.");
    } else {
      add("Crawling", "robots.txt sitewide block", "Pass", "No sitewide block", "", "");
    }
    const blocked = siteRows.filter(r => { const u = parseUrl(String(r[COL["URL"]])); return u && !robotsAllows(group, u.path + u.query); });
    add("Crawling", "Audited URLs blocked by robots.txt", blocked.length ? "Fail" : "Pass",
      blocked.length ? blocked.length + " URL/s, e.g. " + blocked.slice(0, 3).map(r => r[COL["URL"]]).join(", ") : "None",
      "High", "Unblock pages that should rank (blocked pages can't be crawled).");
    add("Crawling", "Sitemap declared in robots.txt", robots.sitemaps.length ? "Pass" : "Warn",
      robots.sitemaps.length ? robots.sitemaps.join(", ") : "No 'Sitemap:' line", "Low", "Add 'Sitemap: https://.../sitemap.xml' to robots.txt.");
  }

  // --- XML sitemap ---
  step(1);
  const candidates = unique(robots.sitemaps.concat([origin + "/sitemap.xml", origin + "/sitemap_index.xml", origin + "/wp-sitemap.xml"])).slice(0, 6);
  const sm = readSitemap(candidates);
  if (!sm) {
    add("Crawling", "XML sitemap", "Fail", "No XML sitemap found", "High", "Create an XML sitemap and submit it in Google Search Console.");
  } else {
    add("Crawling", "XML sitemap", "Pass", sm.url + (sm.isIndex ? " (index: read " + sm.childRead + " of " + sm.childTotal + " child sitemaps)" : ""), "", "");
    add("Crawling", "Sitemap URL count", "Info", sm.urls.size + " URLs" + (sm.isIndex && sm.childRead < sm.childTotal ? " (partial)" : ""), "", "");
    if (sm.latest) {
      const ageDays = Math.round((Date.now() - new Date(sm.latest).getTime()) / 86400000);
      add("Crawling", "Sitemap freshness", isNaN(ageDays) || ageDays <= 180 ? "Pass" : "Warn",
        "Latest lastmod: " + sm.latest + (isNaN(ageDays) ? "" : " (" + ageDays + " days ago)"), "Low",
        "Keep lastmod dates accurate so Google re-crawls updated pages.");
    } else {
      add("Crawling", "Sitemap freshness", "Info", "No lastmod dates in sitemap", "", "");
    }
    const partialNote = sm.isIndex && sm.childRead < sm.childTotal ? " (sitemap read partially, may be overstated)" : "";
    const indexable = siteRows.filter(r => String(r[COL["Indexable"]]) === "Yes");
    const missing = indexable.filter(r => !sm.urls.has(normalizeForCompare(String(r[COL["Final URL"]]))));
    // The Result cell lists the URLs themselves (up to 50) so they can be fixed straight from this tab.
    const listOf = (arr, fmt) => arr.slice(0, 50).map(fmt).join(", ") + (arr.length > 50 ? " … and " + (arr.length - 50) + " more (see the Page Audit tab)" : "");
    if (indexable.length) {
      add("Crawling", "Indexable pages missing from sitemap", missing.length / indexable.length > 0.1 ? "Warn" : "Pass",
        missing.length + " of " + indexable.length + partialNote + (missing.length
          ? " missing: " + listOf(missing, r => String(r[COL["Final URL"]] || r[COL["URL"]]))
          : " missing (all in the sitemap): " + listOf(indexable, r => String(r[COL["Final URL"]] || r[COL["URL"]]))),
        "Medium", "Add every indexable page to the XML sitemap.");
    }
    const junk = siteRows.filter(r => String(r[COL["Indexable"]]) !== "Yes" && sm.urls.has(normalizeForCompare(String(r[COL["URL"]]))));
    const why = r => Number(r[COL["Redirect Hops"]]) > 0 ? "redirects to " + r[COL["Final URL"]]
      : String(r[COL["Indexable"]]).replace(/^No\s*[–-]\s*/, "");
    add("Crawling", "Non-indexable URLs in sitemap", junk.length ? "Warn" : "Pass",
      junk.length ? junk.length + " URL/s: " + listOf(junk, r => r[COL["URL"]] + " (" + why(r) + ")") : "None", "Medium",
      "List only 200, indexable, canonical URLs in the sitemap: replace redirecting URLs with their final URL and remove error or noindex pages.");
  }

  // --- Soft 404 (first hop only: a redirect is already the answer) ---
  const f = first[4];
  if (f.error) {
    add("Crawling", "404 handling", "Info", "Could not test: " + f.error, "", "");
  } else {
    const fc = f.response.getResponseCode();
    const loc = getHeader(f.response.getAllHeaders(), "Location");
    if (fc === 404 || fc === 410) add("Crawling", "404 handling", "Pass", "Missing pages return " + fc, "", "");
    else if (fc >= 300 && fc < 400 && loc) add("Crawling", "404 handling", "Warn", "Missing pages redirect (" + fc + ") to " + (resolveUrl(loc, fake) || loc), "Medium", "Return a real 404 status for missing pages instead of redirecting.");
    else add("Crawling", "404 handling", fc === 200 ? "Fail" : "Warn", "Missing pages return " + fc + (fc === 200 ? " (soft 404)" : ""), "High",
      "Configure the server to return a 404 status for missing pages.");
  }

  if (homeRes) {
    step(2);
    // --- Caching: the homepage's own headers + one static file (CSS/JS) from the homepage ---
    const maxAgeOf = v => { const m = String(v || "").match(/(?:^|[,\s])(?:s-)?max-age\s*=\s*(\d+)/i); return m ? Number(m[1]) : null; };
    const htmlCc = getHeader(homeHeaders, "Cache-Control");
    const cdnHeaders = ["cf-cache-status", "x-cache", "x-vercel-cache", "x-nextjs-cache", "cdn-cache-status", "x-hcdn-cache-status",
      "x-cache-status", "x-litespeed-cache", "x-proxy-cache", "x-fastly-cache"].map(h => [h, getHeader(homeHeaders, h)]).filter(x => x[1]);
    const cssTag = (homeHtml.match(/<link\b[^>]*rel=["']?stylesheet["']?[^>]*>/i) || [""])[0];
    const assetHref = (cssTag.match(/href=["']([^"']+)["']/i) || [])[1] ||
      (homeHtml.match(/<script\b[^>]*\ssrc=["']([^"']+\.js(?:\?[^"']*)?)["']/i) || [])[1];
    const assetUrl = assetHref ? resolveUrl(assetHref, homeFinal) : "";
    let assetCc = "", assetPath = "", assetErr = "";
    if (assetUrl) {
      const ar = fetchOne(assetUrl, true);
      if (ar.response && ar.response.getResponseCode() === 200) {
        assetCc = getHeader(ar.response.getAllHeaders(), "Cache-Control") || "none";
        assetPath = assetUrl.replace(/^https?:\/\/[^\/]+/i, "").replace(/\?.*$/, "");
        if (assetPath.length > 60) assetPath = "…" + assetPath.slice(-57);
      } else {
        assetErr = "could not fetch " + assetUrl.replace(/^https?:\/\/[^\/]+/i, "") + " (" + (ar.error || "HTTP " + ar.response.getResponseCode()) + ")";
      }
    }
    const assetAge = maxAgeOf(assetCc), longCache = assetAge !== null && assetAge >= 7 * 86400 || /immutable/i.test(assetCc);
    // Plain-English wording: each part says what the setting means for a visitor, with the raw value in ().
    const span = s => s >= 31536000 ? Math.round(s / 31536000) + " year" + (s >= 63072000 ? "s" : "")
      : s >= 86400 ? Math.round(s / 86400) + " day" + (s >= 172800 ? "s" : "")
      : s >= 3600 ? Math.round(s / 3600) + " hour" + (s >= 7200 ? "s" : "")
      : s >= 60 ? Math.round(s / 60) + " min" : s + " sec";
    const explain = cc => {
      const v = String(cc || "").toLowerCase(), age = maxAgeOf(v);
      if (!v || v === "none") return "no caching rule (browser guesses; may download again each visit)";
      if (/no-store/.test(v)) return "not saved (no-store: downloaded fresh on every visit)";
      if (/no-cache/.test(v) || age === 0) return "re-checked every visit (no-cache: browser asks the server if it changed)";
      if (age !== null) return "saved for " + span(age) + " (max-age=" + age + (/immutable/.test(v)
        ? ", immutable: repeat visits reuse the saved copy without re-checking)" : ": repeat visits reuse the saved copy)");
      return "rule set but no duration (" + cc + ")";
    };
    const CDN_NAMES = { "cf-cache-status": "Cloudflare", "x-hcdn-cache-status": "Hostinger CDN", "x-vercel-cache": "Vercel",
      "x-nextjs-cache": "Next.js", "x-litespeed-cache": "LiteSpeed", "x-fastly-cache": "Fastly" };
    const cdnState = v => /^hit/i.test(v) ? "page served from the CDN's saved copy, fast"
      : /^miss/i.test(v) ? "not in the CDN's copy yet, fetched from your server this time"
      : /dynamic|bypass|pass|uncacheable/i.test(v) ? "page not stored by the CDN, every visit goes to your server"
      : /expired|stale|revalidated|updating/i.test(v) ? "CDN copy was out of date, refreshed from your server"
      : "CDN status";
    const htmlPart = "Pages (HTML): " + explain(htmlCc) +
      (getHeader(homeHeaders, "ETag") || getHeader(homeHeaders, "Last-Modified") ? "; change check available (ETag/Last-Modified: unchanged pages reload faster)" : "");
    const cdnPart = cdnHeaders.length
      ? " · CDN: " + cdnHeaders.map(x => (CDN_NAMES[x[0]] || "CDN") + " " + x[1] + " (" + cdnState(x[1]) + ")").join(", ")
      : " · CDN: none detected (no CDN cache header)";
    if (assetPath) {
      add("Performance", "Caching (browser & CDN)", longCache ? "Pass" : "Warn",
        "CSS/JS files: " + explain(assetCc) + ", tested " + assetPath + " · " + htmlPart + cdnPart, "Medium",
        "Serve CSS, JS, fonts and images with Cache-Control: public, max-age=31536000, immutable (with versioned file names), and let a CDN cache what it can.");
    } else {
      add("Performance", "Caching (browser & CDN)", "Info", htmlPart + cdnPart + " · " + (assetErr || "No CSS/JS file found on the homepage to test"), "", "");
    }
    // --- Response time (2 timed fetches) ---
    const times = [];
    for (let i = 0; i < 2; i++) {
      const t0 = Date.now();
      const r = fetchOne(homeFinal, false);
      if (!r.error) times.push(Date.now() - t0);
    }
    if (times.length) {
      const avgMs = Math.round(times.reduce((a, b) => a + b, 0) / times.length);
      add("Performance", "Homepage response time", avgMs < 800 ? "Pass" : avgMs < 1800 ? "Warn" : "Fail",
        avgMs + " ms average of " + times.length + " (measured from Google's servers, includes download)",
        avgMs < 1800 ? "Medium" : "High", "Improve server response: caching, a CDN, better hosting.");
    }
    // --- Security headers ---
    step(3);
    [
      ["Strict-Transport-Security", "HSTS", "Medium"],
      ["Content-Security-Policy", "Content-Security-Policy", "Low"]
    ].forEach(h => {
      const v = getHeader(homeHeaders, h[0]);
      add("Security", h[1] + " header", v ? "Pass" : "Warn", v ? v.slice(0, 120) : "Missing", h[2], "Add the " + h[0] + " response header.");
    });

    if (/^https:/i.test(homeFinal) && homeHtml) {
      const mixed = (homeHtml.match(/\s(?:src|srcset)=["']http:\/\//gi) || []).length +
        getTags(homeHtml, "link").map(parseAttributes).filter(a => relHas(a, "stylesheet") && /^http:\/\//i.test(a.href || "")).length;
      add("Security", "Mixed content (homepage)", mixed ? "Warn" : "Pass", mixed ? mixed + " http:// resource/s" : "None", "Medium",
        "Load every image, script and stylesheet over https://.");
    }

    // --- Server / tech ---
    const server = getHeader(homeHeaders, "Server");
    const cdn = [];
    if (getHeader(homeHeaders, "cf-ray") || /cloudflare/i.test(server)) cdn.push("Cloudflare");
    if (getHeader(homeHeaders, "x-amz-cf-id")) cdn.push("CloudFront");
    if (/fastly/i.test(getHeader(homeHeaders, "x-served-by") + getHeader(homeHeaders, "via"))) cdn.push("Fastly");
    if (getHeader(homeHeaders, "x-vercel-id")) cdn.push("Vercel");
    if (getHeader(homeHeaders, "x-nf-request-id")) cdn.push("Netlify");
    if (/akamai/i.test(server + getHeader(homeHeaders, "x-akamai-transformed"))) cdn.push("Akamai");
    add("Technology", "Server / CDN", "Info", (server || "Server header hidden") + (cdn.length ? " | CDN: " + cdn.join(", ") : " | No CDN detected"), "", "");
    if (homeHtml) {
      add("Technology", "CMS / Platform", "Info", detectPlatform(homeHtml, findMetaContent(homeHtml, "generator")), "", "");
      const tr = detectTracking(homeHtml);
      add("Technology", "Analytics & tags (homepage)", tr.hasAnalytics ? "Pass" : "Warn", tr.list.length ? tr.list.join(", ") : "None found", "Medium",
        "Install GA4 (ideally via GTM) to track traffic and conversions.");
      const iconLinked = getTags(homeHtml, "link").map(parseAttributes).some(a => /icon/i.test(a.rel || ""));
      let favicon = iconLinked;
      if (!favicon) {
        const fi = fetchOne(origin + "/favicon.ico", true);
        favicon = !!(fi.response && fi.response.getResponseCode() === 200 && /image/i.test(getHeader(fi.response.getAllHeaders(), "Content-Type")));
      }
      add("Technology", "Favicon", favicon ? "Pass" : "Warn", favicon ? "Found" : "Missing", "Low", "Add a favicon (shown in Google mobile results and browser tabs).");
    }
  }

  // --- Bulk date updates (no requests: uses the dates found on the audited pages) ---
  const dated = data.map(r => {
    if (Number(r[COL["Redirect Hops"]]) > 0 || Number(r[COL["Final Status"]]) !== 200) return null;
    const v = String(r[COL["Published / Modified"]]);
    const pub = (v.match(/Pub: (\d{4}-\d{2}-\d{2})/) || [])[1], mod = (v.match(/Mod: (\d{4}-\d{2}-\d{2})/) || [])[1];
    return pub && mod ? { pub, mod } : null;
  }).filter(Boolean);
  if (dated.length < 5) {
    add("Content", "Bulk date updates", "Info", "Only " + dated.length + " page/s with both a published and a modified date (need 5+)", "", "");
  } else {
    const byDay = {};
    dated.filter(x => x.mod !== x.pub).forEach(x => { byDay[x.mod] = (byDay[x.mod] || 0) + 1; });
    const top = Object.keys(byDay).sort((a, b) => byDay[b] - byDay[a])[0];
    const share = top ? byDay[top] / dated.length : 0;
    add("Content", "Bulk date updates", share >= 0.6 ? "Warn" : "Pass",
      top ? byDay[top] + " of " + dated.length + " dated pages show modified " + top + " (" + Math.round(share * 100) + "%)" : "No updated pages",
      "Medium", "Many pages share one 'updated' day. If the content didn't really change, stop bulk-updating dates: Google may ignore or distrust them.");
  }

  return { checks, host, lastmods: sm ? sm.lastmods : null, sitemapUrls: sm ? sm.urls : null };
}

function parseRobots(txt) {
  const groups = [];
  const sitemaps = [];
  let current = null;
  let lastWasAgent = false;
  txt.split(/\r?\n/).forEach(raw => {
    const line = raw.replace(/#.*$/, "").trim();
    const idx = line.indexOf(":");
    if (!line || idx < 0) return;
    const key = line.slice(0, idx).trim().toLowerCase();
    const val = line.slice(idx + 1).trim();
    if (key === "user-agent") {
      if (!lastWasAgent || !current) { current = { agents: [], rules: [] }; groups.push(current); }
      current.agents.push(val.toLowerCase());
      lastWasAgent = true;
      return;
    }
    lastWasAgent = false;
    if (key === "sitemap") sitemaps.push(val);
    else if ((key === "allow" || key === "disallow") && current) current.rules.push({ type: key, path: val });
    else if (key === "crawl-delay" && current) current.crawlDelay = Number(val) || 0;
  });
  return { groups, sitemaps };
}

function findRobotsGroup(groups, agent) {
  const a = String(agent).toLowerCase();
  return groups.find(g => g.agents.indexOf(a) !== -1) || groups.find(g => g.agents.indexOf("*") !== -1) || null;
}

/** Google's rule: the longest matching path wins; on a tie, Allow wins. */
function robotsAllows(group, path) {
  if (!group) return true;
  let best = { len: -1, allow: true };
  group.rules.forEach(r => {
    if (!r.path) return;
    const anchored = /\$$/.test(r.path);
    const body = (anchored ? r.path.slice(0, -1) : r.path).replace(/[.+?^${}()|[\]\\]/g, "\\$&").replace(/\*/g, ".*");
    if (new RegExp("^" + body + (anchored ? "$" : "")).test(path)) {
      const len = r.path.length;
      if (len > best.len || (len === best.len && r.type === "allow")) best = { len, allow: r.type === "allow" };
    }
  });
  return best.allow;
}

function readSitemap(candidates) {
  for (let c = 0; c < candidates.length; c++) {
    const url = candidates[c];
    const r = fetchOne(url, true);
    if (r.error || r.response.getResponseCode() !== 200) continue;
    const xml = r.response.getContentText();
    const urls = new Set();
    const lastmods = new Map(); // normalized URL -> <lastmod> of that URL
    const addEntries = x => extractUrlEntries(x).forEach(e => {
      const k = normalizeForCompare(e.loc);
      urls.add(k);
      if (e.lastmod) lastmods.set(k, e.lastmod);
    });
    if (/<sitemapindex\b/i.test(xml)) {
      const children = extractLocs(xml);
      const toFetch = children.filter(u => !/\.gz(\?|$)/i.test(u)).slice(0, CONFIG.MAX_CHILD_SITEMAPS);
      let latest = maxLastmod(xml);
      for (let i = 0; i < toFetch.length; i += 10) {
        fetchMany(toFetch.slice(i, i + 10), true).forEach(cr => {
          if (!cr.response || cr.response.getResponseCode() !== 200) return;
          const cx = cr.response.getContentText();
          addEntries(cx);
          const lm = maxLastmod(cx);
          if (lm > latest) latest = lm;
        });
      }
      return { url, isIndex: true, childTotal: children.length, childRead: toFetch.length, urls, lastmods, latest };
    }
    if (/<urlset\b/i.test(xml)) {
      addEntries(xml);
      return { url, isIndex: false, childTotal: 0, childRead: 0, urls, lastmods, latest: maxLastmod(xml) };
    }
  }
  return null;
}

/** Each <url> entry of a urlset with its own <loc> and <lastmod> (image/video <...:loc> tags are ignored). */
function extractUrlEntries(xml) {
  const out = [];
  const re = /<url>([\s\S]*?)<\/url>/gi;
  let m;
  while ((m = re.exec(xml)) !== null) {
    const loc = (m[1].match(/<loc>\s*(?:<!\[CDATA\[)?\s*([\s\S]*?)\s*(?:\]\]>)?\s*<\/loc>/i) || [])[1];
    const lastmod = (m[1].match(/<lastmod>\s*([^<]+?)\s*<\/lastmod>/i) || [])[1];
    if (loc) out.push({ loc: decodeEntities(loc.trim()), lastmod: lastmod || "" });
  }
  return out;
}

/** Adds each page's sitemap <lastmod> to Date Check and flags a mismatch with the page's modified date. */
function applySitemapDates(data, lastmods) {
  if (!lastmods || !lastmods.size) return;
  data.forEach(r => {
    if (Number(r[COL["Redirect Hops"]]) > 0 || Number(r[COL["Final Status"]]) !== 200) return;
    const lm = lastmods.get(normalizeForCompare(String(r[COL["Final URL"]])));
    if (!lm) return;
    // Drop a sitemap part left by an earlier run ("Rebuild Site Health + Summary") before adding the current one.
    let check = String(r[COL["Date Check"]] || "").replace(/ ?\|? ?Sitemap lastmod:.*$/, "");
    check +=(check ? " | " : "") + "Sitemap lastmod: " + dayOf(lm);
    const mod = (String(r[COL["Published / Modified"]]).match(/Mod: (\d{4}-\d{2}-\d{2})/) || [])[1];
    if (mod && Math.abs(parseDate(dayOf(lm)) - parseDate(mod)) > DAY_MS) {
      check += " | ⚠ sitemap lastmod differs from the page's modified date";
      const base = String(r[COL["_BaseIssues"]] || "").split("; ").filter(Boolean);
      if (base.indexOf("Conflicting dates") === -1) base.push("Conflicting dates");
      r[COL["_BaseIssues"]] = base.join("; ");
      if (String(r[COL["Published / Modified"]]).indexOf("⚠ conflict") === -1) r[COL["Published / Modified"]] += " ⚠ conflict";
    }
    r[COL["Date Check"]] = check;
  });
}

function extractLocs(xml) {
  const out = [];
  const re = /<loc>\s*(?:<!\[CDATA\[)?\s*([\s\S]*?)\s*(?:\]\]>)?\s*<\/loc>/gi;
  let m;
  while ((m = re.exec(xml)) !== null) out.push(decodeEntities(m[1].trim()));
  return out;
}

function maxLastmod(xml) {
  let latest = "";
  const re = /<lastmod>\s*([^<]+?)\s*<\/lastmod>/gi;
  let m;
  while ((m = re.exec(xml)) !== null) if (m[1] > latest) latest = m[1];
  return latest;
}

function fetchOptions(followRedirects) {
  return {
    muteHttpExceptions: true,
    followRedirects: !!followRedirects,
    validateHttpsCertificates: true,
    headers: {
      "User-Agent": CURRENT_UA || CONFIG.USER_AGENT || "Mozilla/5.0", // fallback: an undefined header makes every request fail
      "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
      "Accept-Language": "en-US,en;q=0.9"
    }
  };
}

/** Parallel fetch. If one URL throws (DNS/SSL/timeout), falls back to one-by-one so a single bad URL can't break the batch. */
function fetchMany(urls, followRedirects) {
  const opts = fetchOptions(followRedirects);
  try {
    return UrlFetchApp.fetchAll(urls.map(u => Object.assign({ url: u }, opts))).map(r => ({ response: r }));
  } catch (e) {
    return urls.map(u => fetchOne(u, followRedirects));
  }
}

function fetchOne(url, followRedirects) {
  try { return { response: UrlFetchApp.fetch(url, fetchOptions(followRedirects)) }; }
  catch (e) { return { error: e.message }; }
}

/**
 * Follows redirects for a whole batch in parallel: every round fetches the next hop of all redirecting URLs
 * at once (instead of one URL at a time). Returns the same shape as followRedirectChain for each URL.
 */
function resolveChainsParallel(urls, firstResults) {
  const states = urls.map((u, i) => ({ url: u, chain: [], result: firstResults[i], out: null }));
  for (let round = 0; round <= CONFIG.MAX_REDIRECTS; round++) {
    const pending = [];
    states.forEach(s => {
      if (s.out) return;
      if (s.result.error) { s.out = { chain: s.chain, finalUrl: s.url, error: s.result.error }; return; }
      const res = s.result.response;
      const code = res.getResponseCode();
      const location = getHeader(res.getAllHeaders(), "Location");
      s.chain.push({ url: s.url, code });
      if (!(code >= 300 && code < 400 && location)) { s.out = { chain: s.chain, finalUrl: s.url, response: res }; return; }
      if (s.chain.length > CONFIG.MAX_REDIRECTS) { s.out = { chain: s.chain, finalUrl: s.url, error: "Too many redirects" }; return; }
      const next = resolveUrl(location, s.url);
      if (!next) { s.out = { chain: s.chain, finalUrl: s.url, response: res }; return; }
      if (s.chain.some(c => c.url.toLowerCase() === next.toLowerCase())) { s.out = { chain: s.chain, finalUrl: next, error: "Redirect loop" }; return; }
      s.url = next;
      pending.push(s);
    });
    if (!pending.length) break;
    fetchMany(pending.map(s => s.url), false).forEach((r, i) => { pending[i].result = r; });
  }
  return states.map(s => s.out || { chain: s.chain, finalUrl: s.url, error: "Too many redirects" });
}

/**
 * Follows redirects manually so every hop and status code is recorded.
 * Optional stopWhen(nextUrl): return true to stop before fetching that URL (result has stopped: true, no response).
 */
function followRedirectChain(startUrl, firstResult, stopWhen) {
  const chain = [];
  let url = startUrl;
  let result = firstResult || fetchOne(url, false);
  while (true) {
    if (result.error) return { chain, finalUrl: url, error: result.error };
    const res = result.response;
    const code = res.getResponseCode();
    const location = getHeader(res.getAllHeaders(), "Location");
    chain.push({ url, code });
    if (!(code >= 300 && code < 400 && location)) return { chain, finalUrl: url, response: res };
    if (chain.length > CONFIG.MAX_REDIRECTS) return { chain, finalUrl: url, error: "Too many redirects" };
    const next = resolveUrl(location, url);
    if (!next) return { chain, finalUrl: url, response: res };
    if (chain.some(c => c.url.toLowerCase() === next.toLowerCase())) return { chain, finalUrl: next, error: "Redirect loop" };
    if (stopWhen && stopWhen(next)) return { chain, finalUrl: next, stopped: true };
    url = next;
    result = fetchOne(url, false);
  }
}

function getHeader(headers, name) {
  const lower = name.toLowerCase();
  for (const k in headers) {
    if (k.toLowerCase() === lower) {
      const v = headers[k];
      return Array.isArray(v) ? v.join(", ") : String(v);
    }
  }
  return "";
}

function removeBlocks(html, tags) {
  let out = html;
  tags.forEach(t => { out = out.replace(new RegExp("<" + t + "\\b[\\s\\S]*?<\\/" + t + "\\s*>", "gi"), " "); });
  return out;
}

const VOID_TAGS = new Set(["area", "base", "br", "col", "embed", "hr", "img", "input", "link", "meta", "param", "source", "track", "wbr"]);

/**
 * Finds elements matching pred(tag, openTag) with proper nesting (a <div> inside a <div> is handled),
 * and tolerates unclosed tags. Returns top-level matches as {start, innerStart, innerEnd, end, unclosed}.
 */
function scanElements(html, pred) {
  const re = /<(\/?)([a-zA-Z][a-zA-Z0-9-]*)\b[^>]*>/g;
  const stack = [], found = [];
  let open = null, m;
  while ((m = re.exec(html)) !== null) {
    const closing = m[1] === "/", tag = m[2].toLowerCase();
    if (VOID_TAGS.has(tag) || (!closing && /\/>$/.test(m[0]))) continue;
    if (!closing) {
      stack.push(tag);
      if (!open && pred(tag, m[0])) open = { depth: stack.length, start: m.index, innerStart: re.lastIndex };
    } else {
      const idx = stack.lastIndexOf(tag);
      if (idx === -1) continue; // stray closing tag
      stack.length = idx;      // also closes anything left open inside it
      if (open && stack.length < open.depth) {
        found.push({ start: open.start, innerStart: open.innerStart, innerEnd: m.index, end: re.lastIndex });
        open = null;
      }
    }
  }
  if (open) found.push({ start: open.start, innerStart: open.innerStart, innerEnd: html.length, end: html.length, unclosed: true });
  return found;
}

/** Removes whole elements matching pred (with everything inside them). Unclosed matches are kept to avoid losing the page. */
function removeElementsWhere(html, pred) {
  let out = "", last = 0;
  scanElements(html, pred).forEach(f => {
    if (f.unclosed) return;
    out += html.slice(last, f.start) + " ";
    last = f.end;
  });
  return out + html.slice(last);
}

function classTokens(openTag) {
  const a = parseAttributes(openTag);
  return ((a["class"] || "") + " " + (a.id || "")).toLowerCase().split(/\s+/).filter(Boolean);
}

// Hidden or non-content blocks: menus, header/footer, sidebars, forms, pop-ups and off-canvas panels, TOC, related posts, sharing.
// <form> is not listed: some sites wrap a whole product listing in a filter form. Small forms are removed separately.
const NON_CONTENT_TAGS = new Set(["header", "footer", "nav", "aside", "dialog", "template", "button", "select"]);
// Sidebar classes are matched exactly: "has-sidebar" / "sidebar-left" on a layout wrapper must not remove the content.
const SIDEBAR_TOKEN = /^(sidebar|sidebar-container|sidebar-inner|sidebar-widgets|wd-sidebar|widget-area|secondary|site-sidebar|shop-sidebar|blog-sidebar)$/;
const NON_CONTENT_TOKEN = /^(hidden|d-none|is-hidden|screen-reader-text|sr-only|visually-hidden|widget|menu|toc)$|side-hidden|offcanvas|off-canvas|mobile-nav|mobile-menu|modal|popup|drawer|cookie|menu-item|breadcrumb|table-of-contents|ez-toc|rank-math-toc|lwptoc|(^|-)share(-|$)|sharing|social|related|author-box|^comments?$|comment-|newsletter|toolbar|bottom-bar|mobile-bar|sticky-footer|nav-mb/;

// React / Next.js streaming: the server sends content inside <div hidden id="S:0"> (or P:0) and a script moves it
// into place as the page loads, so visitors and Googlebot see it. It is real content, not a hidden block.
const REACT_STREAM_ID = /^[SP]:\d+$/;
// Tailwind/Bootstrap "hidden on small screens, shown from md up": the block is visible on desktop.
const RESPONSIVE_SHOW = /^(sm|md|lg|xl|2xl):(block|flex|grid|inline|inline-block|inline-flex|table|contents|flow-root)$|^d-(sm|md|lg|xl|xxl)-(block|flex|grid|inline|inline-block|inline-flex|table)$/;

function isNonContent(tag, openTag) {
  if (NON_CONTENT_TAGS.has(tag)) return true;
  const a = parseAttributes(openTag);
  if ((a.hidden !== undefined && !REACT_STREAM_ID.test(a.id || "")) || a["aria-hidden"] === "true" || a.role === "navigation" || a.role === "dialog") return true;
  if (/display\s*:\s*none|visibility\s*:\s*hidden/i.test(a.style || "")) return true;
  const tokens = classTokens(openTag);
  const shownLarger = tokens.some(t => RESPONSIVE_SHOW.test(t));
  return tokens.some(t => (NON_CONTENT_TOKEN.test(t) || SIDEBAR_TOKEN.test(t)) && !/^elementor-widget/.test(t) &&
    !(shownLarger && /^(hidden|d-none)$/.test(t)));
}

/** Removes non-content blocks, plus small forms (login, search, newsletter) but not forms that wrap real content. */
function stripNonContent(html) {
  let out = "", last = 0;
  const cleaned = removeElementsWhere(html, isNonContent);
  scanElements(cleaned, tag => tag === "form").forEach(f => {
    if (f.unclosed) return;
    const inner = cleaned.slice(f.innerStart, f.innerEnd);
    if (/type=["']password["']/i.test(inner) || cleanText(inner).length < 400) {
      out += cleaned.slice(last, f.start) + " ";
      last = f.end;
    }
  });
  return out + cleaned.slice(last);
}

// Containers that usually hold the main article/page content, most specific first.
const MAIN_CONTENT_TOKEN = /^(entry-content|post-content|wd-entry-content|article-content|article-body|blog-content|single-content|post-body|td-post-content|page-content|rte|elementor-widget-theme-post-content|product-description|term-description)$/;

/**
 * Returns the HTML of the main content area with non-content blocks removed.
 * Picks the candidate with the most text, so a menu that reuses a content class can't win.
 */
function mainContentHtml(contentHtml) {
  const pick = pred => {
    let best = "", bestLen = 0;
    scanElements(contentHtml, pred).forEach(f => {
      const inner = contentHtml.slice(f.innerStart, f.innerEnd);
      const len = cleanText(stripNonContent(inner)).length;
      if (len > bestLen) { best = inner; bestLen = len; }
    });
    return bestLen > 200 ? best : "";
  };
  const root = pick((tag, open) => /itemprop=["']articleBody["']/i.test(open)) ||
    pick((tag, open) => classTokens(open).some(t => MAIN_CONTENT_TOKEN.test(t))) ||
    pick(tag => tag === "article") ||
    pick(tag => tag === "main") ||
    contentHtml;
  return stripNonContent(root);
}

function sectionOf(html, tag) {
  const re = tag === "body"
    ? /<body\b[^>]*>([\s\S]*?)(?:<\/body\s*>|$)/i
    : new RegExp("<" + tag + "\\b[^>]*>([\\s\\S]*?)<\\/" + tag + "\\s*>", "i");

  return m ? m[1] : "";
}

function getTags(html, tag) {
  return html.match(new RegExp("<" + tag + "(?=[\\s/>])[^>]*>", "gi")) || [];
}

function getElements(html, tag) {
  const re = new RegExp("<" + tag + "(?=[\\s/>])([^>]*)>([\\s\\S]*?)<\\/" + tag + "\\s*>", "gi");
  const out = [];
  let m;
  while ((m = re.exec(html)) !== null) out.push({ attrs: parseAttributes("<" + tag + m[1] + ">"), inner: m[2] });
  return out;
}

/** Parses tag attributes, handling double, single and unquoted values (fixes the apostrophe bug). */
function parseAttributes(tag) {
  const attrs = {};
  const inner = String(tag).replace(/^<[^\s\/>]+/, "").replace(/\/?>$/, "");
  const re = /([^\s=\/>"']+)(?:\s*=\s*(?:"([^"]*)"|'([^']*)'|([^\s"'>]+)))?/g;
  let m;
  while ((m = re.exec(inner)) !== null) {
    const name = m[1].toLowerCase();
    if (attrs[name] !== undefined) continue;
    const val = m[2] !== undefined ? m[2] : m[3] !== undefined ? m[3] : m[4] !== undefined ? m[4] : "";
    attrs[name] = decodeEntities(val);
  }
  return attrs;
}

function relHas(attrs, value) {

}

function decodeEntities(str) {
  const named = { amp: "&", lt: "<", gt: ">", quot: '"', apos: "'", nbsp: " ", rsquo: "’", lsquo: "‘", rdquo: "”",
    ldquo: "“", ndash: "–", mdash: "—", hellip: "…", copy: "©", reg: "®", trade: "™", laquo: "«", raquo: "»",
    middot: "·", bull: "•", eacute: "é", egrave: "è", aacute: "á", uuml: "ü", ouml: "ö", auml: "ä" };
  const fromCode = n => { try { return String.fromCodePoint(n); } catch (e) { return ""; } };
  return String(str || "")
    .replace(/&#x([0-9a-f]+);/gi, (_, h) => fromCode(parseInt(h, 16)))
    .replace(/&#(\d+);/g, (_, n) => fromCode(parseInt(n, 10)))
    .replace(/&([a-z]+);/gi, (m, n) => (Object.prototype.hasOwnProperty.call(named, n.toLowerCase()) ? named[n.toLowerCase()] : m));
}

function cleanSpaces(str) {
  return String(str || "").replace(/\s+/g, " ").trim();
}

function cleanText(html) {
  return cleanSpaces(decodeEntities(String(html || "").replace(/<[^>]+>/g, " ")));
}

function parseUrl(url) {
  const m = String(url || "").trim().match(/^(https?):\/\/([^\/?#]+)([^?#]*)(\?[^#]*)?(#.*)?$/i);
  if (!m) return null;
  return { protocol: m[1].toLowerCase(), host: m[2].toLowerCase(), path: m[3] || "/", query: m[4] || "", hash: m[5] || "" };
}

function bareHost(host) {
  return String(host || "").toLowerCase().replace(/:\d+$/, "").replace(/^www\./, "");
}

function isInternal(host, root) {
  return host === root || host.slice(-(root.length + 1)) === "." + root;
}

/** Resolves a link against the page URL, including ./ and ../ paths. Returns null for non-http links. */
function resolveUrl(href, base) {
  href = String(href || "").trim();
  if (/^https?:\/\//i.test(href)) return href;
  const b = parseUrl(base);
  if (!b) return null;
  if (href.indexOf("//") === 0) return b.protocol + ":" + href;
  if (/^[a-z][a-z0-9+.\-]*:/i.test(href) || href.charAt(0) === "#") return null;
  if (href.charAt(0) === "?") return b.protocol + "://" + b.host + b.path + href;
  const joined = href.charAt(0) === "/" ? href : b.path.replace(/[^\/]*$/, "") + href;
  const cut = joined.search(/[?#]/);
  const pathOnly = cut >= 0 ? joined.slice(0, cut) : joined;
  const rest = cut >= 0 ? joined.slice(cut) : "";
  const segs = [];
  pathOnly.split("/").forEach(seg => {
    if (seg === "..") { if (segs.length > 1) segs.pop(); }
    else if (seg !== ".") segs.push(seg);
  });
  let path = segs.join("/");
  if (path.charAt(0) !== "/") path = "/" + path;
  return b.protocol + "://" + b.host + path + rest;
}

function normalizeForCompare(url) {
  const p = parseUrl(url);
  if (!p) return String(url || "").toLowerCase();
  return (p.protocol + "://" + p.host.replace(/:(80|443)$/, "") + p.path.replace(/\/+$/, "") + p.query).toLowerCase();
}

function sameUrl(a, b) {
  return normalizeForCompare(a) === normalizeForCompare(b);
}

function hashText(text) {
  const bytes = Utilities.computeDigest(Utilities.DigestAlgorithm.MD5, text, Utilities.Charset.UTF_8);
  return bytes.slice(0, 8).map(b => ((b + 256) % 256).toString(16).padStart(2, "0")).join("");
}

Frequently asked questions

Is this SEO audit tool really free?

Yes. It runs as a Google Apps Script inside your own Google Sheet, so there's no subscription, no credit card and no page limit to pay for. You only need a free Google account.

How many pages can it audit?

Up to 5,550 pages per audit. Large sites are crawled in chunks of about 4 minutes that continue automatically, so you can close the sheet while it runs. A free Gmail account can make about 20,000 page requests a day.

Do I need access to the website's Search Console?

No. The audit reads public pages the same way a search engine crawler does, so it works on any website, including a prospect's or a competitor's site. Search Console access isn't needed.

Will the audit slow down or harm the website?

No. Polite mode, the default, sends 5 requests at a time with a short pause, slows down if the server is busy, and respects robots.txt and its Crawl-delay setting.

Does it work with WordPress, Shopify and JavaScript websites?

It works with any website that serves HTML, including WordPress, Shopify and Next.js. It reads the raw HTML like a non-JavaScript crawler, so content that only appears after JavaScript runs is flagged as a rendering risk rather than audited.
